# IX. Таблицы

### 1. Когда следует использовать `<table>`?

Элемент `<table>` используется для представления **табличных данных** — информации, в которой значения логически связаны по строкам и столбцам.

Например:

```html
<table>
  <tr>
    <th>Товар</th>
    <th>Цена</th>
  </tr>

  <tr>
    <td>Кольцо</td>
    <td>50 000 ₸</td>
  </tr>
</table>
```

Таблица уместна, если данные имеют отношения вида:

```text
строка ↔ столбец
```

Например:

- прайс-лист;
- расписание;
- финансовый отчёт;
- статистика;
- результаты сравнения;
- характеристики товаров.

`<table>` выбирают по **семантике данных**, а не потому, что требуется визуально расположить элементы в сетке.

#### Основные элементы структуры таблицы

Базовая структура таблицы строится из нескольких элементов:

```text
<table>
└── <tr>
    ├── <th>
    └── <td>
```

#### `<table>`

Корневой элемент таблицы.

```html
<table>
  ...
</table>
```

Он сообщает браузеру, что содержимое представляет табличные данные.

#### `<tr>`

`<tr>` — table row — создаёт строку таблицы.

```html
<tr>
  ...
</tr>
```

Ячейки `<th>` и `<td>` располагаются внутри строк.

#### `<th>`

`<th>` — header cell — заголовочная ячейка.

```html
<th>Цена</th>
```

#### `<td>`

`<td>` — data cell — обычная ячейка с данными.

```html
<td>50 000 ₸</td>
```

Минимальная содержательная таблица может выглядеть так:

```html
<table>
  <tr>
    <th>Товар</th>
    <th>Цена</th>
  </tr>

  <tr>
    <td>Кольцо</td>
    <td>50 000 ₸</td>
  </tr>
</table>
```

То есть для построения строк и ячеек используются:

```text
<table> → таблица
<tr>    → строка
<th>    → заголовочная ячейка
<td>    → ячейка с данными
```

Дополнительно таблица может содержать:

```text
<caption>
<thead>
<tbody>
<tfoot>
<colgroup>
<col>
```

Эти элементы помогают более точно описывать структуру таблицы, но не требуются в каждой простой таблице.

### 2. Почему таблицы не следует использовать для построения layout?

`<table>` имеет семантику **табличных данных**, поэтому использовать её только для расположения элементов страницы неправильно.

Например, не следует делать:

```html
<table>
  <tr>
    <td>Sidebar</td>
    <td>Main content</td>
  </tr>
</table>
```

если эти элементы не являются табличными данными.

Для layout существуют CSS-механизмы:

```text
Flexbox
Grid
normal flow
positioning
```

Например:

```html
<div class="layout">
  <aside>...</aside>
  <main>...</main>
</div>
```

```css
.layout {
  display: grid;
  grid-template-columns: 250px 1fr;
}
```

Использование таблиц для layout:

- создаёт неправильную семантику;
- затрудняет работу вспомогательных технологий;
- усложняет адаптивную вёрстку;
- смешивает структуру данных с визуальным расположением.

### 3. Для чего используются `<thead>`, `<tbody>` и `<tfoot>`?

Эти элементы группируют строки таблицы по их назначению.

Они не создают отдельные ячейки: внутри них располагаются строки `<tr>`.

Структура может выглядеть так:

```text
<table>
├── <thead>
│   └── <tr>
├── <tbody>
│   └── <tr>
└── <tfoot>
    └── <tr>
```

### `<thead>`

Содержит строки с заголовочной информацией:

```html
<thead>
  <tr>
    <th>Товар</th>
    <th>Цена</th>
  </tr>
</thead>
```

### `<tbody>`

Содержит основную часть данных:

```html
<tbody>
  <tr>
    <td>Кольцо</td>
    <td>50 000 ₸</td>
  </tr>
</tbody>
```

### `<tfoot>`

Содержит итоговую или завершающую информацию:

```html
<tfoot>
  <tr>
    <th>Итого</th>
    <td>85 000 ₸</td>
  </tr>
</tfoot>
```

Полный пример:

```html
<table>
  <thead>
    <tr>
      <th>Товар</th>
      <th>Цена</th>
    </tr>
  </thead>

  <tbody>
    <tr>
      <td>Кольцо</td>
      <td>50 000 ₸</td>
    </tr>

    <tr>
      <td>Серьги</td>
      <td>35 000 ₸</td>
    </tr>
  </tbody>

  <tfoot>
    <tr>
      <th>Итого</th>
      <td>85 000 ₸</td>
    </tr>
  </tfoot>
</table>
```

`<thead>`, `<tbody>` и `<tfoot>` не обязательны для каждой простой таблицы, но позволяют явно разделить её логические части.

### 4. Чем `<th>` отличается от `<td>`?

`<th>` и `<td>` представляют ячейки таблицы, но имеют разное назначение.

### `<th>`

`<th>` — **header cell**, то есть заголовочная ячейка.

```html
<th>Цена</th>
```

Она описывает строку или столбец.

### `<td>`

`<td>` — обычная ячейка с данными.

```html
<td>50 000 ₸</td>
```

Например:

```html
<tr>
  <th>Товар</th>
  <th>Цена</th>
</tr>

<tr>
  <td>Кольцо</td>
  <td>50 000 ₸</td>
</tr>
```

Здесь:

```text
Товар, Цена → заголовки
Кольцо, 50 000 ₸ → данные
```

Различие важно не только визуально.

`<th>` передаёт семантику заголовка таблицы и может использоваться вспомогательными технологиями для определения связи между заголовками и данными.

---

### 5. Для чего нужен атрибут `scope` у `<th>`?

`scope` помогает явно указать, **к каким ячейкам относится заголовок `<th>`**.

Основные значения:

```text
scope="col"
scope="row"
```

### Заголовок столбца

```html
<th scope="col">Цена</th>
```

означает, что заголовок относится к ячейкам этого столбца.

### Заголовок строки

```html
<th scope="row">Кольцо</th>
```

означает, что заголовок относится к ячейкам этой строки.

Например:

```html
<table>
  <thead>
    <tr>
      <th scope="col">Товар</th>
      <th scope="col">Цена</th>
    </tr>
  </thead>

  <tbody>
    <tr>
      <th scope="row">Кольцо</th>
      <td>50 000 ₸</td>
    </tr>
  </tbody>
</table>
```

Существуют также:

```text
scope="rowgroup"
scope="colgroup"
```

для более сложных таблиц.

### 6. Для чего используются `colspan` и `rowspan`?

`colspan` и `rowspan` позволяют ячейке занимать несколько столбцов или строк.

### `colspan`

Определяет, сколько столбцов занимает ячейка.

```html
<td colspan="2">
  Общая ячейка
</td>
```

Например:

```html
<table>
  <tr>
    <th colspan="2">Контакты</th>
  </tr>

  <tr>
    <td>Email</td>
    <td>user@example.com</td>
  </tr>
</table>
```

### `rowspan`

Определяет, сколько строк занимает ячейка.

```html
<td rowspan="2">
  Алматы
</td>
```

Упрощённо:

```text
colspan → объединение по горизонтали
rowspan → объединение по вертикали
```

Сложные объединения ячеек могут затруднять понимание структуры таблицы, поэтому их следует использовать только тогда, когда они отражают структуру данных.

### 7. Как сделать таблицу доступной для screen reader?

Главное правило — использовать правильную семантическую структуру таблицы и явно обозначать заголовки данных.

Пример:

```html
<table>
  <caption>
    Стоимость товаров
  </caption>

  <thead>
    <tr>
      <th scope="col">Товар</th>
      <th scope="col">Цена</th>
    </tr>
  </thead>

  <tbody>
    <tr>
      <th scope="row">Кольцо</th>
      <td>50 000 ₸</td>
    </tr>

    <tr>
      <th scope="row">Серьги</th>
      <td>35 000 ₸</td>
    </tr>
  </tbody>
</table>
```

Для доступности важно:

- использовать `<table>` только для табличных данных;
- использовать `<th>` для заголовков;
- использовать `<td>` для данных;
- при необходимости задавать `scope`;
- использовать `<caption>` для названия таблицы;
- сохранять логичную структуру строк и столбцов;
- избегать ненужных сложных объединений ячеек.

### `<caption>`

`<caption>` задаёт название таблицы:

```html
<table>
  <caption>
    Продажи за сентябрь
  </caption>

  ...
</table>
```

Для сложных таблиц, где `scope` недостаточно, могут использоваться `id` и `headers`:

```html
<th id="price">Цена</th>

<td headers="price">
  50 000 ₸
</td>
```

Но для обычных таблиц предпочтительнее сохранять простую структуру с `<th>` и `scope`.
