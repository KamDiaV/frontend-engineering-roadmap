# IV. Заголовки и структура контента

### 1. Для чего используются `<h1>`–`<h6>`?

Элементы `<h1>`–`<h6>` используются для обозначения **заголовков и подзаголовков разных уровней** в структуре документа.

```html
<h1>HTML</h1>

<h2>Семантика</h2>

<h3>Заголовки</h3>
```

Уровень заголовка отражает его положение в иерархии контента:

```text
<h1> → заголовок самого высокого уровня
<h2> → подраздел уровня ниже
<h3> → подраздел внутри <h2>
...
<h6> → самый низкий уровень
```

Заголовки помогают:

- структурировать содержание;
- показывать отношения между разделами;
- облегчать чтение документа;
- создавать понятную структуру для вспомогательных технологий;
- помогать программам анализировать организацию контента.

Важно, что `<h1>`–`<h6>` задают **семантический уровень заголовка**, а не просто размер текста.

Например:

```html
<h1>Frontend Engineering</h1>

<section>
  <h2>HTML</h2>

  <section>
    <h3>Семантика</h3>
  </section>
</section>
```

---

### 2. Обязательно ли на странице должен быть только один `<h1>`?

HTML технически не запрещает использовать несколько `<h1>` на одной странице.

Например:

```html
<h1>Новости</h1>

<article>
  <h1>Первая новость</h1>
</article>

<article>
  <h1>Вторая новость</h1>
</article>
```

Такая разметка может быть допустимой с точки зрения синтаксиса HTML.

Однако на практике обычно рекомендуется иметь **один основной `<h1>`**, который обозначает главную тему страницы, а для вложенных разделов использовать `<h2>`, `<h3>` и так далее.

Например:

```html
<h1>Новости</h1>

<section>
  <h2>Последние новости</h2>

  <article>
    <h3>Первая новость</h3>
  </article>

  <article>
    <h3>Вторая новость</h3>
  </article>
</section>
```

Такой подход создаёт более очевидную и предсказуемую структуру для разработчиков и вспомогательных технологий.

---

### 3. Почему важна логическая иерархия заголовков?

Заголовки формируют **структуру документа**.

Например:

```html
<h1>HTML</h1>

<h2>Семантика</h2>

<h3>Семантические элементы</h3>

<h2>Формы</h2>

<h3>Элемент input</h3>
```

Из этой структуры видно:

```text
HTML
├── Семантика
│   └── Семантические элементы
└── Формы
    └── Элемент input
```

Логическая иерархия важна, потому что она:

- показывает отношения между разделами;
- делает документ легче для чтения;
- помогает пользователям быстро просматривать содержание;
- позволяет скринридерам перемещаться между заголовками;
- облегчает анализ структуры страницы поисковыми и другими системами.

Если уровни выбраны хаотично, смысловая структура становится менее понятной.

Например:

```html
<h1>HTML</h1>
<h4>Формы</h4>
<h2>Input</h2>
```

По такой разметке трудно понять, какой раздел кому подчиняется.

---

### 4. Можно ли переходить с `<h2>` сразу на `<h4>`?

HTML-парсер не считает такой переход синтаксической ошибкой:

```html
<h2>Формы</h2>
<h4>Input</h4>
```

Но если `<h4>` действительно является непосредственным подразделом `<h2>`, логичнее использовать:

```html
<h2>Формы</h2>
<h3>Input</h3>
```

Уровни заголовков должны отражать **смысловую вложенность разделов**.

Например:

```html
<h1>HTML</h1>
<h2>Формы</h2>
<h3>Input</h3>
<h4>Типы input</h4>
```

Здесь каждый следующий уровень обозначает более глубокий подраздел.

Пропуск уровня может быть оправдан только тогда, когда структура документа действительно этого требует, но в обычной иерархии лучше избегать необоснованных скачков.

---

### 5. Можно ли выбирать `<h1>`–`<h6>` исходя из нужного размера текста?

Нет.

Выбор между `<h1>`–`<h6>` должен зависеть от **семантического уровня заголовка**, а не от его визуального размера.

Неправильный подход:

```html
<h4>Главный заголовок</h4>
```

только потому, что стандартный размер `<h4>` визуально подходит дизайну.

Правильнее:

```html
<h1 class="page-title">
  Главный заголовок
</h1>
```

А внешний вид задавать через CSS:

```css
.page-title {
  font-size: 32px;
}
```

HTML отвечает за структуру и смысл:

```text
HTML → что это за элемент
```

CSS отвечает за представление:

```text
CSS → как он выглядит
```

Поэтому `<h1>` вполне может визуально быть меньше `<h2>`, если этого требует дизайн.

### 6. Чем `<strong>` отличается от `<b>`?

Оба элемента по умолчанию часто отображаются жирным шрифтом, но их семантика отличается.

### `<strong>`

`<strong>` обозначает **важность, серьёзность или срочность содержимого**.

```html
<p>
  <strong>Внимание:</strong>
  операция необратима.
</p>
```

Здесь выделение передаёт смысл: информация особенно важна.

### `<b>`

`<b>` используется для привлечения внимания к фрагменту текста **без придания ему дополнительной важности**.

Например:

```html
<p>
  В статье рассматриваются
  <b>HTML</b>,
  <b>CSS</b> и
  <b>JavaScript</b>.
</p>
```

`<b>` может использоваться для визуально или стилистически выделяемых слов, ключевых терминов или названий, если более подходящего семантического элемента нет.

Главное различие:

```text
<strong> → важность
<b>      → внимание без семантики важности
```

Нельзя выбирать между ними только потому, что оба обычно выглядят жирными.

### 7. Чем `<em>` отличается от `<i>`?

Оба элемента по умолчанию часто отображаются курсивом, но имеют разную семантику.

### `<em>`

`<em>` обозначает **смысловое ударение**, или emphasis.

Например:

```html
<p>
  Я сказал, что нужно сделать это <em>сегодня</em>.
</p>
```

Здесь смысл предложения меняется в зависимости от того, на каком слове находится акцент.

`<em>` может вкладываться:

```html
<p>
  Это <em>действительно <em>очень</em> важно</em>.
</p>
```

Вложенность может обозначать более сильную степень emphasis.

### `<i>`

`<i>` представляет текст, который отличается от окружающего по характеру или голосу, но не получает смыслового ударения.

Например, это может быть:

- термин;
- иностранное выражение;
- мысль;
- название вида;
- другой фрагмент с особой речевой характеристикой.

```html
<p>
  Латинское выражение <i>carpe diem</i>
  означает «лови момент».
</p>
```

Главное различие:

```text
<em> → смысловое ударение
<i>  → текст с отличающимся голосом или характером
```

### 8. Чем `<br>` отличается от создания нового абзаца через `<p>`?

`<br>` создаёт **перенос строки внутри одного смыслового блока**.

Например:

```html
<p>
  ул. Абая, 10<br>
  Астана<br>
  Казахстан
</p>
```

Здесь все строки относятся к одному адресу, поэтому они остаются одним абзацем.

`<p>` создаёт отдельный **абзац текста**:

```html
<p>
  Первый абзац.
</p>

<p>
  Второй абзац.
</p>
```

Абзацы являются отдельными смысловыми блоками.

Главное различие:

```text
<br> → перенос строки
<p>  → отдельный абзац
```

`<br>` не следует использовать для создания визуальных отступов между абзацами.

Например, вместо:

```html
<p>
  Первый текст.
  <br><br>
  Второй текст.
</p>
```

лучше написать:

```html
<p>Первый текст.</p>
<p>Второй текст.</p>
```

А расстояние между ними настроить через CSS.

`<br>` уместен там, где перенос строки является частью самого содержания:

- адрес;
- стихотворение;
- песенный текст;
- строки, где разрыв имеет смысл.

### 9. Когда уместно использовать `<blockquote>`?

`<blockquote>` используется для **развёрнутой цитаты из другого источника**, которая оформляется как отдельный блок.

Например:

```html
<blockquote>
  <p>
    Любая достаточно развитая технология
    неотличима от магии.
  </p>
</blockquote>
```

Если известен источник цитаты, у `<blockquote>` можно указать атрибут `cite`:

```html
<blockquote cite="https://example.com/source">
  <p>
    Текст цитаты.
  </p>
</blockquote>
```

Атрибут `cite` содержит URL источника цитаты.

Важно: `cite` обычно не отображается пользователю автоматически.

Видимую информацию об авторе или источнике следует указывать отдельно:

```html
<figure>
  <blockquote>
    <p>
      Текст цитаты.
    </p>
  </blockquote>

  <figcaption>
    — Автор
  </figcaption>
</figure>
```

`<blockquote>` предназначен именно для **блочной цитаты**.

Для короткой цитаты внутри строки существует элемент `<q>`:

```html
<p>
  Он сказал:
  <q>Я вернусь завтра.</q>
</p>
```

### 10. Для чего используются `<pre>` и `<code>` и чем они отличаются?

`<pre>` и `<code>` решают разные задачи и часто используются вместе.

### `<code>`

`<code>` обозначает фрагмент **компьютерного кода**.

Например, внутри обычного текста:

```html
<p>
  Метод <code>Array.prototype.map()</code>
  создаёт новый массив.
</p>
```

Он передаёт семантику: содержимое является кодом.

### `<pre>`

`<pre>` обозначает **предварительно форматированный текст**.

Внутри него браузер сохраняет пробелы и переводы строк из исходного HTML.

Например:

```html
<pre>
Первая строка
    Вторая строка с отступом
Третья строка
</pre>
```

В обычном HTML последовательности пробелов обычно схлопываются, а внутри `<pre>` форматирование текста сохраняется.

### Использование вместе

Для многострочного блока программного кода обычно используют:

```html
<pre><code>const sum = (a, b) => {
  return a + b;
};</code></pre>
```

Здесь:

- `<code>` сообщает, что содержимое является программным кодом;
- `<pre>` сохраняет форматирование, отступы и переводы строк.

Главное различие:

```text
<code> → семантика компьютерного кода
<pre>  → сохранение исходного форматирования текста
```

Поэтому `<pre>` может содержать не только код, а `<code>` может использоваться без `<pre>` для коротких фрагментов внутри строки.
