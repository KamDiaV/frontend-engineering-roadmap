# V. Ссылки и навигация

### 1. Как работает элемент `<a>`?

Элемент `<a>` создаёт гиперссылку.

Адрес назначения задаётся атрибутом `href`.

```html
<a href="/about">О нас</a>
```

Ссылка может вести:

- на другую страницу;
- на внешний сайт;
- на часть текущей страницы;
- на email-адрес;
- на номер телефона.

Примеры:

```html
<a href="https://example.com">Сайт</a>

<a href="#contacts">Контакты</a>

<a href="mailto:user@example.com">Написать</a>

<a href="tel:+77001234567">Позвонить</a>
```

Если у `<a>` отсутствует `href`, элемент не является обычной гиперссылкой и не получает всё стандартное поведение ссылки.

---

### 2. В чём разница между абсолютным и относительным URL?

**Абсолютный URL** содержит полный адрес ресурса:

```text
https://example.com/products/item.html
```

**Относительный URL** определяется относительно текущего документа, базового URL или корня сайта:

```text
./about.html
../images/photo.jpg
/products/item.html
```

Например:

```html
<a href="https://example.com/about">Абсолютный URL</a>

<a href="./about.html">Относительный URL</a>
```

Путь, начинающийся с `/`, считается относительным URL и разрешается относительно корня текущего сайта:

```html
<a href="/catalog">Каталог</a>
```

---

### 3. Для чего используется атрибут `target`?

Атрибут `target` определяет, **в каком контексте просмотра открыть ссылку**.

Основные значения:

- `_self` — текущий контекст просмотра;
- `_blank` — новый контекст просмотра;
- `_parent` — родительский контекст;
- `_top` — самый верхний контекст.

Например:

```html
<a href="/about" target="_blank">
  О нас
</a>
```

По умолчанию ссылка открывается в текущем контексте.

---

### 4. Что делает `target="_blank"`?

`target="_blank"` открывает ссылку в **новом browsing context** — обычно в новой вкладке или окне.

```html
<a
  href="https://example.com"
  target="_blank"
>
  Открыть сайт
</a>
```

Не стоит говорить, что `_blank` всегда создаёт именно новую вкладку: конкретное поведение зависит от браузера и пользовательских настроек.

---

### 5. Зачем используются `rel="noopener"` и `rel="noreferrer"`?

`rel="noopener"` предотвращает доступ открытой страницы к исходной странице через `window.opener`.

```html
<a
  href="https://example.com"
  target="_blank"
  rel="noopener"
>
  Example
</a>
```

Это снижает риск того, что новая страница сможет воздействовать на исходную вкладку.

`rel="noreferrer"` дополнительно запрещает передавать адрес страницы-источника через HTTP-заголовок `Referer`.

```html
<a
  href="https://example.com"
  target="_blank"
  rel="noreferrer"
>
  Example
</a>
```

`noreferrer` также подразумевает поведение `noopener`.

Современные браузеры для `target="_blank"` обычно уже применяют поведение `noopener`, но атрибут можно указывать явно.

`rel="noreferrer"` Атрибут — это HTML-тег, добавляемый к гиперссылке, чтобы предотвратить передачу браузером информации о переходе пользователя на связанный сайт. Когда пользователь нажимает на ссылку с этим атрибутом, аналитика связанного сайта не сможет определить, что трафик пришел с вашего сайта. `noreferrer` Атрибут — это, прежде всего, функция безопасности, но он также используется в целях конфиденциальности. Рекомендуется использовать его для всех внешних ссылок, открывающихся в новой вкладке.

## Почему атрибут Noreferrer имеет значение

Атрибут noreferrer — ключевой элемент современной веб-безопасности и конфиденциальности. Он важен, поскольку позволяет напрямую защитить конфиденциальность пользователя и предотвратить уязвимость безопасности, известную как табуляция. Хотя noreferrer и noopener — это два разных атрибута, они часто используются вместе для обеспечения бесперебойной и безопасной работы пользователя. Веб-сайт, не использующий атрибут noreferrer, находится в крайне невыгодном положении, поскольку может стать источником проблем безопасности. Используя атрибут noreferrer, вы можете:

- **Улучшение безопасности:** Вы можете защитить пользователей своего веб-сайта от уязвимости безопасности, известной как табуляция.
- **Повышение доверия:** Веб-сайт, ориентированный на безопасность и конфиденциальность, является четким сигналом того, что ваш бизнес представляет собой высококачественный ресурс.
- **Улучшить пользовательский опыт:** Вы можете обеспечить пользователям бесперебойный опыт взаимодействия, что может привести к снижению показателя отказов и повышению показателя кликов.

### 6. Как создать ссылку на определённую часть страницы?

Нужному элементу задаётся `id`:

```html
<section id="contacts">
  <h2>Контакты</h2>
</section>
```

Затем создаётся ссылка с `#`:

```html
<a href="#contacts">Контакты</a>
```

Значение после `#` соответствует `id` целевого элемента:

```text
href="#contacts" → id="contacts"
```

Можно ссылаться и на фрагмент другой страницы:

```html
<a href="/about#team">
  Команда
</a>
```

---

### 7. Что такое fragment identifier (`#section`)?

**Fragment identifier** — часть URL после символа `#`, которая обозначает определённый фрагмент ресурса.

Например:

```text
https://example.com/article#examples
```

Здесь:

```text
#examples
```

— fragment identifier.

В HTML он часто соответствует `id` элемента:

```html
<h2 id="examples">Примеры</h2>
```

Fragment identifier обычно обрабатывается браузером и не отправляется серверу как часть HTTP-запроса.

### 8. В чём разница между `<a>` и `<button>`?

Эти элементы имеют разное назначение.

`<a>` используется для **навигации**:

```html
<a href="/catalog">Каталог</a>
```

`<button>` используется для **действия**:

```html
<button type="button">
  Открыть меню
</button>
```

Основное правило:

```text
<a>      → переход
<button> → действие
```

---

### 9. Почему не стоит использовать `<div>` с обработчиком `click` вместо ссылки или кнопки?

`<div>` — обычный контейнер и не имеет встроенной семантики ссылки или кнопки.

Например:

```html
<div onclick="openMenu()">
  Открыть меню
</div>
```

Сам по себе такой элемент:

- не воспринимается как кнопка;
- не получает стандартного клавиатурного поведения кнопки;
- не имеет встроенной семантики для вспомогательных технологий;
- не получает все стандартные возможности нативного интерактивного элемента.

Вместо этого лучше использовать:

```html
<button type="button">
  Открыть меню
</button>
```

или, если нужна навигация:

```html
<a href="/catalog">
  Каталог
</a>
```

#### Короткий ответ для собеседования

`<div>` не имеет встроенной семантики и поведения ссылки или кнопки.
Для интерактивных элементов лучше использовать нативные `<a>` и `<button>`.

---

### 10. Когда использовать `<a>`, а когда `<button>`?

Выбор зависит от результата действия пользователя.

Используйте `<a>`, если после активации происходит **переход по URL**:

```html
<a href="/profile">Профиль</a>
```

Используйте `<button>`, если происходит **действие в интерфейсе**:

```html
<button type="button">
  Открыть фильтры
</button>
```

Например:

`<a>`:

- переход на страницу;
- переход к разделу документа;
- открытие внешнего ресурса.

`<button>`:

- открыть модальное окно;
- раскрыть меню;
- переключить состояние;
- удалить элемент;
- отправить форму.

Внешний вид не определяет семантику.

Ссылка может выглядеть как кнопка:

```html
<a class="button" href="/checkout">
  Перейти к оформлению
</a>
```

Но если она выполняет навигацию, семантически это всё равно `<a>`.
