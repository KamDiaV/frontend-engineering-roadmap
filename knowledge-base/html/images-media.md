# VI. Изображения и медиа

### 1. Как правильно добавить изображение в HTML?

Изображение в HTML добавляется с помощью элемента `<img>`.

Основные атрибуты:

- `src` — путь или URL к изображению;
- `alt` — текстовая альтернатива изображения.

Например:

```html
<img
  src="./images/product.jpg"
  alt="Золотое кольцо с зелёным камнем"
>
```

Здесь:

- `src="./images/product.jpg"` указывает источник изображения;
- `alt="Золотое кольцо с зелёным камнем"` задаёт его текстовую альтернативу.

Элемент `<img>` является **void element**, поэтому у него нет закрывающего тега.

Правильно:

```html
<img src="./images/photo.jpg" alt="Горное озеро">
```

Неправильно:

```html
<img src="./images/photo.jpg" alt="Горное озеро"></img>
```

Также рекомендуется указывать `width` и `height`:

```html
<img
  src="./images/photo.jpg"
  alt="Горное озеро"
  width="800"
  height="600"
>
```

---

### 2. Для чего нужен атрибут `alt`?

Атрибут `alt` задаёт **текстовую альтернативу изображения**.

Она нужна в ситуациях, когда изображение нельзя увидеть или оно недоступно пользователю.

Например:

```html
<img
  src="./images/chart.png"
  alt="Продажи выросли с 20 до 45 тысяч единиц с января по июнь"
>
```

Текст `alt` может использоваться вспомогательными технологиями, например скринридерами.

Он также может отображаться или использоваться браузером, если изображение не удалось загрузить.

Хороший `alt` должен передавать **смысл или функцию изображения в конкретном контексте**, а не обязательно буквально описывать всё, что на нём находится.

Если изображение является интерактивным элементом, например находится внутри ссылки, `alt` должен передавать назначение этого элемента.

```html
<a href="/catalog">
  <img
    src="./images/catalog.jpg"
    alt="Каталог украшений"
  >
</a>
```

---

### 3. Каким должен быть `alt` у декоративного изображения?

Если изображение является исключительно декоративным и не несёт полезной информации, обычно используется пустой `alt`:

```html
<img src="./images/decorative-line.svg" alt="">
```

Пустой `alt` сообщает вспомогательным технологиям, что изображение не нужно озвучивать как содержательный элемент.

К декоративным могут относиться:

- орнаменты;
- декоративные разделители;
- изображения, не добавляющие новой информации;
- графика, смысл которой полностью представлен соседним текстом.

Например:

```html
<h2>
  <img src="./images/star.svg" alt="">
  Популярные товары
</h2>
```

Если звезда здесь является только украшением, отдельное описание ей не требуется.

---

### 4. Чем `alt=""` отличается от отсутствующего `alt`?

Пустой `alt` и отсутствие `alt` имеют разный смысл.

```html
<img src="./images/decor.svg" alt="">
```

`alt=""` явно сообщает, что изображение **не требует текстовой альтернативы**, например потому что оно декоративное.

Если `alt` отсутствует:

```html
<img src="./images/photo.jpg">
```

текстовая альтернатива не задана.

В таком случае поведение вспомогательных технологий может различаться: некоторые из них могут попытаться озвучить имя файла, URL или другую доступную информацию.

Поэтому для декоративных изображений важно использовать именно:

```html
alt=""
```

а не просто удалять атрибут `alt`.

### 5. Для чего используются `<figure>` и `<figcaption>`?

Элемент `<figure>` используется для содержимого, которое образует **самостоятельную смысловую единицу** и обычно связано с основным содержимым документа.

Это может быть:

- изображение;
- диаграмма;
- иллюстрация;
- фрагмент кода;
- таблица;
- цитата.

Например:

```html
<figure>
  <img
    src="./images/chart.png"
    alt="График роста продаж с января по июнь"
  >

  <figcaption>
    Динамика продаж за первое полугодие.
  </figcaption>
</figure>
```

`<figcaption>` задаёт подпись для содержимого `<figure>`.

Если `<figcaption>` присутствует, он должен быть первым или последним дочерним элементом `<figure>`.

Важно различать `alt` и `<figcaption>`:

- `alt` — текстовая альтернатива изображения;
- `<figcaption>` — видимая подпись ко всему `<figure>`.

Они решают разные задачи и не обязаны дублировать друг друга.

### 6. Что такое responsive images?

**Responsive images** — это механизм, позволяющий предоставить браузеру несколько вариантов изображения, чтобы он мог выбрать наиболее подходящий.

Например, выбор может зависеть от:

- размера изображения в макете;
- ширины viewport;
- плотности пикселей устройства;
- поддерживаемого формата;
- media conditions.

Responsive images позволяют:

- не загружать чрезмерно большие изображения на небольших экранах;
- предоставлять изображения подходящего разрешения;
- использовать разные изображения или кадрирование при разных условиях.

Основные средства HTML для responsive images:

- `srcset`;
- `sizes`;
- `<picture>`;
- `<source>`.

---

### 7. Для чего используются `srcset` и `sizes`?

Атрибут `srcset` позволяет указать **набор кандидатов изображения**.

Например:

```html
<img
  src="./images/photo-800.jpg"
  srcset="
    ./images/photo-400.jpg 400w,
    ./images/photo-800.jpg 800w,
    ./images/photo-1200.jpg 1200w
  "
  sizes="
    (max-width: 600px) 100vw,
    800px
  "
  alt="Горное озеро"
>
```

Дескрипторы:

```text
400w
800w
1200w
```

указывают intrinsic width соответствующих файлов в CSS-пикселях.

`sizes` описывает браузеру предполагаемую **ширину слота изображения в макете** при разных условиях.

Например:

```html
sizes="
  (max-width: 600px) 100vw,
  800px
"
```

означает:

- при viewport до `600px` изображение предполагается шириной `100vw`;
- иначе — `800px`.

Используя `srcset`, `sizes`, размер viewport и device pixel ratio, браузер выбирает подходящий кандидат.

`srcset` также можно использовать с дескрипторами плотности:

```html
<img
  src="./images/logo.png"
  srcset="
    ./images/logo.png 1x,
    ./images/logo@2x.png 2x
  "
  alt="Логотип компании"
>
```

При использовании `1x`, `2x` и других density descriptors атрибут `sizes` не применяется.

#### Короче:

`srcset` задаёт несколько кандидатов изображения.

`sizes` сообщает браузеру предполагаемый размер изображения в макете при использовании `w`-дескрипторов.

На основе этой информации браузер сам выбирает подходящий файл.

### 8. Для чего используется элемент `<picture>`?

Элемент `<picture>` используется, когда нужно предоставить несколько вариантов изображения и задать условия, при которых должен использоваться каждый из них.

Он состоит из одного или нескольких `<source>` и обязательного `<img>`.

Например:

```html
<picture>
  <source
    media="(max-width: 600px)"
    srcset="./images/product-mobile.jpg"
  >

  <img
    src="./images/product-desktop.jpg"
    alt="Золотое кольцо"
  >
</picture>
```

`<picture>` особенно полезен для **art direction** — когда для разных условий используются не просто разные размеры одного файла, а разные версии изображения.

Например:

- широкая фотография для desktop;
- более крупное кадрирование объекта для mobile.

Также `<picture>` можно использовать для выбора формата:

```html
<picture>
  <source
    srcset="./images/photo.avif"
    type="image/avif"
  >

  <source
    srcset="./images/photo.webp"
    type="image/webp"
  >

  <img
    src="./images/photo.jpg"
    alt="Горное озеро"
  >
</picture>
```

Браузер рассматривает `<source>` по порядку и использует первый подходящий вариант.

`<img>` является обязательной частью `<picture>` и служит самим элементом изображения, а также fallback-вариантом.

#### Короче:

`<picture>` используется для выбора разных источников изображения по условиям, например по media query или поддерживаемому MIME-типу.

Он особенно полезен для art direction и выбора форматов изображения.

---

### 9. Чем `<picture>` отличается от `srcset`?

`srcset` и `<picture>` оба используются для responsive images, но дают разный уровень контроля.

`srcset` обычно подходит для **resolution switching** — когда содержимое изображения остаётся тем же, но доступны разные размеры или разрешения.

```html
<img
  src="./images/photo-800.jpg"
  srcset="
    ./images/photo-400.jpg 400w,
    ./images/photo-800.jpg 800w,
    ./images/photo-1200.jpg 1200w
  "
  sizes="100vw"
  alt="Горное озеро"
>
```

В этом случае браузер выбирает подходящий кандидат.

`<picture>` нужен, когда разработчик хочет задавать правила выбора источника.

Например:

```html
<picture>
  <source
    media="(max-width: 600px)"
    srcset="./images/photo-mobile.jpg"
  >

  <img
    src="./images/photo-desktop.jpg"
    alt="Горное озеро"
  >
</picture>
```

Он используется для:

- art direction;
- выбора разных форматов;
- выбора источников по `media`.

Важно: `<picture>` не является альтернативой `srcset` в буквальном смысле — `<source>` внутри `<picture>` сам использует `srcset`.

#### Короче:

`srcset` обычно предоставляет браузеру несколько вариантов одного изображения и позволяет ему выбрать подходящий.

`<picture>` позволяет разработчику задавать разные источники по условиям, например для art direction или выбора формата.

### 10. Для чего используется `loading="lazy"`?

Атрибут:

```html
loading="lazy"
```

указывает браузеру, что загрузку изображения можно отложить, пока оно не приблизится к viewport.

Например:

```html
<img
  src="./images/product.jpg"
  alt="Золотое кольцо"
  loading="lazy"
>
```

Это называется **native lazy loading**.

Оно может уменьшить количество ресурсов, загружаемых при первоначальной загрузке страницы.

`loading="lazy"` особенно подходит для изображений, которые находятся далеко ниже первого экрана.

Для изображения, которое важно для первоначального отображения страницы, например LCP-изображения в hero-секции, `loading="lazy"` обычно использовать не следует, поскольку это может задержать его загрузку.

Другим значением является:

```html
loading="eager"
```

Оно сообщает браузеру, что ресурс следует загружать без lazy-loading поведения.

При этом точный момент загрузки всё равно определяется самим браузером и его сетевым планировщиком.

#### Короче:

`loading="lazy"` включает нативную ленивую загрузку.

Браузер может отложить загрузку изображения, пока оно не приблизится к viewport, что помогает уменьшить первоначальную сетевую нагрузку.

Для важных изображений первого экрана lazy loading обычно не используют.

### 11. Что делают атрибуты `width` и `height` у `<img>` и почему их полезно указывать?

Атрибуты `width` и `height` задают intrinsic dimensions изображения в CSS-пикселях.

Например:

```html
<img
  src="./images/photo.jpg"
  alt="Горное озеро"
  width="800"
  height="600"
>
```

Они также позволяют браузеру определить **intrinsic aspect ratio** изображения ещё до завершения его загрузки.

В данном случае:

```text
800 / 600 = 4 / 3
```

Благодаря этому браузер может заранее зарезервировать подходящее пространство в макете.

CSS при этом может задавать фактический отображаемый размер:

```css
img {
  max-width: 100%;
  height: auto;
}
```

Например, файл может иметь HTML-размеры:

```html
width="800"
height="600"
```

но визуально отображаться шириной `400px`.

Главное преимущество указания `width` и `height` — браузер заранее знает соотношение сторон и может уменьшить неожиданные сдвиги макета.

### 12. Как HTML изображений может влиять на производительность и CLS?

Изображения часто составляют значительную часть веса страницы, поэтому их HTML-разметка влияет на производительность.

#### Размер загружаемого ресурса

Если для небольшого изображения в интерфейсе загрузить файл с очень большим разрешением, пользователь может скачать больше данных, чем необходимо.

Для разных размеров можно использовать:

```html
srcset
sizes
```

чтобы браузер мог выбрать подходящий ресурс.

#### Lazy loading

Для изображений вне первоначального viewport можно использовать:

```html
loading="lazy"
```

Это позволяет отложить их загрузку.

#### Форматы изображений

С помощью `<picture>` можно предоставлять разные форматы:

```html
<picture>
  <source srcset="./images/photo.avif" type="image/avif">
  <source srcset="./images/photo.webp" type="image/webp">

  <img
    src="./images/photo.jpg"
    alt="Горное озеро"
    width="800"
    height="600"
  >
</picture>
```

#### CLS

**CLS — Cumulative Layout Shift** — Core Web Vital, измеряющий неожиданные изменения положения видимого контента во время жизни страницы.

Если изображение появляется без заранее зарезервированного пространства, оно может сдвинуть соседний контент.

Например:

```html
<img
  src="./images/photo.jpg"
  alt="Горное озеро"
>
```

Если браузер заранее не знает подходящий размер изображения, после его загрузки макет может измениться.

Указание:

```html
width="800"
height="600"
```

позволяет браузеру определить соотношение сторон и заранее зарезервировать пространство.

Важно также не применять lazy loading к критически важным изображениям первого экрана, поскольку это может ухудшить скорость отображения основного контента и LCP.

#### Короче:

Изображения влияют на производительность прежде всего через объём загружаемых данных и момент загрузки.

Для оптимизации используют `srcset`, `sizes`, подходящие форматы и `loading="lazy"` для некритичных изображений.

`width` и `height` помогают заранее зарезервировать пространство под изображение и снизить риск CLS.

### 13. Для чего используются `<audio>` и `<video>`?

Элементы `<audio>` и `<video>` предназначены для встраивания аудио- и видеоконтента без необходимости использовать сторонние плагины.

#### `<audio>`

Например:

```html
<audio src="./audio/song.mp3" controls></audio>
```

Атрибут `controls` просит браузер предоставить стандартные элементы управления воспроизведением.

Также можно указать несколько источников:

```html
<audio controls>
  <source src="./audio/song.ogg" type="audio/ogg">
  <source src="./audio/song.mp3" type="audio/mpeg">

  Ваш браузер не поддерживает элемент audio.
</audio>
```

#### `<video>`

Например:

```html
<video
  src="./video/movie.mp4"
  controls
  width="800"
></video>
```

Часто используемые атрибуты:

- `controls` — стандартные элементы управления;
- `autoplay` — запросить автоматическое начало воспроизведения;
- `muted` — отключить звук;
- `loop` — повторять воспроизведение;
- `poster` — изображение, показываемое до начала воспроизведения видео.

Например:

```html
<video
  controls
  poster="./images/video-cover.jpg"
  width="800"
>
  <source src="./video/movie.mp4" type="video/mp4">

  Ваш браузер не поддерживает элемент video.
</video>
```

Браузеры могут ограничивать autoplay, особенно воспроизведение со звуком.

#### Короче:

`<audio>` используется для встраивания аудио, а `<video>` — для встраивания видео.

Они поддерживают встроенное управление воспроизведением и могут содержать несколько `<source>` с альтернативными медиафайлами.

### 14. Для чего нужен элемент `<source>`?

Элемент `<source>` задаёт **альтернативный источник медиа**.

Он используется внутри:

- `<picture>`;
- `<audio>`;
- `<video>`.

Но его атрибуты зависят от контекста.

#### В `<audio>` и `<video>`

Используется атрибут `src`:

```html
<video controls>
  <source
    src="./video/movie.webm"
    type="video/webm"
  >

  <source
    src="./video/movie.mp4"
    type="video/mp4"
  >
</video>
```

Браузер рассматривает источники по порядку и выбирает подходящий ресурс.

Аналогично для `<audio>`:

```html
<audio controls>
  <source
    src="./audio/song.ogg"
    type="audio/ogg"
  >

  <source
    src="./audio/song.mp3"
    type="audio/mpeg"
  >
</audio>
```

#### В `<picture>`

Вместо `src` используется `srcset`:

```html
<picture>
  <source
    media="(max-width: 600px)"
    srcset="./images/mobile.jpg"
  >

  <source
    srcset="./images/photo.webp"
    type="image/webp"
  >

  <img
    src="./images/photo.jpg"
    alt="Горное озеро"
  >
</picture>
```

Здесь `<source>` может использовать:

- `srcset` — кандидаты изображения;
- `media` — условие выбора;
- `type` — MIME-тип;
- `sizes` — описание размера слота при использовании соответствующего `srcset`.

`<source>` является void element и не имеет закрывающего тега.

#### Короче:

`<source>` позволяет задавать альтернативные источники для `<picture>`, `<audio>` и `<video>`.

В `<audio>` и `<video>` обычно используется `src`, а внутри `<picture>` — `srcset`.

Браузер выбирает подходящий источник из предоставленных вариантов.
