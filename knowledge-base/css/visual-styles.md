# XII. Цвета, фон и границы

## 1. Какие способы задания цвета существуют в CSS?

В современном CSS цвет можно задавать несколькими способами.

Основные варианты, которые нужно знать в первую очередь:

```text
именованные цвета

HEX

rgb()

hsl()
```

Также современный CSS поддерживает более новые цветовые модели:

```text
hwb()

lab()
lch()

oklab()
oklch()

color()
```

И специальные значения и функции:

```text
transparent
currentColor
color-mix()
light-dark()
```

Для начала особенно важно хорошо понимать:

```text
HEX
RGB
HSL
alpha channel
```

---

### Именованные цвета

Можно использовать готовые названия:

```css
color: red;
color: blue;
color: black;
color: white;
color: rebeccapurple;
```

Например:

```css
.button {
  background-color: blue;
  color: white;
}
```

CSS содержит большое количество стандартных именованных цветов.

Но для точного дизайна они используются реже, потому что выбор ограничен заранее определёнными названиями.

---

### HEX

Цвет можно записать шестнадцатеричным кодом:

```css
color: #ff0000;
```

Здесь:

```text
#ff0000
→ красный
```

Стандартная запись:

```text
#RRGGBB
```

где:

```text
RR → red
GG → green
BB → blue
```

Каждый канал может иметь значение:

```text
00 → минимум

ff → максимум
```

Например:

```css
color: #000000;
```

→ чёрный.

```css
color: #ffffff;
```

→ белый.

```css
color: #ff0000;
```

→ красный.

```css
color: #00ff00;
```

→ зелёный.

```css
color: #0000ff;
```

→ синий.

---

### Сокращённый HEX

Иногда можно встретить:

```css
color: #fff;
```

Это сокращение:

```css
color: #ffffff;
```

А:

```css
color: #f00;
```

означает:

```css
color: #ff0000;
```

Для читаемости в проектах часто используют полную шестизначную запись.

---

### HEX с прозрачностью

Современный CSS позволяет добавить четвёртый канал:

```text
#RRGGBBAA
```

Например:

```css
background-color: #00000080;
```

Последние два символа:

```text
80
```

задают alpha channel — уровень непрозрачности цвета.

Существует и сокращённая четырёхзначная форма:

```text
#RGBA
```

---

### RGB

Можно задавать цвет через:

```css
rgb()
```

Например:

```css
color: rgb(255 0 0);
```

Здесь:

```text
red   = 255
green = 0
blue  = 0
```

Получаем красный.

Диапазон каждого основного канала:

```text
0–255
```

---

### Современный RGB с alpha channel

```css
background-color: rgb(0 0 0 / 50%);
```

или:

```css
background-color: rgb(0 0 0 / 0.5);
```

означает чёрный цвет с непрозрачностью `50%`.

Старая запись:

```css
rgba(0, 0, 0, 0.5);
```

тоже работает.

Но в современном CSS:

```text
rgba()
```

является фактически псевдонимом:

```text
rgb()
```

Поэтому сейчас можно спокойно писать:

```css
rgb(0 0 0 / 0.5)
```

---

### HSL

Например:

```css
color: hsl(0 100% 50%);
```

HSL описывает цвет через:

```text
Hue
Saturation
Lightness
```

То есть:

```text
оттенок
насыщенность
светлота
```

Эту модель подробно разберём в вопросе 3.

---

### Современные цветовые модели

CSS также поддерживает:

```css
color: hwb(200 20% 10%);
```

```css
color: lab(60% 20 30);
```

```css
color: oklch(70% 0.15 250);
```

Например, `oklch()` становится особенно полезным при построении цветовых систем, потому что лучше соответствует тому, как человек воспринимает различия яркости и цвета.

Но начинающему не нужно сразу запоминать синтаксис всех моделей.

Сначала важно уверенно понимать:

```text
HEX
RGB
HSL
alpha
```

а затем переходить к:

```text
OKLCH
color-mix()
и другим современным возможностям
```

---

### `transparent`

Специальное значение:

```css
background-color: transparent;
```

означает полностью прозрачный цвет.

Например, начальное значение `background-color`:

```css
background-color: transparent;
```

---

### `currentColor`

Специальное значение:

```css
currentColor
```

берёт текущее значение свойства:

```css
color
```

Например:

```css
.button {
  color: blue;
  border: 1px solid currentColor;
}
```

Граница тоже будет синей.

Это удобно, когда цвет нескольких элементов должен зависеть от основного цвета текста.

---

### Главное

Основные способы:

```text
red
→ именованный цвет

#ff0000
→ HEX

rgb(255 0 0)
→ RGB

hsl(0 100% 50%)
→ HSL
```

С прозрачностью:

```css
rgb(255 0 0 / 50%)
```

Современный CSS также предоставляет более широкие цветовые пространства:

```text
lab()
lch()
oklab()
oklch()
color()
```

---

## 2. Чем HEX отличается от RGB?

HEX и `rgb()` — это **не две принципиально разные цветовые модели**.

В обычном использовании они оба позволяют описывать цвет через:

```text
Red
Green
Blue
```

и обычно представляют цвет в пространстве sRGB.

Главное отличие — **способ записи чисел**.

---

### RGB

Например:

```css
color: rgb(255 0 0);
```

Значения записываются привычными десятичными числами:

```text
red   = 255
green = 0
blue  = 0
```

---

### HEX

Тот же цвет:

```css
color: #ff0000;
```

использует шестнадцатеричную систему.

```text
ff → 255
00 → 0
00 → 0
```

Поэтому:

```text
rgb(255 0 0)
=
#ff0000
```

---

### Другой пример

```css
color: rgb(255 255 255);
```

и:

```css
color: #ffffff;
```

оба означают белый.

---

### Сравнение

| Характеристика | HEX | RGB |
|---|---|---|
| Основная модель | RGB | RGB |
| Обычное пространство | sRGB | sRGB |
| Запись | шестнадцатеричная | десятичная |
| Пример красного | `#ff0000` | `rgb(255 0 0)` |
| Поддерживает alpha | Да | Да |
| Удобно читать отдельные каналы | Меньше | Больше |

---

### Alpha channel

HEX:

```css
color: #ff000080;
```

RGB:

```css
color: rgb(255 0 0 / 50%);
```

Обе записи могут описывать полупрозрачный красный.

---

### Что лучше использовать?

Оба варианта нормальны.

Например:

```css
color: #1f2937;
```

компактно.

А:

```css
color: rgb(31 41 55);
```

наглядно показывает значения отдельных RGB-каналов.

Особенно удобно использовать `rgb()` с прозрачностью:

```css
box-shadow: 0 4px 20px rgb(0 0 0 / 15%);
```

---

### Главное

```text
HEX и RGB
→ обычно описывают одну и ту же модель RGB

разница
→ в синтаксисе записи
```

Например:

```text
#ff0000
=
rgb(255 0 0)
=
красный
```

---

## 3. Что такое HSL?

**HSL** — способ задания цвета через три характеристики:

```text
H → Hue
S → Saturation
L → Lightness
```

По-русски:

```text
H → оттенок
S → насыщенность
L → светлота
```

Синтаксис:

```css
color: hsl(0 100% 50%);
```

---

### Hue — оттенок

Оттенок определяется положением на цветовом круге.

Обычно можно представить:

```text
0deg
→ красный

60deg
→ жёлтый

120deg
→ зелёный

180deg
→ голубой

240deg
→ синий

300deg
→ пурпурный

360deg
→ снова красный
```

Например:

```css
color: hsl(240 100% 50%);
```

даст синий.

---

### Saturation — насыщенность

```text
0%
→ цвет полностью ненасыщенный
→ оттенок серого

100%
→ максимально насыщенный цвет
```

Например:

```css
color: hsl(0 0% 50%);
```

будет серым.

А:

```css
color: hsl(0 100% 50%);
```

будет насыщенным красным.

---

### Lightness — светлота

```text
0%
→ чёрный

50%
→ обычная середина

100%
→ белый
```

Например:

```css
color: hsl(0 100% 50%);
```

→ красный.

```css
color: hsl(0 100% 25%);
```

→ более тёмный красный.

```css
color: hsl(0 100% 75%);
```

→ более светлый красный.

---

### Alpha channel в HSL

Можно добавить прозрачность:

```css
background-color: hsl(0 100% 50% / 50%);
```

или:

```css
background-color: hsl(0 100% 50% / 0.5);
```

---

### `hsla()`

В старом коде можно увидеть:

```css
hsla(0, 100%, 50%, 0.5)
```

Современный CSS рассматривает:

```text
hsla()
```

как псевдоним:

```text
hsl()
```

Поэтому предпочтительна более современная запись:

```css
hsl(0 100% 50% / 0.5)
```

---

### Почему HSL может быть удобнее RGB?

Представим, что нужно сделать один цвет светлее.

В RGB:

```css
rgb(40 90 180)
```

не всегда очевидно, какие значения изменить.

В HSL:

```css
hsl(215 64% 43%)
```

можно изменить только светлоту:

```css
hsl(215 64% 60%)
```

То есть цветовая идея сохраняется, а цвет становится светлее.

---

### Важно

HSL удобен для человека, но не является идеально равномерной моделью человеческого восприятия.

Например, одинаковое:

```text
lightness: 50%
```

у разных оттенков не обязательно будет выглядеть одинаково светлым.

Для более современных цветовых систем существуют:

```text
OKLab
OKLCH
```

Но для базового понимания CSS HSL по-прежнему очень важен.

---

### Главное

```text
HSL

Hue
→ какой цвет

Saturation
→ насколько он насыщенный

Lightness
→ насколько он светлый
```

---

## 4. Что такое Alpha Channel?

**Alpha Channel (альфа-канал)** определяет степень непрозрачности конкретного цвета.

Диапазон:

```text
0
→ полностью прозрачно

1
→ полностью непрозрачно
```

или:

```text
0%
→ полностью прозрачно

100%
→ полностью непрозрачно
```

---

### Пример

```css
background-color: rgb(0 0 0 / 0.5);
```

означает:

```text
чёрный
+
50% непрозрачности
```

Через него будет частично видно содержимое позади.

---

### То же через проценты

```css
background-color: rgb(0 0 0 / 50%);
```

---

### В HSL

```css
background-color: hsl(0 0% 0% / 50%);
```

---

### В HEX

Можно использовать:

```text
#RRGGBBAA
```

например:

```css
background-color: #00000080;
```

---

### Alpha относится именно к цвету

Например:

```css
.card {
  background-color: rgb(0 0 0 / 50%);
  color: white;
}
```

Полупрозрачным будет фон.

Но текст:

```text
white
```

остаётся полностью непрозрачным.

Это важное отличие от:

```css
opacity: 0.5;
```

которое влияет на весь элемент.

---

### Главное

```text
alpha channel
→ непрозрачность конкретного цвета

0 / 0%
→ полностью прозрачно

1 / 100%
→ полностью непрозрачно
```

---

## 5. Что делает `opacity`?

Свойство:

```css
opacity
```

задаёт непрозрачность **всего элемента как единого результата отрисовки**.

Например:

```css
.card {
  opacity: 0.5;
}
```

означает:

```text
50% непрозрачности
```

---

### Диапазон

```css
opacity: 0;
```

→ полностью прозрачно.

```css
opacity: 0.5;
```

→ полупрозрачно.

```css
opacity: 1;
```

→ полностью непрозрачно.

Можно использовать проценты:

```css
opacity: 50%;
```

---

### Начальное значение

```css
opacity: 1;
```

---

### `opacity` влияет на содержимое

Например:

```html
<div class="card">
  <h2>Title</h2>
  <button>Buy</button>
</div>
```

```css
.card {
  opacity: 0.5;
}
```

Полупрозрачными визуально станут:

```text
фон карточки
текст
кнопка
изображения
границы
и другое содержимое
```

То есть нельзя сделать:

```css
.card {
  opacity: 0.5;
}

.card__title {
  opacity: 1;
}
```

и ожидать, что заголовок снова станет полностью непрозрачным относительно внешнего фона.

Вся карточка уже компонуется как полупрозрачная группа.

---

### `opacity: 0` не удаляет элемент

Очень важно:

```css
opacity: 0;
```

делает элемент визуально невидимым, но элемент:

```text
остаётся в DOM
занимает место в layout
может участвовать в событиях
может оставаться фокусируемым
```

Это не то же самое, что:

```css
display: none;
```

---

### `opacity` и Stacking Context

Если:

```css
opacity
```

имеет значение меньше `1`, элемент создаёт новый Stacking Context.

Это важно при работе с:

```css
z-index
```

---

### Главное

```text
opacity
→ прозрачность всего элемента
  вместе с его содержимым
```

---

## 6. Чем `opacity` отличается от цвета с Alpha Channel?

Главное различие:

```text
opacity
→ влияет на весь элемент

alpha channel
→ влияет только на конкретный цвет
```

---

### `opacity`

Например:

```css
.card {
  background-color: black;
  color: white;

  opacity: 0.5;
}
```

Полупрозрачными станут:

```text
чёрный фон
+
белый текст
+
всё содержимое карточки
```

---

### Alpha Channel

```css
.card {
  background-color: rgb(0 0 0 / 50%);
  color: white;
}
```

Теперь:

```text
фон
→ полупрозрачный

текст
→ полностью непрозрачный
```

---

### Визуально

`opacity: 0.5`:

```text
┌──────────────────────┐
│ полупрозрачный фон   │
│ полупрозрачный текст │
└──────────────────────┘
```

Alpha только у фона:

```text
┌──────────────────────┐
│ полупрозрачный фон   │
│ обычный текст        │
└──────────────────────┘
```

---

### Поэтому для прозрачного фона лучше

Не:

```css
.card {
  background: black;
  opacity: 0.5;
}
```

если текст должен оставаться обычным.

А:

```css
.card {
  background-color: rgb(0 0 0 / 50%);
}
```

---

### Сравнение

| Свойство | Что становится прозрачным |
|---|---|
| `opacity` | весь элемент и его визуальное содержимое |
| alpha в цвете | только конкретный цвет |

---

### Главное

```text
нужен прозрачный весь элемент
→ opacity
```

```text
нужен прозрачный только фон / border / shadow
→ цвет с alpha channel
```

---

## 7. Что делает `background-color`?

`background-color` задаёт **цвет фона элемента**.

Например:

```css
.card {
  background-color: white;
}
```

или:

```css
.card {
  background-color: #f5f5f5;
}
```

или:

```css
.card {
  background-color: rgb(255 255 255 / 80%);
}
```

---

### Начальное значение

```css
background-color: transparent;
```

То есть по умолчанию фон элемента прозрачен.

---

### Фон находится под содержимым

Условно:

```text
текст / содержимое
↑
background
↑
то, что находится за элементом
```

---

### `background-color` и `background-image`

Например:

```css
.hero {
  background-color: black;
  background-image: url("hero.jpg");
}
```

`background-image` рисуется над цветом.

То есть:

```text
content
↑
background-image
↑
background-color
```

Если изображение содержит прозрачные участки, через них будет виден:

```text
background-color
```

Если изображение не загрузится, цвет также может выступить запасным фоном.

Поэтому при важном фоновом изображении часто полезно задавать и подходящий:

```css
background-color
```

---

### Фон и Border Box

По умолчанию фон рисуется в области вплоть до внешнего края `border-box`.

То, где именно фон должен обрезаться, можно дополнительно контролировать:

```css
background-clip
```

Например:

```css
background-clip: padding-box;
```

---

### Контраст

Если на фоне находится текст:

```css
.card {
  background-color: #111827;
  color: white;
}
```

важно следить за достаточным контрастом между:

```text
текстом
и
фоном
```

---

### Главное

```text
background-color
→ задаёт цвет фона элемента
```

И:

```text
background-image
→ располагается поверх background-color
```

---

## 8. Как работает `background-image`?

`background-image` задаёт **одно или несколько фоновых изображений элемента**.

Например:

```css
.hero {
  background-image: url("hero.jpg");
}
```

---

### Начальное значение

```css
background-image: none;
```

---

### Это не обязательно файл изображения

`background-image` может принимать:

```css
url("image.jpg")
```

но также:

```css
linear-gradient(...)
```

```css
radial-gradient(...)
```

и другие CSS-изображения.

Например:

```css
.hero {
  background-image:
    linear-gradient(
      rgb(0 0 0 / 50%),
      rgb(0 0 0 / 50%)
    ),
    url("hero.jpg");
}
```

Здесь поверх фотографии находится полупрозрачный градиент.

---

### Несколько фоновых изображений

Можно перечислить несколько слоёв через запятую:

```css
.box {
  background-image:
    url("icon.svg"),
    linear-gradient(blue, purple);
}
```

Очень важно:

> Первый указанный фон находится сверху.

То есть:

```text
url("icon.svg")
↑
linear-gradient(...)
↑
background-color
```

---

### Свойства каждого слоя

Для фонового изображения обычно используются:

```css
background-size
background-position
background-repeat
```

Например:

```css
.hero {
  background-image: url("hero.jpg");
  background-size: cover;
  background-position: center;
  background-repeat: no-repeat;
}
```

---

### `background-image` не влияет на размер элемента

Если изображение имеет:

```text
1920 × 1080
```

это не означает, что элемент автоматически получит такой размер.

Размер самого элемента определяется:

```text
контентом
width
height
min-height
padding
layout
и другими CSS-свойствами
```

Фоновое изображение просто рисуется в области элемента.

---

### Фон не является содержимым

Это важное отличие от:

```html
<img>
```

Если изображение несёт смысловую информацию, обычно лучше использовать:

```html
<img src="..." alt="...">
```

Если изображение декоративное:

```text
фон
узор
декоративная фотография
градиент
```

часто подходит:

```css
background-image
```

---

### Главное

```text
background-image
→ рисует изображение
  на фоне элемента
```

Можно использовать:

```text
url()
gradient()
несколько слоёв
```

---

## 9. Что делают `background-size`, `background-position`, `background-repeat`?

Эти свойства управляют отображением фонового изображения.

---

### `background-size`

Определяет размер фонового изображения.

Например:

```css
background-size: 300px 200px;
```

Здесь:

```text
ширина  = 300px
высота  = 200px
```

---

Можно задать:

```css
background-size: 50%;
```

или:

```css
background-size: auto;
```

или специальные значения:

```css
background-size: cover;
```

```css
background-size: contain;
```

`cover` и `contain` подробно разберём в следующем вопросе.

---

### `background-position`

Определяет положение фонового изображения.

Например:

```css
background-position: center;
```

центрирует его.

Можно использовать:

```css
background-position: top;
background-position: bottom;
background-position: left;
background-position: right;
```

Комбинации:

```css
background-position: top right;
```

```css
background-position: bottom left;
```

---

### Числовые значения

Например:

```css
background-position: 20px 40px;
```

Обычно первое значение относится к горизонтальному направлению, второе — к вертикальному.

Можно использовать проценты:

```css
background-position: 50% 50%;
```

что соответствует центру.

---

### `background-repeat`

Определяет, должно ли фоновое изображение повторяться.

Начальное значение:

```css
background-repeat: repeat;
```

То есть небольшое изображение может замостить весь фон:

```text
★ ★ ★ ★
★ ★ ★ ★
★ ★ ★ ★
```

---

### `no-repeat`

```css
background-repeat: no-repeat;
```

изображение рисуется один раз.

Это очень часто используется вместе с:

```css
background-size: cover;
background-position: center;
```

---

### Другие значения

```css
background-repeat: repeat-x;
```

повторяет по горизонтали.

```css
background-repeat: repeat-y;
```

повторяет по вертикали.

Также существуют:

```text
space
round
```

---

### Типичный фон секции

```css
.hero {
  background-image: url("hero.jpg");
  background-size: cover;
  background-position: center;
  background-repeat: no-repeat;
}
```

Эту комбинацию ты будешь встречать очень часто.

---

### Shorthand `background`

Можно объединить свойства:

```css
.hero {
  background:
    url("hero.jpg")
    center / cover
    no-repeat;
}
```

---

### Главное

```text
background-size
→ размер фонового изображения

background-position
→ положение

background-repeat
→ повторение
```

---

## 10. Чем `cover` отличается от `contain`?

Оба значения используются в:

```css
background-size
```

и сохраняют пропорции фонового изображения.

Но цель у них разная.

---

### `cover`

```css
background-size: cover;
```

означает:

> Увеличь или уменьши изображение так, чтобы оно полностью закрыло область элемента.

При этом часть изображения может выйти за границы и быть обрезана.

---

### Пример

Есть широкий контейнер:

```text
┌────────────────────────────┐
│                            │
│                            │
└────────────────────────────┘
```

и более вертикальная фотография.

При:

```css
background-size: cover;
```

изображение увеличится до тех пор, пока весь контейнер не будет заполнен.

Часть изображения может оказаться за границами:

```text
      image
  ┌───────────────┐
  │ ┌───────────┐ │
  │ │ container │ │
  │ └───────────┘ │
  └───────────────┘
```

---

### `contain`

```css
background-size: contain;
```

означает:

> Покажи всё изображение внутри контейнера.

Изображение полностью помещается.

Но могут остаться незаполненные области:

```text
┌──────────────────────────┐
│      ┌────────────┐      │
│      │   image    │      │
│      └────────────┘      │
└──────────────────────────┘
```

---

### Сравнение

| Значение | Заполняет весь контейнер | Показывает всё изображение |
|---|---:|---:|
| `cover` | Да | Не всегда |
| `contain` | Не всегда | Да |

---

### Когда использовать `cover`?

Например:

```text
hero image
фон секции
обложка
фон карточки
```

когда главное:

> Не должно оставаться пустого пространства.

---

### Когда использовать `contain`?

Например:

```text
логотип
иллюстрация
товарное изображение
```

когда главное:

> Важно увидеть изображение полностью.

---

### `contain` и `background-repeat`

Если написать:

```css
background-size: contain;
```

но оставить стандартное:

```css
background-repeat: repeat;
```

изображение при наличии свободного пространства может повторяться.

Поэтому часто используют:

```css
background-size: contain;
background-repeat: no-repeat;
background-position: center;
```

---

### Главное

```text
cover
→ заполнить весь контейнер
→ часть изображения можно обрезать
```

```text
contain
→ показать всё изображение
→ могут остаться пустые области
```

---

## 11. Как работает `linear-gradient()`?

`linear-gradient()` создаёт **линейный градиент** — плавный переход между двумя или более цветами вдоль прямой линии.

Например:

```css
.box {
  background-image:
    linear-gradient(red, blue);
}
```

По умолчанию переход идёт сверху вниз:

```text
red
↓
↓
↓
blue
```

---

### Градиент является CSS Image

Очень важно:

```css
linear-gradient(...)
```

возвращает изображение, а не обычный цвет.

Поэтому правильно:

```css
background-image:
  linear-gradient(red, blue);
```

или:

```css
background:
  linear-gradient(red, blue);
```

Но не:

```css
background-color:
  linear-gradient(red, blue);
```

---

### Направление

Например:

```css
background:
  linear-gradient(
    to right,
    red,
    blue
  );
```

Переход:

```text
red → → → blue
```

---

Можно использовать:

```css
to left
to top
to bottom
```

и диагонали:

```css
to bottom right
```

---

### Угол

Можно использовать угол:

```css
background:
  linear-gradient(
    45deg,
    red,
    blue
  );
```

Например:

```text
0deg
90deg
180deg
270deg
```

задают разные направления градиента.

---

### Больше двух цветов

```css
background:
  linear-gradient(
    to right,
    red,
    orange,
    yellow,
    green,
    blue
  );
```

---

### Color Stops

Можно указать положение каждого цвета:

```css
background:
  linear-gradient(
    to right,
    red 0%,
    yellow 50%,
    blue 100%
  );
```

Здесь:

```text
0%
→ red

50%
→ yellow

100%
→ blue
```

---

### Резкий переход

Если соседние остановки находятся в одной точке:

```css
background:
  linear-gradient(
    to right,
    black 50%,
    white 50%
  );
```

плавного перехода между ними практически не будет.

Получим две области:

```text
BLACK | WHITE
```

---

### Overlay поверх изображения

Очень распространённый пример:

```css
.hero {
  background-image:
    linear-gradient(
      rgb(0 0 0 / 50%),
      rgb(0 0 0 / 50%)
    ),
    url("hero.jpg");

  background-size: cover;
  background-position: center;
}
```

Получаем:

```text
контент
↑
полупрозрачный gradient
↑
фотография
```

Так можно затемнить фотографию для лучшей читаемости текста.

---

### Главное

```text
linear-gradient()
→ переход цветов
  вдоль прямой линии
```

Можно управлять:

```text
направлением
углом
цветами
положением цветов
```

---

## 12. Как работает `radial-gradient()`?

`radial-gradient()` создаёт **радиальный градиент**.

В отличие от `linear-gradient()`, цвета распространяются не вдоль прямой линии, а **от центральной точки наружу**.

Например:

```css
.box {
  background:
    radial-gradient(
      white,
      blue
    );
}
```

Условно:

```text
      blue
   ↗   ↑   ↖
 blue white blue
   ↘   ↓   ↙
      blue
```

---

### По умолчанию

Центр находится примерно:

```text
50% 50%
```

то есть в центре элемента.

Форма по умолчанию обычно:

```text
ellipse
```

в зависимости от размеров области.

---

### Круг

Можно явно задать:

```css
background:
  radial-gradient(
    circle,
    white,
    blue
  );
```

---

### Эллипс

```css
background:
  radial-gradient(
    ellipse,
    white,
    blue
  );
```

---

### Изменение центра

Например:

```css
background:
  radial-gradient(
    circle at top left,
    white,
    blue
  );
```

Теперь градиент начинается из верхнего левого угла.

---

Можно использовать координаты:

```css
background:
  radial-gradient(
    circle at 30% 40%,
    white,
    blue
  );
```

---

### Несколько цветов

```css
background:
  radial-gradient(
    circle,
    white 0%,
    yellow 30%,
    orange 60%,
    red 100%
  );
```

---

### Размер

Существуют ключевые слова вроде:

```text
closest-side
farthest-side
closest-corner
farthest-corner
```

Они определяют, относительно какой границы рассчитывается конечный размер градиента.

Например:

```css
background:
  radial-gradient(
    circle closest-side,
    white,
    blue
  );
```

Для базовой работы обычно достаточно сначала хорошо понимать:

```text
circle
ellipse
at <position>
color stops
```

---

### Главное различие

```text
linear-gradient()
→ цвета идут вдоль линии
```

```text
radial-gradient()
→ цвета расходятся
  от центральной точки наружу
```

## 13. Что такое `border-radius`?

`border-radius` скругляет углы элемента.

Например:

```css
.card {
  border-radius: 16px;
}
```

Получаем:

```text
без border-radius

┌──────────────┐
│              │
└──────────────┘


с border-radius

╭──────────────╮
│              │
╰──────────────╯
```

---

### Наличие `border` не обязательно

Несмотря на название:

```text
border-radius
```

элементу не обязательно иметь:

```css
border
```

Например:

```css
.button {
  background-color: blue;
  border-radius: 12px;
}
```

работает без видимой границы.

---

### Одно значение

```css
border-radius: 20px;
```

применяет одинаковое скругление ко всем четырём углам.

---

### Четыре значения

```css
border-radius:
  10px 20px 30px 40px;
```

порядок:

```text
top-left
top-right
bottom-right
bottom-left
```

То есть по часовой стрелке.

---

### Можно задавать отдельные углы

```css
border-top-left-radius: 20px;
border-top-right-radius: 20px;
border-bottom-right-radius: 20px;
border-bottom-left-radius: 20px;
```

---

### Проценты

Можно использовать:

```css
border-radius: 50%;
```

Это особенно важно для кругов и эллипсов.

---

### Горизонтальный и вертикальный радиус

Можно задавать два радиуса угла:

```css
border-top-right-radius: 20px 40px;
```

Первый относится к горизонтальному радиусу, второй — к вертикальному.

Существует и расширенный синтаксис через `/`:

```css
border-radius:
  50% / 30%;
```

Это позволяет создавать более сложные овальные формы.

---

### `border-radius` и содержимое

Скругление применяется к границам и фону самого элемента.

Но дочерний элемент, который выходит за его границы, не обязательно автоматически будет обрезан по радиусу.

Например, если внутри карточки находится изображение и нужно жёстко обрезать всё содержимое по форме карточки, иногда используют:

```css
.card {
  border-radius: 20px;
  overflow: hidden;
}
```

Но `overflow: hidden` следует добавлять только тогда, когда обрезание действительно нужно, потому что оно может также обрезать:

```text
тени
выпадающие элементы
декор
```

---

### Главное

```text
border-radius
→ скругляет углы элемента
```

И не требует наличия видимого:

```css
border
```

---

## 14. Как создать круг с помощью CSS?

Чтобы получить круг, нужны две основные вещи:

```text
одинаковая ширина и высота
+
border-radius: 50%
```

Например:

```css
.circle {
  width: 100px;
  height: 100px;

  border-radius: 50%;
  background-color: blue;
}
```

Получаем:

```text
   ●
```

---

### Современный вариант через `aspect-ratio`

Можно написать:

```css
.circle {
  width: 100px;
  aspect-ratio: 1;

  border-radius: 50%;
  background-color: blue;
}
```

`aspect-ratio: 1` означает:

```text
ширина : высота
=
1 : 1
```

То есть элемент квадратный.

А:

```css
border-radius: 50%;
```

превращает квадрат в круг.

---

### Если ширина и высота разные

Например:

```css
.ellipse {
  width: 200px;
  height: 100px;

  border-radius: 50%;
}
```

получится не круг, а эллипс:

```text
   _________
 /           \
|             |
 \___________/
```

Поэтому важно:

```text
width = height
```

---

### Круглое изображение

Например, аватар:

```css
.avatar {
  width: 80px;
  aspect-ratio: 1;

  border-radius: 50%;
  object-fit: cover;
}
```

HTML:

```html
<img
  class="avatar"
  src="avatar.jpg"
  alt="User"
/>
```

`object-fit: cover` позволяет фотографии заполнить круг без искажения пропорций.

---

### Главное

```css
.circle {
  width: 100px;
  aspect-ratio: 1;
  border-radius: 50%;
}
```

или:

```css
.circle {
  width: 100px;
  height: 100px;
  border-radius: 50%;
}
```

## 15. Что делает `box-shadow`?

`box-shadow` добавляет одну или несколько теней вокруг области элемента.

Например:

```css
.card {
  box-shadow:
    0 8px 24px
    rgb(0 0 0 / 15%);
}
```

---

### Основной синтаксис

```css
box-shadow:
  offset-x
  offset-y
  blur
  spread
  color;
```

Например:

```css
box-shadow:
  10px 20px 30px 5px
  rgb(0 0 0 / 20%);
```

---

### Первое значение — X

```text
10px
```

задаёт горизонтальное смещение.

Положительное:

```text
→ вправо
```

Отрицательное:

```text
← влево
```

---

### Второе значение — Y

```text
20px
```

задаёт вертикальное смещение.

Положительное:

```text
↓ вниз
```

Отрицательное:

```text
↑ вверх
```

---

### Blur

Третье значение:

```text
30px
```

— радиус размытия.

Например:

```css
box-shadow:
  0 0 30px black;
```

Чем больше значение, тем мягче и шире тень.

---

### Spread

Четвёртое значение:

```text
5px
```

расширяет или уменьшает размер тени перед размытием.

Например:

```css
box-shadow:
  0 0 20px 10px
  rgb(0 0 0 / 20%);
```

Положительный `spread` увеличивает область тени.

Отрицательный:

```css
box-shadow:
  0 10px 20px -10px
  rgb(0 0 0 / 30%);
```

может уменьшить её.

---

### Цвет

Например:

```css
box-shadow:
  0 4px 20px
  rgb(0 0 0 / 10%);
```

Для естественных теней обычно используют цвет с alpha channel.

Например:

```text
10%
15%
20%
```

непрозрачности.

---

### `inset`

По умолчанию тень находится снаружи.

Но:

```css
box-shadow:
  inset 0 0 10px
  rgb(0 0 0 / 20%);
```

создаёт внутреннюю тень.

Условно:

```text
обычный box-shadow
→ тень наружу

inset
→ тень внутрь
```

---

### Несколько теней

Можно перечислить через запятую:

```css
.card {
  box-shadow:
    0 2px 4px rgb(0 0 0 / 10%),
    0 8px 24px rgb(0 0 0 / 12%);
}
```

Тени накладываются друг на друга.

Это позволяет создавать более естественный эффект глубины.

---

### `box-shadow` не меняет Layout

Тень визуально выходит за границы элемента, но не резервирует дополнительное место.

Например:

```css
box-shadow:
  0 20px 50px black;
```

не заставляет соседний элемент автоматически отодвинуться ещё на `50px`.

То есть тень:

```text
рисуется
```

но не участвует в обычном расчёте размеров Box Model.

---

### `border-radius`

Если элемент имеет:

```css
border-radius: 20px;
```

его `box-shadow` также учитывает скруглённую форму его коробки.

---

### Главное

```text
box-shadow

offset-x
offset-y
blur
spread
color
```

Например:

```css
box-shadow:
  0 8px 24px
  rgb(0 0 0 / 15%);
```

Для внутренней тени:

```css
box-shadow:
  inset 0 0 10px
  rgb(0 0 0 / 20%);
```

---

## 16. Чем `box-shadow` отличается от `filter: drop-shadow()`?

Оба создают тень, но рассчитывают её **от разных форм**.

Главное различие:

```text
box-shadow
→ ориентируется на CSS-box элемента

drop-shadow()
→ ориентируется на видимую форму
  отрисованного элемента
```

---

### `box-shadow`

Например:

```css
.logo {
  box-shadow:
    0 8px 20px
    rgb(0 0 0 / 30%);
}
```

Тень строится вокруг коробки элемента.

Если PNG имеет прозрачный фон:

```text
┌────────────────────┐
│       ★            │
│                    │
└────────────────────┘
```

`box-shadow` ориентируется прежде всего на прямоугольную CSS-область изображения:

```text
████████████████████
█       ★          █
████████████████████
```

---

### `drop-shadow()`

```css
.logo {
  filter:
    drop-shadow(
      0 8px 20px
      rgb(0 0 0 / 30%)
    );
}
```

`drop-shadow()` использует альфа-маску отрисованного изображения.

То есть для прозрачного PNG или SVG он может повторять форму непрозрачных частей:

```text
    ★
   shadow
```

а не просто рисовать прямоугольную тень вокруг коробки.

---

### Особенно заметно на PNG и SVG

Представим PNG звезды с прозрачным фоном.

С:

```css
box-shadow
```

тень связана с коробкой элемента.

С:

```css
filter: drop-shadow(...)
```

тень может следовать контуру самой звезды.

Поэтому:

```text
PNG с прозрачностью
SVG
нерегулярная форма
```

— типичные случаи для `drop-shadow()`.

---

### Синтаксис `drop-shadow()`

```css
filter:
  drop-shadow(
    10px 10px 5px black
  );
```

Основные параметры:

```text
offset-x
offset-y
blur
color
```

---

### У `drop-shadow()` нет Spread

В отличие от:

```css
box-shadow:
  0 0 20px 10px black;
```

где:

```text
10px
→ spread
```

у:

```css
drop-shadow()
```

параметра `spread` нет.

---

### У `drop-shadow()` нет `inset`

Можно написать:

```css
box-shadow:
  inset 0 0 20px black;
```

Но:

```css
filter:
  drop-shadow(inset ...);
```

не является допустимым аналогом.

---

### Несколько теней

`box-shadow`:

```css
box-shadow:
  0 4px 10px black,
  0 10px 30px red;
```

Можно задавать несколько теней через запятую.

Для `filter` можно последовательно применять несколько функций:

```css
filter:
  drop-shadow(0 4px 10px black)
  drop-shadow(0 10px 20px red);
```

---

### Сравнение

| Характеристика | `box-shadow` | `drop-shadow()` |
|---|---|---|
| Основа формы | CSS-box | отрисованная альфа-маска |
| Хорош для карточек | Да | Иногда |
| Хорош для прозрачных PNG/SVG | Ограниченно | Да |
| `spread` | Да | Нет |
| `inset` | Да | Нет |
| Используется через | `box-shadow` | `filter` |

### Когда использовать `box-shadow`?

Например:

```text
карточка
кнопка
модальное окно
панель
обычный прямоугольный блок
```

```css

  box-shadow:
    0 8px 24px
    rgb(0 0 0 / 12%);
}
```

---

### Когда использовать `drop-shadow()`?

Например:

```text
SVG-иконка
PNG с прозрачным фоном
логотип сложной формы
```

```css
.logo {
  filter:
    drop-shadow(
      0 6px 10px
      rgb(0 0 0 / 30%)
    );
}
```

### Главное

```text
box-shadow
→ тень CSS-box
```

```text

→ тень по видимой форме
  отрисованного элемента
```

Кроме того:

```text

→ поддерживает spread и inset

drop-shadow()
→ не поддерживает
```
