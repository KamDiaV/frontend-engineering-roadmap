# IX. CSS Grid

## 1. Что такое CSS Grid?

**CSS Grid** — модель CSS-раскладки, предназначенная для размещения элементов в виде сетки из **строк и столбцов**.

Grid особенно удобен для двумерных раскладок, когда нужно одновременно контролировать:

```text
строки
+
столбцы
```

Например:

```html
<div class="grid">
  <div>1</div>
  <div>2</div>
  <div>3</div>
  <div>4</div>
  <div>5</div>
  <div>6</div>
</div>
```

```css
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
}
```

Получаем:

```text
┌─────┬─────┬─────┐
│  1  │  2  │  3  │
├─────┼─────┼─────┤
│  4  │  5  │  6  │
└─────┴─────┴─────┘
```

Элемент:

```html
<div class="grid">
```

становится **grid-контейнером**.

Его непосредственные дочерние элементы становятся **grid-элементами**.

---

### Что позволяет Grid?

С помощью Grid можно:

- создавать строки и столбцы;
- задавать размеры строк и столбцов;
- размещать элементы по линиям сетки;
- растягивать элементы на несколько ячеек;
- создавать именованные области;
- автоматически создавать дополнительные строки и столбцы;
- задавать промежутки между элементами;
- выравнивать элементы;
- создавать адаптивные сетки;
- перекрывать элементы друг другом.

Например:

```css
.layout {
  display: grid;
  grid-template-columns: 250px 1fr;
}
```

может создать:

```text
┌───────────┬──────────────────────┐
│ Sidebar   │ Main                 │
│           │                      │
└───────────┴──────────────────────┘
```

---

### Почему Grid считается двумерной моделью?

Потому что он позволяет одновременно управлять:

```text
горизонтальным направлением
+
вертикальным направлением
```

То есть можно явно сказать:

```css
grid-template-columns: 200px 1fr 1fr;
grid-template-rows: 100px 300px;
```

и получить систему:

```text
3 столбца
×
2 строки
```

Именно двумерная раскладка — одно из главных отличий Grid от Flexbox. Спецификация CSS Grid описывает Grid как модель, оптимизированную для управления расположением элементов сразу в двух измерениях.

---

## 2. Чем Grid отличается от Flexbox?

Главное различие:

```text
Flexbox
→ в первую очередь одномерная раскладка

Grid
→ двумерная раскладка
```

---

### Flexbox

Flexbox в первую очередь работает вдоль одной главной оси.

Например:

```css
.container {
  display: flex;
}
```

получаем:

```text
A → B → C
```

Можно использовать перенос:

```css
flex-wrap: wrap;
```

и получить:

```text
A B C
D E F
```

Но каждая flex-линия рассчитывается в значительной степени самостоятельно.

Например:

```text
первая строка:
A   B   C

вторая строка:
D E F
```

Элементы второй строки не обязаны образовывать те же вертикальные столбцы, что элементы первой.

---

### Grid

Grid создаёт настоящую систему строк и столбцов:

```css
.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
}
```

```text
Column 1  Column 2  Column 3
   ↓         ↓         ↓

┌───────┬───────┬───────┐
│   A   │   B   │   C   │
├───────┼───────┼───────┤
│   D   │   E   │   F   │
└───────┴───────┴───────┘
```

Столбцы первой и второй строки образуют одну общую систему.

---

### Ещё одно важное различие

Flexbox часто отталкивается от **содержимого**.

Например:

```text
есть элементы
↓
Flexbox распределяет их
```

Grid часто отталкивается от **структуры сетки**:

```text
сначала создаём сетку
↓
потом размещаем в неё элементы
```

Это не абсолютное правило, но полезная модель для понимания.

---

### Сравнение

| Характеристика | Flexbox | Grid |
|---|---|---|
| Основная модель | Одномерная | Двумерная |
| Главный контроль | Одна ось | Строки и столбцы |
| Хорош для компонентов | Да | Да |
| Хорош для сложной сетки страницы | Иногда | Особенно хорошо |
| Элементы удобно распределять по свободному пространству | Да | Да |
| Строгое выравнивание строк и колонок | Ограничено | Да |
| Размещение по конкретным линиям | Нет | Да |

Grid и Flexbox не являются конкурентами, один из которых должен заменить другой. Спецификация прямо рассматривает их как дополняющие друг друга инструменты.

---

## 3. Когда лучше использовать Grid, а когда Flexbox?

Упрощённое правило:

```text
нужно управлять в основном одним направлением
→ Flexbox

нужно управлять строками и столбцами одновременно
→ Grid
```

---

### Flexbox хорошо подходит для:

Навигации:

```text
Logo   Home   Shop   Contacts
```

Кнопок:

```text
[Icon] [Text]
```

Групп элементов:

```text
Avatar   Name   Button
```

Центрирования:

```css
.container {
  display: flex;
  justify-content: center;
  align-items: center;
}
```

Распределения элементов вдоль одной оси:

```css
.header {
  display: flex;
  justify-content: space-between;
}
```

---

### Grid хорошо подходит для:

Сетки карточек:

```text
┌─────┬─────┬─────┐
│     │     │     │
├─────┼─────┼─────┤
│     │     │     │
└─────┴─────┴─────┘
```

Основной структуры страницы:

```text
┌───────────────────────────┐
│ Header                    │
├──────────┬────────────────┤
│ Sidebar  │ Main           │
├──────────┴────────────────┤
│ Footer                    │
└───────────────────────────┘
```

Галерей:

```text
┌───────┬───────┐
│       │       │
├───────┼───────┤
│       │       │
└───────┴───────┘
```

Сложных макетов, где элементы занимают несколько строк или столбцов:

```text
┌───────────────┬───────┐
│               │   B   │
│       A       ├───────┤
│               │   C   │
└───────────────┴───────┘
```

---

### Не нужно выбирать только один

Например:

```css
.page {
  display: grid;
}
```

может управлять всей структурой страницы.

А внутри:

```css
.header {
  display: flex;
}
```

Flexbox может управлять элементами шапки.

То есть:

```text
Grid
→ большая структура

Flexbox
→ расположение элементов внутри компонента
```

— очень распространённая комбинация.

---

## 4. Как создать grid-контейнер?

Чтобы создать Grid, родителю задают:

```css
.container {
  display: grid;
}
```

Например:

```html
<div class="container">
  <div>A</div>
  <div>B</div>
  <div>C</div>
</div>
```

```css
.container {
  display: grid;
}
```

Теперь:

```text
.container
→ grid-контейнер

A, B, C
→ grid-элементы
```

Grid-элементами становятся **непосредственные дети** контейнера.

---

### Обычно затем определяют сетку

Например:

```css
.container {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
}
```

Создаются три столбца:

```text
┌─────────┬─────────┬─────────┐
│    A    │    B    │    C    │
└─────────┴─────────┴─────────┘
```

---

### `display: inline-grid`

Существует также:

```css
display: inline-grid;
```

Внутри элемент остаётся grid-контейнером, но сам контейнер участвует во внешней раскладке как строчный элемент.

То есть:

```css
display: grid;
```

и:

```css
display: inline-grid;
```

создают Grid внутри, но отличаются внешним поведением самого контейнера.

---

## 5. Что делают `grid-template-columns` и `grid-template-rows`?

Эти свойства определяют **явные столбцы и строки Grid**.

```css
grid-template-columns
```

задаёт столбцы.

```css
grid-template-rows
```

задаёт строки.

---

### Пример столбцов

```css
.container {
  display: grid;
  grid-template-columns: 200px 300px 100px;
}
```

Получаем три столбца:

```text
200px      300px        100px
  ↓          ↓            ↓

┌────────┬────────────┬──────┐
│        │            │      │
└────────┴────────────┴──────┘
```

---

### Можно смешивать разные единицы

Например:

```css
grid-template-columns: 200px 1fr 2fr;
```

Первый столбец:

```text
200px
```

А оставшееся пространство распределяется между:

```text
1fr
2fr
```

---

### Пример строк

```css
.container {
  display: grid;
  grid-template-rows: 100px 200px;
}
```

Получаем:

```text
┌──────────────────────┐
│       100px          │
├──────────────────────┤
│                      │
│       200px          │
│                      │
└──────────────────────┘
```

---

### Вместе

```css
.container {
  display: grid;

  grid-template-columns: 200px 1fr;
  grid-template-rows: 100px 300px;
}
```

Создаётся:

```text
2 столбца
×
2 строки
```

```text
          200px          1fr
            ↓             ↓

       ┌───────────┬────────────┐
100px  │           │            │
       ├───────────┼────────────┤
300px  │           │            │
       │           │            │
       └───────────┴────────────┘
```

---

### Что такое явная сетка?

Строки и столбцы, которые разработчик явно создаёт через:

```css
grid-template-columns
grid-template-rows
grid-template-areas
```

образуют **Explicit Grid (явную сетку)**.

---

## 6. Что такое Grid Track?

**Grid Track (дорожка сетки)** — пространство между двумя соседними линиями Grid.

Grid Track может быть:

```text
столбцом
или
строкой
```

Например:

```css
grid-template-columns: 200px 1fr 1fr;
```

создаёт три дорожки-столбца:

```text
line 1    line 2    line 3    line 4
  │          │         │          │
  │  200px   │   1fr   │   1fr    │
  │          │         │          │
```

Каждое пространство между двумя линиями:

```text
line 1 → line 2
line 2 → line 3
line 3 → line 4
```

— отдельный Grid Track.

---

### Дорожки строк

```css
grid-template-rows: 100px 200px;
```

создаёт:

```text
line 1
────────────

   100px

────────────
line 2

   200px

────────────
line 3
```

То есть две дорожки строк.

---

### Главное

```text
Grid Track
=
пространство между
двумя соседними grid lines
```

Спецификация прямо определяет Grid Track как общий термин для строки или столбца Grid.

---

## 7. Что такое Grid Line?

**Grid Line (линия сетки)** — горизонтальная или вертикальная линия, разделяющая дорожки Grid.

Например:

```css
grid-template-columns: 1fr 1fr 1fr;
```

создаёт три столбца.

Но линий будет **четыре**:

```text
  1         2         3         4
  │         │         │         │
  │ column  │ column  │ column  │
  │    1    │    2    │    3    │
```

Очень важно:

```text
3 столбца
→ 4 вертикальные линии
```

А:

```text
2 строки
→ 3 горизонтальные линии
```

---

### Линии можно использовать для размещения элементов

Например:

```css
.item {
  grid-column: 1 / 3;
}
```

означает:

```text
начни с линии 1
закончи на линии 3
```

Элемент займёт два столбца:

```text
line 1      line 2      line 3
  │            │           │
  ├────────────────────────┤
  │          item          │
  └────────────────────────┘
```

---

### Отрицательная нумерация

У линий явной сетки можно использовать отрицательные номера.

Например:

```css
.item {
  grid-column: 1 / -1;
}
```

`-1` означает последнюю линию явной сетки.

Поэтому элемент займёт всю ширину сетки:

```text
первая линия
↓
┌─────────────────────────────┐
│            item             │
└─────────────────────────────┘
                              ↑
                     последняя линия
```

Это очень распространённый приём.

Положительные номера линий считаются от начала явной сетки, отрицательные — от её конца.

---

## 8. Что такое Grid Cell?

**Grid Cell (ячейка Grid)** — пространство на пересечении одной строки и одного столбца.

Это наименьшая единица сетки, в которую можно поместить grid-элемент.

Например:

```text
┌─────────┬─────────┐
│ cell 1  │ cell 2  │
├─────────┼─────────┤
│ cell 3  │ cell 4  │
└─────────┴─────────┘
```

---

### Ячейка ограничена четырьмя линиями

Например:

```text
       column line 1   column line 2
              ↓              ↓

row line 1 →  ┌──────────────┐
              │              │
              │     cell     │
              │              │
row line 2 →  └──────────────┘
```

Ячейка находится между:

```text
двумя вертикальными линиями
+
двумя горизонтальными линиями
```

Спецификация определяет Grid Cell как пересечение одной строки и одного столбца.

---

## 9. Что такое Grid Area?

**Grid Area (область Grid)** — прямоугольная область, состоящая из одной или нескольких соседних ячеек Grid.

Например:

```text
┌─────┬─────┬─────┐
│  A  │  A  │     │
├─────┼─────┼─────┤
│  A  │  A  │     │
└─────┴─────┴─────┘
```

Область `A` занимает:

```text
2 строки
×
2 столбца
```

---

### Одна ячейка тоже может быть областью

Например:

```text
┌─────────┐
│    A    │
└─────────┘
```

Это тоже Grid Area.

---

### Область ограничивается четырьмя линиями

У неё есть:

```text
верхняя линия
правая линия
нижняя линия
левая линия
```

---

### Области можно задавать разными способами

Через линии:

```css
.item {
  grid-column: 1 / 3;
  grid-row: 1 / 3;
}
```

или через именованные области:

```css
.item {
  grid-area: main;
}
```

Спецификация определяет Grid Area как прямоугольную область из одной или нескольких соседних ячеек.

---

## 10. Что делает единица `fr`?

`fr` — специальная гибкая единица Grid.

Она используется для распределения **оставшегося свободного пространства между дорожками**.

Например:

```css
.container {
  display: grid;
  grid-template-columns: 1fr 1fr;
}
```

Получаем две гибкие колонки:

```text
┌──────────────┬──────────────┐
│      1fr     │      1fr     │
└──────────────┴──────────────┘
```

При обычных условиях они поделят доступное пространство поровну.

---

### `1fr 2fr`

```css
grid-template-columns: 1fr 2fr;
```

Сумма коэффициентов:

```text
1 + 2 = 3
```

Первая дорожка получает одну долю.

Вторая — две доли.

Условно:

```text
┌──────────┬────────────────────┐
│   1fr    │        2fr         │
└──────────┴────────────────────┘
```

---

### Фиксированный столбец + `fr`

```css
grid-template-columns: 200px 1fr;
```

Если контейнер:

```text
1000px
```

то сначала учитывается:

```text
200px
```

Остаётся:

```text
800px
```

И эта область достаётся гибкой дорожке `1fr`.

---

### `fr` — не процент

Например:

```css
grid-template-columns: 200px 1fr 1fr;
```

означает:

```text
сначала 200px
↓
затем оставшееся пространство
делится между двумя 1fr
```

А проценты рассчитываются относительно размера контейнера напрямую.

---

### Важный нюанс

Запись:

```css
grid-template-columns: 1fr 1fr;
```

не всегда означает, что любой контент гарантированно сожмётся ровно до половины контейнера.

У дорожек Grid есть автоматические минимальные размеры, зависящие от содержимого.

Поэтому иногда длинный контент может вызвать переполнение.

В таких случаях часто используется:

```css
grid-template-columns:
  minmax(0, 1fr)
  minmax(0, 1fr);
```

Упрощённо:

```text
1fr
→ гибкая дорожка,
  но её автоматический минимум
  может учитывать содержимое

minmax(0, 1fr)
→ разрешает дорожке
  уменьшаться вплоть до 0
```

---

### Главное

```text
fr
=
доля гибкого свободного пространства Grid
```

---

## 11. Как работает `repeat()`?

Функция:

```css
repeat()
```

позволяет не повторять одинаковые размеры дорожек вручную.

Например:

```css
grid-template-columns: 1fr 1fr 1fr;
```

можно записать:

```css
grid-template-columns: repeat(3, 1fr);
```

Результат одинаковый:

```text
3 столбца по 1fr
```

---

### Синтаксис

```css
repeat(количество, повторяемая-часть)
```

Например:

```css
repeat(4, 200px)
```

означает:

```css
200px 200px 200px 200px
```

---

### Можно повторять несколько дорожек

Например:

```css
grid-template-columns:
  repeat(2, 100px 1fr);
```

эквивалентно:

```css
grid-template-columns:
  100px 1fr 100px 1fr;
```

---

### Можно комбинировать

```css
grid-template-columns:
  200px repeat(3, 1fr);
```

Получаем:

```text
200px | 1fr | 1fr | 1fr
```

---

### Автоматическое повторение

Вместо конкретного числа можно использовать:

```text
auto-fill
auto-fit
```

Например:

```css
grid-template-columns:
  repeat(auto-fit, minmax(250px, 1fr));
```

Это позволяет создавать адаптивную сетку, количество колонок которой зависит от доступной ширины.

`repeat()` предназначен именно для компактной записи повторяющихся дорожек и поддерживает как фиксированное число повторений, так и автоматическое повторение.

---

## 12. Как работает `minmax()`?

Функция:

```css
minmax()
```

задаёт **минимальный и максимальный размер дорожки Grid**.

Синтаксис:

```css
minmax(min, max)
```

Например:

```css
grid-template-columns:
  minmax(200px, 1fr);
```

означает:

```text
минимум
→ 200px

максимум
→ 1fr
```

То есть дорожка может увеличиваться, но не должна становиться меньше `200px` в рамках этого определения.

---

### Пример со строками

```css
.container {
  display: grid;
  grid-auto-rows: minmax(100px, auto);
}
```

Это означает:

```text
минимальная высота строки
→ 100px

максимальная
→ зависит от содержимого
```

Если текста мало:

```text
100px
```

Если содержимого больше:

```text
строка может увеличиться
```

---

### Очень распространённая комбинация

```css
grid-template-columns:
  repeat(auto-fit, minmax(250px, 1fr));
```

Здесь каждая колонка:

```text
не должна быть меньше 250px
```

но может увеличиваться:

```text
до своей доли свободного пространства
```

---

### `minmax(0, 1fr)`

Очень полезная запись:

```css
grid-template-columns:
  minmax(0, 1fr)
  minmax(0, 1fr);
```

Она позволяет гибким дорожкам сжиматься сильнее, чем при обычном автоматическом минимуме `1fr`.

Это особенно полезно, если внутри есть:

- длинный текст;
- большие изображения;
- элементы с `white-space: nowrap`;
- другие плохо сжимающиеся компоненты.

---

### Главное

```text
minmax()
=
задаёт диапазон размера дорожки
```

```css
minmax(200px, 1fr)
```

означает:

```text
не меньше 200px
+
можно увеличиваться до гибкой доли
```

MDN использует `minmax()` именно для задания диапазона допустимых размеров дорожки.

---

## 13. Чем `auto-fill` отличается от `auto-fit`?

Оба значения используются внутри:

```css
repeat()
```

и позволяют браузеру автоматически определить, сколько дорожек помещается в контейнере.

Например:

```css
grid-template-columns:
  repeat(auto-fill, minmax(200px, 1fr));
```

или:

```css
grid-template-columns:
  repeat(auto-fit, minmax(200px, 1fr));
```

---

### Что общего?

Оба пытаются создать столько колонок, сколько помещается.

Например, при широкой области:

```text
┌─────┬─────┬─────┬─────┐
│     │     │     │     │
└─────┴─────┴─────┴─────┘
```

При уменьшении контейнера количество колонок уменьшается:

```text
┌────────┬────────┐
│        │        │
├────────┼────────┤
│        │        │
└────────┴────────┘
```

---

### `auto-fill`

```css
repeat(auto-fill, minmax(200px, 1fr))
```

создаёт столько дорожек, сколько может поместиться, **включая потенциально пустые дорожки**.

Например, в контейнер помещаются четыре колонки, но элементов только два:

```text
┌──────┬──────┬──────┬──────┐
│  A   │  B   │      │      │
└──────┴──────┴──────┴──────┘
```

Пустые дорожки продолжают существовать.

---

### `auto-fit`

```css
repeat(auto-fit, minmax(200px, 1fr))
```

сначала работает похожим образом, но затем **схлопывает пустые автоматически созданные дорожки**.

Если элементов только два:

```text
┌──────────────┬──────────────┐
│      A       │      B       │
└──────────────┴──────────────┘
```

Свободное пространство может перейти существующим дорожкам.

---

### Главное различие

```text
auto-fill
→ заполняет сетку дорожками
→ пустые дорожки сохраняются
```

```text
auto-fit
→ тоже создаёт подходящее количество дорожек
→ пустые дорожки затем схлопываются
→ существующие элементы могут растянуться
```

Именно схлопывание пустых повторяемых дорожек является ключевым отличием `auto-fit` от `auto-fill`.

---

### Когда разница заметна?

Когда:

```text
контейнер достаточно широкий
+
элементов меньше,
чем потенциальных колонок
```

Если элементов достаточно для заполнения всех колонок, `auto-fill` и `auto-fit` могут выглядеть одинаково.

---

### Частый адаптивный паттерн

```css
.cards {
  display: grid;

  grid-template-columns:
    repeat(auto-fit, minmax(250px, 1fr));

  gap: 24px;
}
```

Это позволяет часто создавать адаптивную сетку без медиазапросов.

---

## 14. Что делает `gap` в Grid?

`gap` задаёт промежутки между строками и столбцами Grid.

Например:

```css
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}
```

Получаем:

```text
┌─────┐ 20px ┌─────┐ 20px ┌─────┐
│  A  │      │  B  │      │  C  │
└─────┘      └─────┘      └─────┘
```

---

### `row-gap`

```css
row-gap: 20px;
```

задаёт расстояние между строками.

---

### `column-gap`

```css
column-gap: 30px;
```

задаёт расстояние между столбцами.

---

### `gap`

Это сокращение:

```css
gap: 20px 30px;
```

эквивалентно:

```css
row-gap: 20px;
column-gap: 30px;
```

То есть:

```text
первое значение
→ строки

второе значение
→ столбцы
```

---

### Одно значение

```css
gap: 24px;
```

задаёт одинаковый промежуток:

```text
между строками
+
между столбцами
```

---

### `gap` не создаёт внешний отступ контейнера

Например:

```css
gap: 20px;
```

создаёт пространство **между дорожками**, но не добавляет автоматически:

```text
20px слева
20px справа
20px сверху
20px снизу
```

Для этого нужен:

```css
padding
```

или другой подход.

---

## 15. Как позиционировать элемент по Grid Lines?

Grid позволяет явно указать, между какими линиями должен находиться элемент.

Например:

```css
.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
}
```

Создаются:

```text
4 вертикальные линии
```

```text
1       2       3       4
│       │       │       │
│ col 1 │ col 2 │ col 3 │
```

---

### `grid-column-start`

```css
.item {
  grid-column-start: 1;
}
```

задаёт начальную вертикальную линию.

---

### `grid-column-end`

```css
.item {
  grid-column-end: 3;
}
```

задаёт конечную линию.

---

### Сокращение `grid-column`

Вместо:

```css
.item {
  grid-column-start: 1;
  grid-column-end: 3;
}
```

можно:

```css
.item {
  grid-column: 1 / 3;
}
```

Элемент займёт:

```text
столбец 1
+
столбец 2
```

---

### Для строк

Аналогично:

```css
.item {
  grid-row: 1 / 3;
}
```

---

### Всё вместе

```css
.item {
  grid-column: 1 / 3;
  grid-row: 1 / 3;
}
```

Элемент займёт область:

```text
┌───────┬───────┬───────┐
│       ITEM     │       │
├─────────────── ┤       │
│       ITEM     │       │
└───────┴───────┴───────┘
```

---

### `span`

Можно указать количество дорожек:

```css
.item {
  grid-column: span 2;
}
```

означает:

```text
занять 2 столбца
```

Например:

```css
grid-column: 2 / span 2;
```

означает:

```text
начать на линии 2
+
занять две дорожки
```

---

### На всю ширину

Очень распространённая запись:

```css
.item {
  grid-column: 1 / -1;
}
```

означает:

```text
от первой линии
до последней линии явной сетки
```

Grid предоставляет отдельные свойства `grid-column-*` и `grid-row-*`, а также их сокращённые формы именно для такого размещения.

---

## 16. Что такое Named Grid Areas?

**Named Grid Areas (именованные области Grid)** позволяют давать областям сетки понятные имена.

Например, вместо:

```css
.header {
  grid-column: 1 / 3;
  grid-row: 1;
}
```

можно создать область:

```text
header
```

и написать:

```css
.header {
  grid-area: header;
}
```

---

### Пример структуры страницы

Представим:

```text
┌──────────────────────┐
│ Header               │
├─────────┬────────────┤
│ Sidebar │ Main       │
├─────────┴────────────┤
│ Footer               │
└──────────────────────┘
```

Мы можем назвать области:

```text
header
sidebar
main
footer
```

---

### Зачем это нужно?

Так CSS становится более похожим на схему страницы:

```css
grid-template-areas:
  "header  header"
  "sidebar main"
  "footer  footer";
```

Эта запись визуально показывает структуру макета.

---

## 17. Как работает `grid-template-areas`?

`grid-template-areas` позволяет описать сетку с помощью именованных областей.

Например:

```css
.layout {
  display: grid;

  grid-template-columns: 250px 1fr;

  grid-template-areas:
    "header  header"
    "sidebar main"
    "footer  footer";
}
```

Получаем:

```text
┌─────────────────────────────┐
│ header      header          │
├───────────┬─────────────────┤
│ sidebar   │ main            │
├───────────┴─────────────────┤
│ footer      footer          │
└─────────────────────────────┘
```

---

### Затем элементы связываются с областями

```css
.header {
  grid-area: header;
}

.sidebar {
  grid-area: sidebar;
}

.main {
  grid-area: main;
}

.footer {
  grid-area: footer;
}
```

---

### Каждая строка строки CSS — строка Grid

Например:

```css
grid-template-areas:
  "a a"
  "b c";
```

означает:

```text
┌─────┬─────┐
│  a  │  a  │
├─────┼─────┤
│  b  │  c  │
└─────┴─────┘
```

---

### Точка означает пустую область

Например:

```css
grid-template-areas:
  "header header"
  ".      main";
```

Точка:

```text
.
```

означает, что соответствующая ячейка не входит в именованную область.

---

### Область должна быть прямоугольной

Например, такую форму создать нельзя:

```text
A A
A B
```

если `A` должна быть одной именованной областью неправильной Г-образной формы.

Grid Area должна быть прямоугольником.

---

### Можно одновременно задавать размеры

```css
.layout {
  display: grid;

  grid-template-columns: 250px 1fr;
  grid-template-rows: auto 1fr auto;

  grid-template-areas:
    "header  header"
    "sidebar main"
    "footer  footer";
}
```

Спецификация определяет `grid-template-areas` вместе с `grid-template-columns` и `grid-template-rows` как часть явной сетки.

---

## 18. Что такое Implicit Grid?

**Implicit Grid (неявная сетка)** — строки или столбцы, которые браузер создаёт автоматически, когда элементов не помещается в явно созданную сетку или элемент размещён за её пределами.

---

### Явная сетка

Например:

```css
.container {
  display: grid;

  grid-template-columns:
    repeat(3, 1fr);

  grid-template-rows:
    100px 100px;
}
```

Мы явно создали:

```text
3 столбца
×
2 строки
```

Это:

```text
Explicit Grid
```

---

### Но элементов больше

Допустим:

```html
<div class="container">
  <div>1</div>
  <div>2</div>
  <div>3</div>
  <div>4</div>
  <div>5</div>
  <div>6</div>
  <div>7</div>
</div>
```

Первые шесть элементов занимают:

```text
3 × 2 = 6 ячеек
```

Но существует ещё:

```text
7
```

Браузер автоматически создаёт дополнительную строку:

```text
┌─────┬─────┬─────┐
│  1  │  2  │  3  │ ← explicit
├─────┼─────┼─────┤
│  4  │  5  │  6  │ ← explicit
├─────┼─────┼─────┤
│  7  │     │     │ ← implicit
└─────┴─────┴─────┘
```

Последняя строка относится к неявной сетке.

---

### Неявная сетка может появиться и через позиционирование

Например:

```css
.item {
  grid-column: 5;
}
```

если явно создано только:

```text
3 столбца
```

браузеру придётся создать дополнительные дорожки.

---

### Какого они размера?

По умолчанию неявно созданные дорожки имеют автоматическое определение размера.

При необходимости этим можно управлять через:

```css
grid-auto-rows
grid-auto-columns
```

Явная сетка задаётся через `grid-template-*`, а Grid расширяет её неявными дорожками при необходимости.

---

## 19. Что делают `grid-auto-columns` и `grid-auto-rows`?

Эти свойства задают размеры **автоматически созданных дорожек неявной сетки**.

```css
grid-auto-rows
```

задаёт размеры неявных строк.

```css
grid-auto-columns
```

задаёт размеры неявных столбцов.

---

### Пример с `grid-auto-rows`

```css
.container {
  display: grid;

  grid-template-columns:
    repeat(3, 1fr);

  grid-auto-rows: 150px;
}
```

Мы явно определили столбцы, но строки браузер может создавать автоматически.

Каждая такая строка будет:

```text
150px
```

---

### Пример

```text
┌─────┬─────┬─────┐
│  1  │  2  │  3  │
│     150px       │
├─────┼─────┼─────┤
│  4  │  5  │  6  │
│     150px       │
└─────┴─────┴─────┘
```

---

### Более гибкий вариант

```css
grid-auto-rows:
  minmax(100px, auto);
```

Тогда:

```text
минимум
→ 100px

если содержимого больше
→ строка может увеличиваться
```

---

### `grid-auto-columns`

Например:

```css
.container {
  display: grid;

  grid-template-rows:
    100px 100px;

  grid-auto-flow: column;
  grid-auto-columns: 200px;
}
```

Автоматически созданные столбцы будут:

```text
200px
```

---

### Можно задавать повторяющийся шаблон

Например:

```css
grid-auto-rows:
  100px 200px;
```

Неявные строки будут использовать этот шаблон циклически:

```text
100px
200px
100px
200px
...
```

---

### Главное

```text
grid-template-columns / rows
→ размеры явной сетки
```

```text
grid-auto-columns / rows
→ размеры автоматически созданных дорожек
```

---

## 20. Что делает `grid-auto-flow`?

`grid-auto-flow` определяет, **как алгоритм автоматического размещения Grid располагает элементы, которым разработчик не указал конкретные координаты**.

Начальное значение:

```css
grid-auto-flow: row;
```

---

### `row`

```css
grid-auto-flow: row;
```

Элементы заполняют сетку по строкам.

Например:

```text
1 → 2 → 3
↓
4 → 5 → 6
```

```text
┌─────┬─────┬─────┐
│  1  │  2  │  3  │
├─────┼─────┼─────┤
│  4  │  5  │  6  │
└─────┴─────┴─────┘
```

Если строк не хватает, создаются новые.

---

### `column`

```css
grid-auto-flow: column;
```

элементы размещаются прежде всего по столбцам:

```text
1 ↓ 2
3 ↓ 4
```

Например:

```text
┌─────┬─────┬─────┐
│  1  │  3  │  5  │
├─────┼─────┼─────┤
│  2  │  4  │  6  │
└─────┴─────┴─────┘
```

Если столбцов не хватает, Grid может создавать новые.

---

### `dense`

Существует:

```css
grid-auto-flow: dense;
```

или:

```css
grid-auto-flow: row dense;
```

или:

```css
grid-auto-flow: column dense;
```

Режим `dense` пытается заполнить свободные «дыры» в сетке более поздними элементами подходящего размера.

---

### Пример проблемы без `dense`

Допустим, некоторые элементы занимают несколько колонок:

```text
┌─────────────┬─────┐
│      A      │  B  │
├─────┬───────┴─────┤
│     │             │
└─────┴─────────────┘
```

Могут оставаться пустые места.

При:

```css
grid-auto-flow: dense;
```

браузер может взять более поздний небольшой элемент и поместить его в свободную ячейку.

---

### Важный нюанс доступности

`dense` может привести к тому, что **визуальный порядок элементов перестанет совпадать с их порядком в HTML**.

То есть:

```text
HTML:
A B C D E
```

визуально может быть:

```text
A B D C E
```

если `D` подошёл для заполнения более ранней пустой области.

Поэтому использовать `dense` для смыслового переставления интерфейса нужно осторожно.

MDN прямо отмечает, что плотный алгоритм может визуально разместить более поздние элементы раньше, чтобы заполнить пустые места.

---

### Главное

```text
grid-auto-flow: row
→ заполнять строки
```

```text
grid-auto-flow: column
→ заполнять столбцы
```

```text
dense
→ попытаться заполнить пустые места
  более поздними элементами
```

---

## 21. Как центрировать Grid-элемент?

Grid имеет отдельные свойства для выравнивания элементов.

Для одного конкретного grid-элемента можно использовать:

```css
justify-self
align-self
```

---

### `justify-self`

Управляет положением элемента по строчной оси внутри его Grid Area.

При обычном горизонтальном письме это обычно горизонтальное направление.

Например:

```css
.item {
  justify-self: center;
}
```

---

### `align-self`

Управляет положением по блочной оси.

При обычном горизонтальном письме это обычно вертикальное направление.

```css
.item {
  align-self: center;
}
```

---

### Центрирование по двум осям

```css
.item {
  justify-self: center;
  align-self: center;
}
```

---

### `place-self`

Эти свойства можно объединить:

```css
.item {
  place-self: center;
}
```

Это удобная сокращённая запись.

В данном случае:

```text
горизонтально
→ center

вертикально
→ center
```

---

### Центрирование всех элементов контейнера

Если нужно задать выравнивание всем grid-элементам:

```css
.container {
  display: grid;

  justify-items: center;
  align-items: center;
}
```

или сокращённо:

```css
.container {
  display: grid;
  place-items: center;
}
```

---

### Полное центрирование одного элемента

Например:

```css
.container {
  display: grid;
  width: 500px;
  height: 300px;
}

.item {
  place-self: center;
}
```

```text
┌─────────────────────────┐
│                         │
│        ┌───────┐        │
│        │ item  │        │
│        └───────┘        │
│                         │
└─────────────────────────┘
```

---

### Ещё более короткий способ

Если в контейнере один элемент и нужно просто поставить его по центру:

```css
.container {
  display: grid;
  place-items: center;
}
```

Это один из самых компактных способов центрирования в CSS.

---

### Не путать два уровня

```text
justify-items / align-items
→ задаются контейнеру
→ влияют на элементы
```

```text
justify-self / align-self
→ задаются конкретному элементу
```

```text
place-items
→ shorthand для justify-items + align-items
```

```text
place-self
→ shorthand для justify-self + align-self
```

Grid поддерживает выравнивание элементов по обеим осям сетки.

## 22. Можно ли комбинировать Grid и Flexbox?

Да.

Более того, это **обычная и правильная практика**.

Grid и Flexbox решают разные задачи и прекрасно работают вместе.

---

### Например, Grid для всей страницы

```css
.page {
  display: grid;

  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";

  grid-template-columns:
    250px 1fr;
}
```

Получаем большую структуру:

```text
┌─────────────────────────────┐
│ Header                      │
├──────────┬──────────────────┤
│ Sidebar  │ Main             │
├──────────┴──────────────────┤
│ Footer                      │
└─────────────────────────────┘
```

---

### А внутри Header — Flexbox

```css
.header {
  display: flex;
  align-items: center;
  justify-content: space-between;
}
```

Теперь:

```text
Grid
→ управляет местом Header на странице

Flexbox
→ управляет элементами внутри Header
```

---

### Grid внутри Flexbox тоже возможен

Например:

```css
.page {
  display: flex;
}

.gallery {
  display: grid;
  grid-template-columns:
    repeat(3, 1fr);
}
```

То есть `.gallery` одновременно:

```text
flex item
для своего родителя
```

и:

```text
grid container
для своих детей
```

---

### Один элемент может выполнять две роли

Например:

```html
<div class="page">
  <div class="cards">
    <article></article>
    <article></article>
  </div>
</div>
```

```css
.page {
  display: flex;
}
```

`.cards` является:

```text
flex-элементом
```

А:

```css
.cards {
  display: grid;
}
```

делает `.cards` одновременно:

```text
flex item
+
grid container
```

Это совершенно нормально.

Спецификация Grid прямо указывает, что Grid-контейнеры можно вкладывать и комбинировать с Flexbox для создания более сложных макетов.
