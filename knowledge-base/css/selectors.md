## 1. Что такое CSS-селекторы и какие основные типы селекторов существуют?

**CSS-селектор (CSS selector)** — это шаблон, определяющий, к каким элементам документа должны применяться CSS-правила.

Общий синтаксис:

```css
selector {
  property: value;
}
```

Основные категории селекторов:

| Категория | Пример | Назначение |
|---|---|---|
| Селектор типа (Type) | `p` | Выбирает элементы по имени тега |
| Селектор класса (Class) | `.card` | Выбирает элементы с указанным классом |
| Селектор идентификатора (ID) | `#header` | Выбирает элемент с указанным `id` |
| Универсальный (Universal) | `*` | Соответствует любому элементу |
| Селектор атрибута (Attribute) | `[type="text"]` | Выбирает элементы по атрибутам |
| Псевдокласс (Pseudo-class) | `:hover` | Выбирает элементы по состоянию или другим условиям |
| Псевдоэлемент (Pseudo-element) | `::before` | Позволяет обращаться к определённой части элемента или создаваемой CSS сущности |

Селекторы также можно комбинировать, формируя более сложные выражения.

```css
.card.active {
  border-color: green;
}
```

Селектор `.card.active` выбирает элементы, одновременно имеющие классы `card` и `active`.

С точки зрения структуры различают:

- **Simple selector** — простой селектор, например `.card`.
- **Compound selector** — сочетание простых селекторов без комбинаторов, например `button.primary:hover`.
- **Complex selector** — сочетание селекторов посредством комбинаторов, например `.card > p`.
- **Selector list** — список селекторов, разделённых запятыми, например `h1, h2, h3`.

*Источник: MDN — CSS Selectors.*

## 2. Чем отличаются селекторы по тегу, классу и ID? Почему для стилизации обычно предпочитают class?

### Селектор по тегу (Type selector)

Выбирает все элементы с указанным именем тега.

```css
p {
  color: black;
}
```

Применяется ко всем элементам `<p>`.

Обычно используется для базовой стилизации HTML-элементов.

### Селектор класса (Class selector)

Выбирает все элементы, содержащие указанный класс в атрибуте `class`.

```html
<button class="button">Save</button>
<button class="button button--primary">Submit</button>
```

```css
.button {
  padding: 12px 24px;
}

.button--primary {
  background-color: blue;
}
```

Один класс можно назначать нескольким элементам, а одному элементу — несколько классов.

### Селектор ID (ID selector)

Выбирает элемент по значению атрибута `id`.

```html
<header id="header"></header>
```

```css
#header {
  background-color: white;
}
```

Значение `id` должно быть уникальным в пределах документа.

### Почему class предпочтительнее ID?

Причина заключается в переиспользовании и управлении специфичностью (*specificity*).

| Критерий | Type | Class | ID |
|---|---:|---:|---:|
| Специфичность | `0-0-1` | `0-1-0` | `1-0-0` |
| Переиспользование | Да | Да | ID должен быть уникальным |
| Удобство компонентной стилизации | Ограниченное | Высокое | Ограниченное |

ID имеет значительно более высокую специфичность, поэтому переопределение соответствующих правил может усложнять поддержку CSS.

**Практическая рекомендация:** использовать классы для стилизации компонентов, а ID — преимущественно для идентификации элементов, якорной навигации и других задач, где необходим уникальный идентификатор.

## 3. Что такое универсальный и групповой селекторы?

### Универсальный селектор `*` (Universal selector)

Соответствует любому элементу в заданной области.

Часто используется для нормализации базовых стилей:

```css
*,
*::before,
*::after {
  box-sizing: border-box;
}
```

В данном примере `box-sizing: border-box` устанавливается для всех элементов, а также для их псевдоэлементов `::before` и `::after`.

Сам по себе универсальный селектор имеет нулевую специфичность (`0-0-0`).

### Групповой селектор (Selector list)

Позволяет применять одинаковые CSS-правила к нескольким селекторам, разделяя их запятыми.

```css
h1,
h2,
h3 {
  font-family: Georgia, serif;
}
```

Эквивалентен отдельному объявлению одинакового правила для каждого заголовка.

**Важная особенность:** если обычный список содержит синтаксически недопустимый селектор, всё правило может быть проигнорировано браузером. Функции `:is()` и `:where()` имеют более устойчивую обработку отдельных недопустимых селекторов внутри своих списков.

## 4. Что такое CSS-комбинаторы и чем отличаются `A B`, `A > B`, `A + B` и `A ~ B`?

**Комбинаторы (Combinators)** определяют отношения между элементами в дереве документа и используются для построения сложных селекторов.

Четыре основных комбинатора:

| Комбинатор | Название | Что выбирает |
|---|---|---|
| `A B` | Descendant | Любого потомка `B` внутри `A` |
| `A > B` | Child | Непосредственного ребёнка `B` элемента `A` |
| `A + B` | Next-sibling | Элемент `B`, непосредственно следующий за `A` |
| `A ~ B` | Subsequent-sibling | Все подходящие элементы `B`, расположенные после `A` на одном уровне |

### Descendant combinator — пробел

```css
.card p {
  color: gray;
}
```

Выбирает все `<p>`, находящиеся внутри `.card`, независимо от глубины вложенности.

### Child combinator — `>`

```css
.card > p {
  color: gray;
}
```

Выбирает только те `<p>`, которые являются непосредственными дочерними элементами `.card`.

### Next-sibling combinator — `+`

```css
h2 + p {
  margin-top: 0;
}
```

Выбирает `<p>`, непосредственно следующий за `<h2>`, если оба имеют одного родителя.

### Subsequent-sibling combinator — `~`

```css
h2 ~ p {
  color: gray;
}
```

Выбирает все подходящие `<p>`, находящиеся после `<h2>` в пределах одного родительского элемента.

**Особенности:**

- `+` и `~` работают только с элементами, имеющими общего родителя.
- Комбинаторы соседства учитывают порядок элементов в DOM, а не визуальное расположение на странице.
- Комбинаторы не увеличивают специфичность сами по себе.
- Пробельные текстовые узлы и комментарии не мешают работе `+`.

*Источник: MDN — CSS Selectors and Combinators.*

## 5. Что такое селекторы атрибутов и как они работают?

**Attribute selectors** позволяют выбирать элементы на основании наличия атрибута или соответствия его значения определённому условию.

Основные варианты:

| Селектор | Условие |
|---|---|
| `[attr]` | Атрибут существует |
| `[attr="value"]` | Значение точно равно `value` |
| `[attr^="value"]` | Значение начинается с `value` |
| `[attr$="value"]` | Значение заканчивается на `value` |
| `[attr*="value"]` | Значение содержит подстроку `value` |
| `[attr~="value"]` | Содержит `value` как отдельное слово в списке, разделённом пробелами |
| `[attr\|="value"]` | Равно `value` или начинается с `value-` |

### Примеры

```css
/* Все элементы с атрибутом disabled */
[disabled] {
  opacity: 0.5;
}

/* Точное соответствие значения */
input[type="email"] {
  border-color: blue;
}

/* Ссылки, начинающиеся с https:// */
a[href^="https://"] {
  color: green;
}

/* Ссылки, заканчивающиеся на .pdf */
a[href$=".pdf"] {
  color: red;
}

/* Ссылки, содержащие подстроку example */
a[href*="example"] {
  text-decoration: underline;
}
```

### Чувствительность к регистру

По умолчанию чувствительность зависит от языка документа и семантики конкретного атрибута.

Можно явно использовать модификаторы:

```css
[data-theme="dark" i] {
  background-color: black;
}
```

- `i` — сравнение ASCII-символов без учёта регистра.
- `s` — сравнение с учётом регистра.

**Важно:** `[disabled]` проверяет только наличие атрибута. Селектор `[disabled="false"]` также найдёт элемент с `disabled="false"`, хотя HTML интерпретирует наличие булева атрибута `disabled` как отключённое состояние соответствующего элемента.

Специфичность селектора атрибута — `0-1-0`.

## 6. Что такое псевдоклассы и псевдоэлементы? В чём их различие?

### Псевдокласс (Pseudo-class)

**Псевдокласс** — это ключевое слово, добавляемое к селектору для выбора элемента на основании его состояния, положения в дереве документа или выполнения определённого условия.

Синтаксис: одинарное двоеточие (`:`).

```css
button:hover {
  background-color: blue;
}
```

Псевдокласс не создаёт новый элемент, а определяет дополнительное условие выбора существующего.

### Псевдоэлемент (Pseudo-element)

**Псевдоэлемент** позволяет обращаться к определённой части элемента или к абстрактной сущности, представленной браузером при отображении документа.

Синтаксис: двойное двоеточие (`::`).

```css
p::first-letter {
  font-size: 2rem;
}
```

### Основные различия

| Критерий | Псевдокласс | Псевдоэлемент |
|---|---|---|
| Синтаксис | `:` | `::` |
| Назначение | Определяет условие выбора элемента | Обращается к части элемента или абстрактной сущности |
| Примеры | `:hover`, `:focus`, `:first-child` | `::before`, `::after`, `::selection` |
| Специфичность | Обычно `0-1-0` | `0-0-1` |

Для четырёх исторических псевдоэлементов (`::before`, `::after`, `::first-line`, `::first-letter`) браузеры также поддерживают старую запись с одним двоеточием. В современном CSS рекомендуется использовать `::`.

Псевдокласс и псевдоэлемент можно комбинировать:

```css
button:hover::after {
  opacity: 1;
}
```

Правило применяется к псевдоэлементу `::after`, когда исходная кнопка находится в состоянии `:hover`.

*Источник: [MDN — Pseudo-elements](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/Pseudo-elements).*

## 7. Для чего используются псевдоклассы состояния `:hover`, `:focus`, `:focus-visible`, `:active` и `:visited`?

Псевдоклассы состояния позволяют изменять оформление элементов в зависимости от взаимодействия пользователя с интерфейсом.

| Псевдокласс | Назначение |
|---|---|
| `:hover` | Элемент, на который указывает курсор или другое подходящее указательное устройство |
| `:focus` | Элемент, получивший фокус |
| `:focus-visible` | Элемент, для которого браузер считает необходимым визуально обозначить фокус |
| `:active` | Элемент в состоянии активации, например во время нажатия |
| `:visited` | Посещённая пользователем гиперссылка |

Пример:

```css
.button:hover {
  background-color: blue;
}

.button:active {
  transform: scale(0.98);
}

.button:focus {
  outline: 2px solid blue;
}

a:visited {
  color: purple;
}
```

### Чем `:focus` отличается от `:focus-visible`?

`:focus` применяется к любому элементу, который в данный момент имеет фокус, независимо от способа его получения.

`:focus-visible` применяется, когда браузер на основании собственных эвристик определяет необходимость видимого индикатора фокуса.

Например, при клавиатурной навигации через `Tab` браузер обычно применяет `:focus-visible`, тогда как при нажатии мышью на кнопку индикатор может не отображаться.

```css
.button:focus-visible {
  outline: 2px solid blue;
  outline-offset: 3px;
}
```

Важно: `:focus-visible` не является исключительно псевдоклассом клавиатурного фокуса. Его работа определяется браузером и может зависеть от типа элемента, способа взаимодействия и других факторов.

**Практическая рекомендация:** не удалять стандартный `outline` без предоставления доступной альтернативы. Видимый фокус необходим пользователям, которые взаимодействуют с интерфейсом посредством клавиатуры.

### Какие ограничения существуют у `:visited`?

Браузеры ограничивают возможности `:visited`, чтобы сайты не могли определять историю посещённых пользователем страниц.

В частности, разрешено изменять ограниченный набор цветовых свойств:

- `color`;
- `background-color`;
- `border-color` и его составляющие;
- `outline-color`;
- `column-rule-color`;
- `text-decoration-color`;
- `text-emphasis-color`;
- цветовые составляющие SVG `fill` и `stroke`.

Дополнительные ограничения:

1. Изменение прозрачности между посещённой и непосещённой ссылкой не применяется.
2. Скрипты не могут надёжно определить факт посещения ссылки через `getComputedStyle()` или методы выбора элементов.
3. Нельзя изменять геометрию и расположение элемента на основании состояния `:visited`.

Например, изменение `font-size`, `display` или `transform` через `:visited` не будет применено как различие между посещённой и непосещённой ссылкой.

При совместном использовании псевдоклассов ссылок традиционно придерживаются порядка **LVHA**:

```css
a:link {}
a:visited {}
a:hover {}
a:active {}
```

Это помогает корректно организовать каскад при одинаковой специфичности правил.

*Источник: [MDN — Privacy and the :visited selector](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Selectors/Privacy_and_:visited).*

## 8. Как работают структурные псевдоклассы `:first-child`, `:last-child`, `:nth-child()` и `:nth-of-type()`?

**Структурные псевдоклассы** позволяют выбирать элементы на основании их положения среди дочерних элементов общего родителя.

### `:first-child` и `:last-child`

- `:first-child` — выбирает элемент, являющийся первым дочерним элементом своего родителя.
- `:last-child` — выбирает элемент, являющийся последним дочерним элементом своего родителя.

```css
li:first-child {
  font-weight: bold;
}

li:last-child {
  border-bottom: none;
}
```

**Важно:** `p:first-child` выбирает не первый параграф среди параграфов, а параграф, который является первым дочерним элементом своего родителя.

### `:nth-child()`

Функциональный псевдокласс, выбирающий элементы на основании их порядкового номера среди дочерних элементов.

Нумерация начинается с 1.

Основные варианты:

| Селектор | Результат |
|---|---|
| `:nth-child(1)` | Первый дочерний элемент |
| `:nth-child(3)` | Третий дочерний элемент |
| `:nth-child(odd)` | Нечётные позиции (1, 3, 5...) |
| `:nth-child(even)` | Чётные позиции (2, 4, 6...) |
| `:nth-child(3n)` | Каждая третья позиция |
| `:nth-child(3n + 1)` | Позиции 1, 4, 7, 10... |
| `:nth-child(-n + 3)` | Первые три дочерних элемента |

Общая формула:

\[
An + B
\]

где:

- `A` — шаг последовательности;
- `n` — неотрицательное целое число (0, 1, 2...);
- `B` — смещение.

Пример чередования строк:

```css
tr:nth-child(even) {
  background-color: #f5f5f5;
}
```

### Чем `:nth-child()` отличается от `:nth-of-type()`?

Главное различие заключается в том, какие элементы учитываются при определении позиции.

Рассмотрим HTML:

```html
<div>
  <h2>Title</h2>
  <p>First paragraph</p>
  <p>Second paragraph</p>
  <p>Third paragraph</p>
</div>
```

Сравнение:

```css
p:nth-child(2) {
  color: red;
}
```

Выберет `First paragraph`, поскольку этот `<p>` является вторым дочерним элементом `<div>`.

```css
p:nth-of-type(2) {
  color: blue;
}
```

Выберет `Second paragraph`, поскольку это второй элемент типа `<p>` среди элементов с общим родителем.

Таким образом:

- `:nth-child()` учитывает общую последовательность дочерних элементов.
- `:nth-of-type()` учитывает позицию среди элементов с одинаковым именем тега.

### Современный синтаксис `:nth-child()` с параметром `of`

CSS Selectors Level 4 дополнительно поддерживает фильтрацию элементов:

```css
.card:nth-child(2 of .card) {
  border-color: blue;
}
```

Селектор выбирает второй элемент с классом `.card` среди соответствующих ему дочерних элементов одного родителя, независимо от наличия между ними других элементов.

Это отличается от обычного `.card:nth-child(2)`, который требует, чтобы карточка занимала именно вторую позицию среди всех дочерних элементов.

*Источник: [MDN — :nth-child()](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/:nth-child).*

## 9. Что делают функциональные псевдоклассы `:not()`, `:is()`, `:where()` и `:has()`?

Функциональные псевдоклассы принимают аргументы в круглых скобках и позволяют формировать более гибкие условия выбора элементов.

### `:not()` — исключение

Выбирает элементы, которые не соответствуют переданным селекторам.

```css
.button:not(.disabled) {
  cursor: pointer;
}
```

Выбирает все элементы `.button`, у которых отсутствует класс `.disabled`.

Можно передавать несколько селекторов:

```css
.card:not(.featured, .hidden) {
  opacity: 0.8;
}
```

Правило применяется к карточкам, которые не имеют ни класса `featured`, ни класса `hidden`.

### `:is()` — объединение

Позволяет объединять несколько альтернативных селекторов без многократного повторения одинаковой части.

Вместо:

```css
article h1,
article h2,
article h3 {
  color: navy;
}
```

Можно написать:

```css
article :is(h1, h2, h3) {
  color: navy;
}
```

Оба варианта выбирают заголовки `h1`, `h2` и `h3`, находящиеся внутри `article`.

### `:where()` — объединение с нулевой специфичностью

Работает аналогично `:is()`, но всегда имеет нулевую собственную специфичность вместе со всеми селекторами внутри аргумента.

```css
:where(h1, h2, h3) {
  margin: 0;
}
```

Полезен для базовых стилей, CSS Reset и правил, которые впоследствии должны легко переопределяться.

### Сравнение специфичности

| Псевдокласс | Особенность специфичности |
|---|---|
| `:not()` | Принимает специфичность наиболее специфичного аргумента |
| `:is()` | Принимает специфичность наиболее специфичного аргумента |
| `:where()` | Всегда имеет специфичность `0-0-0` |
| `:has()` | Принимает специфичность наиболее специфичного аргумента |

Например:

```css
:is(.card, #featured) {
  color: red;
}
```

Специфичность всего селектора — `1-0-0`, даже если фактически выбран элемент по классу `.card`.

Сам функциональный псевдокласс дополнительную специфичность не добавляет.

### `:has()` — селектор отношений (Relational pseudo-class)

Позволяет выбирать элемент на основании наличия других элементов, соответствующих заданному относительному селектору.

В частности, благодаря `:has()` можно стилизовать родителя на основании содержимого его дочерних элементов.

```css
.card:has(img) {
  padding: 20px;
}
```

Выбирает `.card`, если внутри неё присутствует изображение `<img>` на любой глубине вложенности.

Для проверки непосредственного дочернего элемента:

```css
.card:has(> img) {
  padding: 20px;
}
```

`:has()` также позволяет выбирать предыдущий соседний элемент на основании следующего.

```css
h2:has(+ p) {
  margin-bottom: 10px;
}
```

Выбирает заголовок `<h2>`, непосредственно после которого расположен параграф.

**Важные особенности `:has()`:**

- Поддерживается современными основными браузерами; относится к Baseline Widely Available с декабря 2023 года.
- Нельзя вкладывать один `:has()` непосредственно в другой `:has()`.
- Псевдоэлементы, как правило, не допускаются в аргументах `:has()`.
- Слишком широкие и сложные проверки могут влиять на производительность при динамических изменениях DOM.

Поэтому желательно ограничивать область поиска конкретными компонентами, например `.card:has(> img)`, вместо бесконтрольного применения сложных проверок к универсальному селектору `*`.

*Источники: [MDN — :is()](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/:is), [MDN — :where()](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/:where), [MDN — :has()](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/:has).*

## 10. Для чего используются псевдоэлементы `::before`, `::after`, `::placeholder`, `::selection` и `::marker`?

Псевдоэлементы позволяют стилизовать определённые части элемента или добавлять визуальное содержимое без необходимости создавать дополнительные HTML-элементы.

### `::before` и `::after`

Используются для создания CSS-генерируемого содержимого внутри исходного элемента:

- `::before` — перед основным содержимым;
- `::after` — после основного содержимого.

Например, для декоративного элемента:

```css
.card::before {
  content: "";
  display: block;
  width: 40px;
  height: 2px;
  background-color: black;
}
```

Для отображения `::before` и `::after` обычно необходимо указать свойство `content`.

```css
.element::before {
  content: "";
}
```

Даже если псевдоэлемент не содержит текста, `content: ""` позволяет создать пустое генерируемое содержимое, которому затем можно назначить размеры, фон, границы и другие стили.

Если значение `content` отсутствует, равно `normal` или `none`, соответствующий псевдоэлемент не отображается.

**Важно:** `::before` и `::after` не предназначены для хранения смысловой информации, необходимой для понимания интерфейса. CSS-генерируемое содержимое не всегда надёжно доступно вспомогательным технологиям.

Кроме того, эти псевдоэлементы нельзя применять обычным образом к замещаемым элементам (*replaced elements*), например `<img>`.

### `::placeholder`

Позволяет стилизовать текст-подсказку, отображаемый в полях формы посредством HTML-атрибута `placeholder`.

```css
input::placeholder {
  color: gray;
  font-style: italic;
}
```

Не следует путать с псевдоклассом `:placeholder-shown`, который выбирает сам элемент управления, когда в нём отображается placeholder.

### `::selection`

Позволяет стилизовать часть содержимого, выделенную пользователем.

```css
::selection {
  color: white;
  background-color: navy;
}
```

Поддерживает ограниченный набор свойств, преимущественно связанных с оформлением текста и цветом выделения.

### `::marker`

Позволяет стилизовать маркеры элементов списка: точки, цифры и другие обозначения.

```css
li::marker {
  color: red;
  font-weight: bold;
}
```

Поддерживает ограниченный набор CSS-свойств, включая некоторые свойства текста, `color` и `content`.

Применяется к элементам, генерирующим маркер, то есть имеющим `display: list-item`.

*Источники: MDN — CSS Pseudo-elements, ::before, ::marker.*
