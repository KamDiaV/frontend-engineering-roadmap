# II. Селекторы CSS

## 1. Какие основные типы CSS-селекторов существуют?

**CSS-селектор (CSS Selector)** — шаблон, с помощью которого браузер определяет, к каким элементам HTML-документа необходимо применить CSS-правило.

Общий синтаксис:

```css
selector {
  property: value;
}
```

Например:

```css
p {
  color: red;
}
```

Здесь:

- `p` — селектор;
- `color` — CSS-свойство;
- `red` — значение свойства.

Правило устанавливает красный цвет текста для всех элементов `<p>` в документе.

### Основные типы CSS-селекторов

| Тип | Синтаксис | Назначение |
|---|---|---|
| Type Selector | `p` | Выбирает элементы по имени тега |
| Class Selector | `.card` | Выбирает элементы по классу |
| ID Selector | `#header` | Выбирает элементы по идентификатору |
| Universal Selector | `*` | Соответствует любым элементам |
| Attribute Selector | `[type="email"]` | Выбирает элементы по наличию или значению атрибута |
| Pseudo-class | `:hover` | Выбирает элементы по состоянию или другим условиям |
| Pseudo-element | `::before` | Позволяет обращаться к определённой части элемента или CSS-генерируемому содержимому |

Селекторы могут объединяться между собой для формирования более сложных условий выбора.

Например:

```css
.card.active {
  border-color: green;
}
```

Выбирает элементы, одновременно имеющие классы `card` и `active`.

В спецификации CSS Selectors также различают несколько структурных категорий селекторов:

| Категория | Пример | Описание |
|---|---|---|
| Simple Selector | `.card` | Один простой селектор |
| Compound Selector | `.card.active` | Сочетание простых селекторов без комбинаторов |
| Complex Selector | `.card > p` | Селекторы, связанные комбинаторами |
| Selector List | `h1, h2, h3` | Список альтернативных селекторов |

## 2. Чем отличаются селекторы по тегу, классу и ID?

Основное различие заключается в том, по какому признаку браузер выбирает HTML-элементы.

### 1. Type Selector — селектор по тегу

Выбирает все элементы с указанным именем тега.

Например:

```css
p {
  color: black;
}
```

Применяется ко всем элементам `<p>` независимо от их классов, идентификаторов и расположения в документе.

Обычно используется для базовой стилизации HTML-элементов.

### 2. Class Selector — селектор класса

Выбирает элементы, содержащие указанный класс в атрибуте `class`.

Для обращения к классу используется точка (`.`).

HTML:

```html
<button class="button">Save</button>
<button class="button">Submit</button>
```

CSS:

```css
.button {
  padding: 12px 24px;
}
```

Обе кнопки получат одинаковые внутренние отступы.

Особенности:

- один класс можно назначать нескольким элементам;
- один элемент может одновременно иметь несколько классов;
- классы удобно использовать для создания переиспользуемых компонентов.

Например:

```html
<button class="button button--primary">
  Submit
</button>
```

Элемент одновременно принадлежит двум классам: `button` и `button--primary`.

### 3. ID Selector — селектор идентификатора

Выбирает элемент по значению атрибута `id`.

Для обращения к идентификатору используется символ `#`.

HTML:

```html
<header id="header"></header>
```

CSS:

```css
#header {
  background-color: white;
}
```

Значение `id` должно быть уникальным в пределах документа.

Если ошибочно назначить одинаковый ID нескольким элементам, CSS-селектор всё равно может выбрать их все, однако такая разметка нарушает требование уникальности.

### Сравнение

| Критерий | Type | Class | ID |
|---|---|---|---|
| Синтаксис | `p` | `.card` | `#header` |
| Признак выбора | Имя тега | Значение `class` | Значение `id` |
| Переиспользование | Да | Да | ID должен быть уникальным |
| Специфичность | `0-0-1` | `0-1-0` | `1-0-0` |

## 3. Почему для стилизации обычно предпочитают class, а не ID?

Основные причины — **переиспользование и управление специфичностью (Specificity)**.

Специфичность — это вес CSS-селектора, который участвует в разрешении конфликтов между конкурирующими CSS-объявлениями.

ID имеет значительно более высокую специфичность, чем класс.

Например:

```css
#title {
  color: red;
}

.title {
  color: blue;
}
```

HTML:

```html
<h1 id="title" class="title">Hello</h1>
```

При прочих равных заголовок будет красным, несмотря на то что правило `.title` объявлено позже.

Причина — более высокая специфичность `#title`.

Это может усложнять переопределение стилей и сопровождение проекта.

### Преимущества использования классов

1. **Переиспользование.** Один класс можно назначить множеству HTML-элементов.
2. **Умеренная специфичность.** Стили проще переопределять без чрезмерно сложных селекторов.
3. **Компонентный подход.** Классы позволяют разделять базовые стили и модификаторы.
4. **Масштабируемость.** Компоненты проще переносить между страницами и проектами.

Например:

```css
.button {
  padding: 12px 24px;
  border-radius: 4px;
}

.button--primary {
  background-color: blue;
}

.button--secondary {
  background-color: gray;
}
```

Так можно использовать общий класс `.button` и изменять внешний вид посредством дополнительных классов.

**Практическая рекомендация:** использовать классы для стилизации компонентов, а ID — преимущественно для уникальной идентификации элементов, якорной навигации и других задач, где необходим уникальный идентификатор.

## 4. Что такое универсальный селектор `*`?

**Universal Selector (`*`)** — универсальный CSS-селектор, который соответствует любому элементу в заданной области.

Синтаксис:

```css
* {
  margin: 0;
}
```

В данном примере у всех элементов документа, к которым применимо правило, сбрасываются внешние отступы.

Универсальный селектор часто используется для создания базовых стилей и CSS Reset.

Например:

```css
*,
*::before,
*::after {
  box-sizing: border-box;
}
```

Это правило устанавливает `box-sizing: border-box` для всех элементов, а также для их псевдоэлементов `::before` и `::after`.

### Особенности

- `*` имеет нулевую специфичность (`0-0-0`);
- сам по себе `*` не включает псевдоэлементы;
- универсальный селектор можно комбинировать с другими селекторами.

Например:

```css
.card * {
  color: gray;
}
```

Выбирает все элементы-потомки внутри `.card`, независимо от глубины их вложенности.

## 5. Как работают групповые селекторы?

**Grouping Selectors (групповые селекторы)** позволяют применять одинаковые CSS-объявления сразу к нескольким селекторам.

Для объединения используется запятая (`,`).

Например, вместо трёх отдельных правил:

```css
h1 {
  font-family: Georgia, serif;
}

h2 {
  font-family: Georgia, serif;
}

h3 {
  font-family: Georgia, serif;
}
```

можно написать:

```css
h1,
h2,
h3 {
  font-family: Georgia, serif;
}
```

Все три селектора используют один блок CSS-объявлений.

Такую конструкцию называют **Selector List (список селекторов)**.

### Особенности

- Группировка уменьшает дублирование кода.
- Каждый селектор в списке проверяется независимо.
- Специфичность рассчитывается отдельно для каждого селектора.

**Важно:** если обычный список содержит синтаксически недопустимый селектор, браузер может проигнорировать всё правило.

Это отличается от некоторых функциональных псевдоклассов, например `:is()` и `:where()`, которые используют более устойчивую обработку отдельных недопустимых селекторов внутри своих списков.

## 6. Что такое Descendant Selector?

**Descendant Selector (селектор потомков)** — CSS-селектор, позволяющий выбирать элементы, находящиеся внутри другого элемента, независимо от глубины вложенности.

Для записи используется пробел между двумя селекторами.

Синтаксис:

```css
A B {
  /* CSS declarations */
}
```

Здесь:

- `A` — элемент-предок (ancestor);
- `B` — элемент-потомок (descendant).

Например:

```css
.card p {
  color: gray;
}
```

HTML:

```html
<div class="card">
  <p>First paragraph</p>

  <div>
    <p>Second paragraph</p>
  </div>
</div>
```

Селектор `.card p` выберет оба параграфа, поскольку оба находятся внутри `.card`.

**Важно:** Descendant Selector не требует, чтобы элемент-потомок был непосредственным ребёнком указанного предка.

Между ними может находиться любое количество других вложенных элементов.

## 7. Чем `A B` отличается от `A > B`?

Оба селектора определяют отношения между элементами в структуре документа, но отличаются допустимой глубиной вложенности.

### `A B` — Descendant Combinator

Выбирает любые элементы `B`, находящиеся внутри `A`, независимо от глубины вложенности.

```css
.card p {
  color: gray;
}
```

### `A > B` — Child Combinator

Выбирает только те элементы `B`, которые являются непосредственными детьми элемента `A`.

```css
.card > p {
  color: gray;
}
```

Рассмотрим HTML:

```html
<div class="card">
  <p>First paragraph</p>

  <div>
    <p>Second paragraph</p>
  </div>
</div>
```

Результат:

| Селектор | Выбранные элементы |
|---|---|
| `.card p` | Оба параграфа |
| `.card > p` | Только `First paragraph` |

Главное различие:

```text
A B   → любой уровень вложенности
A > B → только непосредственный ребёнок
```

В данном случае пробел и символ `>` являются **CSS-комбинаторами (Combinators)** — специальными конструкциями, определяющими отношения между элементами.

Сами комбинаторы не увеличивают специфичность селектора.

## 8. Что делает Adjacent Sibling Selector `+`?

**Adjacent Sibling Selector**, который в современных спецификациях называется **Next-sibling Combinator**, выбирает элемент, расположенный непосредственно после другого элемента, если оба имеют одного родителя.

Синтаксис:

```css
A + B {
  /* CSS declarations */
}
```

Здесь выбирается элемент `B`, непосредственно следующий за элементом `A`.

Например:

```css
h2 + p {
  margin-top: 0;
}
```

HTML:

```html
<h2>Heading</h2>

<p>First paragraph</p>
<p>Second paragraph</p>
```

Правило применяется только к `First paragraph`, поскольку этот параграф непосредственно следует за `<h2>`.

### Особенности

- Элементы должны иметь общего родителя.
- Учитывается порядок элементов в DOM, а не визуальное расположение.
- Комбинатор выбирает следующий элемент, а не предыдущий.
- Пробельные текстовые узлы и комментарии между элементами не мешают работе `+`.

Например, в записи:

```html
<h2>Heading</h2>

<!-- Comment -->

<p>Paragraph</p>
```

селектор `h2 + p` по-прежнему выберет параграф.

---

## 9. Что делает General Sibling Selector `~`?

**General Sibling Selector**, который в современных спецификациях называется **Subsequent-sibling Combinator**, выбирает все подходящие элементы, находящиеся после указанного элемента и имеющие с ним общего родителя.

Синтаксис:

```css
A ~ B {
  /* CSS declarations */
}
```

Например:

```css
h2 ~ p {
  color: gray;
}
```

HTML:

```html
<h2>Heading</h2>

<p>First paragraph</p>
<div>Other content</div>
<p>Second paragraph</p>
```

Будут выбраны оба параграфа.

В отличие от `+`, комбинатор `~` не требует, чтобы элементы непосредственно следовали друг за другом.

### Сравнение `+` и `~`

| Комбинатор | Поведение |
|---|---|
| `A + B` | Выбирает `B`, непосредственно следующий за `A` |
| `A ~ B` | Выбирает все подходящие `B`, расположенные после `A` и имеющие с ним общего родителя |

Важно: оба комбинатора работают только между элементами, находящимися на одном уровне вложенности, то есть имеющими общего родителя.

## 10. Что такое Attribute Selectors?

**Attribute Selectors (селекторы атрибутов)** — CSS-селекторы, позволяющие выбирать HTML-элементы на основании наличия атрибута или соответствия его значения определённому условию.

Для записи используются квадратные скобки (`[]`).

Например:

```css
input[type="email"] {
  border-color: blue;
}
```

Выбирает элементы `<input>`, значение атрибута `type` которых равно `email`.

### Когда применяются селекторы атрибутов?

Они полезны, когда необходимо выбирать элементы на основании уже существующих HTML-атрибутов, не добавляя дополнительные классы.

Например:

```css
[disabled] {
  opacity: 0.5;
}
```

Выбирает все элементы с атрибутом `disabled`.

Или:

```css
[data-theme="dark"] {
  background-color: black;
  color: white;
}
```

Выбирает элементы, имеющие пользовательский атрибут `data-theme` со значением `dark`.

Селекторы атрибутов особенно полезны при работе с формами, ссылками, состояниями и пользовательскими `data-*` атрибутами.

Специфичность любого селектора атрибута — `0-1-0`.

## 11. Как работают `[attr]`, `[attr="value"]`, `[attr^="value"]`, `[attr$="value"]` и `[attr*="value"]`?

Селекторы атрибутов позволяют проверять не только наличие атрибута, но и соответствие его значения определённому условию.

### Основные варианты

| Селектор | Условие |
|---|---|
| `[attr]` | Атрибут существует |
| `[attr="value"]` | Значение точно равно `value` |
| `[attr^="value"]` | Значение начинается с `value` |
| `[attr$="value"]` | Значение заканчивается на `value` |
| `[attr*="value"]` | Значение содержит подстроку `value` |

### 1. `[attr]` — проверка наличия атрибута

```css
[disabled] {
  opacity: 0.5;
}
```

Выбирает все элементы, имеющие атрибут `disabled`, независимо от его записанного значения.

### 2. `[attr="value"]` — точное соответствие

```css
input[type="email"] {
  border-color: blue;
}
```

Выбирает элементы `<input>`, значение атрибута `type` которых равно `email`.

### 3. `[attr^="value"]` — начало значения

```css
a[href^="https://"] {
  color: green;
}
```

Выбирает ссылки, значение `href` которых начинается с `https://`.

### 4. `[attr$="value"]` — конец значения

```css
a[href$=".pdf"] {
  color: red;
}
```

Выбирает ссылки, значение `href` которых заканчивается на `.pdf`.

### 5. `[attr*="value"]` — наличие подстроки

```css
a[href*="example"] {
  text-decoration: underline;
}
```

Выбирает ссылки, значение `href` которых содержит подстроку `example` в любом месте.

### Дополнительные варианты

CSS также поддерживает:

| Селектор | Условие |
|---|---|
| `[attr~="value"]` | Значение содержит `value` как отдельное слово в списке, разделённом пробелами |
| `[attr\|="value"]` | Значение равно `value` или начинается с `value-` |

Например:

```css
[lang|="en"] {
  font-style: italic;
}
```

Выбирает элементы, у которых `lang` равен `en` или начинается с `en-`, например `en-US` и `en-GB`.

### Чувствительность к регистру

По умолчанию чувствительность сравнения зависит от языка документа и определения конкретного атрибута.

Для явного управления можно использовать модификаторы:

```css
[data-theme="dark" i] {
  background-color: black;
}
```

- `i` — сравнение ASCII-символов без учёта регистра;
- `s` — сравнение с учётом регистра.

**Важно:** селектор атрибута проверяет именно атрибут, а не фактическое поведение элемента.

Например:

```html
<button disabled="false">Submit</button>
```

Селектор `[disabled="false"]` найдёт такую кнопку, однако HTML интерпретирует наличие булева атрибута `disabled` как отключённое состояние.

## 12. Что такое Pseudo-class?

**Pseudo-class (псевдокласс)** — ключевое слово, добавляемое к CSS-селектору для выбора элемента на основании его состояния, положения в дереве документа или выполнения другого условия.

Синтаксис — одинарное двоеточие (`:`).

Например:

```css
button:hover {
  background-color: blue;
}
```

Псевдокласс `:hover` позволяет изменить оформление кнопки, когда пользователь наводит на неё указатель.

Псевдоклассы не создают новые HTML-элементы, а дополняют условия выбора существующих.

### Основные категории псевдоклассов

| Категория | Примеры | Назначение |
|---|---|---|
| Состояния взаимодействия | `:hover`, `:focus`, `:active` | Выбор элементов по состоянию |
| Структурные | `:first-child`, `:last-child`, `:nth-child()` | Выбор элементов по положению в структуре документа |
| Состояния форм | `:checked`, `:disabled`, `:required`, `:invalid` | Выбор элементов формы по состоянию |
| Функциональные | `:not()`, `:is()`, `:where()`, `:has()` | Формирование дополнительных условий выбора |
| Состояния ссылок | `:link`, `:visited` | Выбор ссылок по состоянию посещения |

Обычный псевдокласс имеет специфичность `0-1-0`, однако некоторые функциональные псевдоклассы используют специальные правила расчёта специфичности.

## 13. Что такое Pseudo-element?

**Pseudo-element (псевдоэлемент)** — конструкция CSS, позволяющая обращаться к определённой части элемента либо к абстрактной сущности, представленной браузером при отображении документа.

В отличие от обычного HTML-элемента, псевдоэлемент не требует создания дополнительной HTML-разметки.

Синтаксис — двойное двоеточие (`::`).

Например:

```css
p::first-letter {
  font-size: 32px;
}
```

Псевдоэлемент `::first-letter` позволяет стилизовать первую букву текста соответствующего элемента.

### Основные псевдоэлементы

| Псевдоэлемент | Назначение |
|---|---|
| `::before` | Создаёт содержимое перед основным содержимым элемента |
| `::after` | Создаёт содержимое после основного содержимого элемента |
| `::first-letter` | Выбирает первую букву |
| `::first-line` | Выбирает первую отформатированную строку текста |
| `::placeholder` | Стилизует текст-подсказку в поле формы |
| `::selection` | Стилизует выделенную пользователем часть содержимого |
| `::marker` | Стилизует маркеры элементов списка |

Обычная специфичность псевдоэлемента — `0-0-1`.

**Примечание:** для четырёх исторических псевдоэлементов (`::before`, `::after`, `::first-line`, `::first-letter`) браузеры также поддерживают старую запись с одним двоеточием. В современном CSS рекомендуется использовать синтаксис `::`.

## 14. Чем Pseudo-class отличается от Pseudo-element?

Главное различие заключается в назначении.

**Pseudo-class** определяет дополнительное условие выбора существующего элемента.

**Pseudo-element** позволяет обращаться к определённой части элемента или CSS-генерируемому содержимому.

### Сравнение

| Критерий | Pseudo-class | Pseudo-element |
|---|---|---|
| Синтаксис | `:` | `::` |
| Назначение | Определяет условие выбора элемента | Обращается к части элемента или CSS-сущности |
| Примеры | `:hover`, `:focus`, `:first-child` | `::before`, `::after`, `::selection` |
| Обычная специфичность | `0-1-0` | `0-0-1` |

Пример псевдокласса:

```css
button:hover {
  background-color: blue;
}
```

Правило изменяет оформление самой кнопки, когда она находится в состоянии `:hover`.

Пример псевдоэлемента:

```css
button::after {
  content: " →";
}
```

Правило добавляет генерируемое содержимое после основного содержимого кнопки.

### Комбинирование

Псевдоклассы и псевдоэлементы можно использовать совместно:

```css
button:hover::after {
  opacity: 1;
}
```

Это правило применяется к псевдоэлементу `::after` кнопки, когда сама кнопка находится в состоянии `:hover`.

## 15. Для чего используются `:hover`, `:focus`, `:active` и `:visited`?

Эти псевдоклассы позволяют изменять оформление элементов в зависимости от состояния взаимодействия пользователя с интерфейсом.

### Основные псевдоклассы состояния

| Псевдокласс | Назначение |
|---|---|
| `:hover` | Элемент, на который указывает курсор или другое подходящее указательное устройство |
| `:focus` | Элемент, получивший фокус |
| `:active` | Элемент в состоянии активации |
| `:visited` | Гиперссылка, которую браузер считает посещённой |

### `:hover` — наведение

Используется для оформления элемента при наведении указателя.

Например:

```css
.button:hover {
  background-color: blue;
}
```

Часто применяется для кнопок, ссылок и других интерактивных элементов.

Важно учитывать, что на устройствах с сенсорным экраном поведение `:hover` может отличаться, поэтому важные действия интерфейса не должны быть доступны исключительно при наведении.

### `:focus` — фокус

Выбирает элемент, который в данный момент имеет фокус.

Например:

```css
input:focus {
  border-color: blue;
}
```

Фокус может возникать при:

- навигации посредством клавиатуры;
- взаимодействии мышью;
- программной установке фокуса через JavaScript.

Фокус показывает, какой элемент в данный момент готов принимать соответствующий пользовательский ввод.

### `:active` — активация

Применяется к элементу, находящемуся в состоянии активации.

Например, кнопка обычно соответствует `:active` в период её нажатия.

```css
.button:active {
  transform: scale(0.98);
}
```

Часто используется для создания визуальной обратной связи при взаимодействии.

### `:visited` — посещённая ссылка

Используется для стилизации гиперссылок, которые браузер считает ранее посещёнными.

```css
a:visited {
  color: purple;
}
```

Этот псевдокласс имеет специальные ограничения безопасности, поскольку информация об истории посещений пользователя является приватной.

---

## 16. Чем `:focus` отличается от `:focus-visible`?

Оба псевдокласса связаны с фокусом элемента, но отличаются условиями применения.

### `:focus`

Применяется к элементу, который в данный момент имеет фокус, независимо от способа его получения.

Например:

```css
.button:focus {
  outline: 2px solid blue;
}
```

Правило применяется, когда кнопка получает фокус через клавиатуру, мышь или программным способом — при условии, что соответствующее взаимодействие действительно устанавливает фокус.

### `:focus-visible`

Применяется к элементу, имеющему фокус, когда браузер определяет необходимость отображения визуального индикатора фокуса.

Например:

```css
.button:focus-visible {
  outline: 2px solid blue;
  outline-offset: 3px;
}
```

Работа `:focus-visible` определяется браузерными эвристиками.

Они могут учитывать:

- способ взаимодействия;
- тип элемента;
- необходимость текстового ввода;
- программное перемещение фокуса;
- пользовательские настройки.

Например, при переходе между кнопками посредством `Tab` обычно применяется `:focus-visible`, тогда как при нажатии мышью на кнопку индикатор может не отображаться.

**Важно:** `:focus-visible` не является исключительно псевдоклассом клавиатурного фокуса.

### Сравнение

| Псевдокласс | Когда применяется |
|---|---|
| `:focus` | Когда элемент имеет фокус |
| `:focus-visible` | Когда элемент имеет фокус и браузер считает необходимым визуально его обозначить |

**Практическая рекомендация:** не удалять стандартный `outline` без предоставления доступной альтернативы. Видимый фокус необходим пользователям, которые взаимодействуют с интерфейсом посредством клавиатуры.

## 17. Как работают `:first-child`, `:last-child` и `:nth-child()`?

**Структурные псевдоклассы (Structural Pseudo-classes)** позволяют выбирать элементы на основании их положения среди дочерних элементов общего родителя.

### `:first-child` — первый дочерний элемент

Выбирает элемент, являющийся первым дочерним элементом своего родителя.

```css
li:first-child {
  font-weight: bold;
}
```

Например:

```html
<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>
```

Правило применяется к первому `<li>` — `HTML`.

### `:last-child` — последний дочерний элемент

Выбирает элемент, являющийся последним дочерним элементом своего родителя.

```css
li:last-child {
  border-bottom: none;
}
```

В предыдущем HTML-примере правило применяется к последнему `<li>` — `JavaScript`.

**Важно:** `p:first-child` выбирает не первый параграф среди всех параграфов, а параграф, который является первым дочерним элементом своего родителя.

### `:nth-child()` — выбор по порядковому номеру

Функциональный псевдокласс, выбирающий элементы на основании их порядкового номера среди дочерних элементов.

Нумерация начинается с 1.

Основные варианты:

| Селектор | Результат |
|---|---|
| `:nth-child(1)` | Первый дочерний элемент |
| `:nth-child(3)` | Третий дочерний элемент |
| `:nth-child(odd)` | Нечётные позиции: 1, 3, 5... |
| `:nth-child(even)` | Чётные позиции: 2, 4, 6... |
| `:nth-child(3n)` | Каждая третья позиция |
| `:nth-child(3n + 1)` | Позиции 1, 4, 7, 10... |
| `:nth-child(-n + 3)` | Первые три дочерних элемента |

Общая формула:

\[
An + B
\]

где:

- `A` — шаг последовательности;
- `n` — неотрицательное целое число (0, 1, 2...);
- `B` — смещение.

Например, для чередования фона строк таблицы:

```css
tr:nth-child(even) {
  background-color: #f5f5f5;
}
```

Важно учитывать, что `:nth-child()` определяет порядковую позицию среди дочерних элементов, а не среди текстовых узлов или комментариев.

---

## 18. Чем `:nth-child()` отличается от `:nth-of-type()`?

Главное различие заключается в том, какие элементы учитываются при определении порядкового номера.

### `:nth-child()`

Учитывает позицию элемента среди всех дочерних элементов общего родителя.

Рассмотрим HTML:

```html
<div>
  <h2>Title</h2>
  <p>First paragraph</p>
  <p>Second paragraph</p>
  <p>Third paragraph</p>
</div>
```

Селектор:

```css
p:nth-child(2) {
  color: red;
}
```

Выберет `First paragraph`, поскольку этот `<p>` является вторым дочерним элементом `<div>`.

### `:nth-of-type()`

Учитывает позицию элемента только среди дочерних элементов с одинаковым именем тега.

Для того же HTML:

```css
p:nth-of-type(2) {
  color: blue;
}
```

Выберет `Second paragraph`, поскольку это второй элемент типа `<p>` среди элементов с общим родителем.

### Сравнение

| Псевдокласс | Что учитывает |
|---|---|
| `:nth-child()` | Позицию среди всех дочерних элементов |
| `:nth-of-type()` | Позицию среди дочерних элементов с одинаковым именем тега |

### Современный синтаксис `:nth-child()` с параметром `of`

CSS Selectors Level 4 дополнительно поддерживает фильтрацию элементов.

Например:

```css
.card:nth-child(2 of .card) {
  border-color: blue;
}
```

Селектор выбирает второй элемент с классом `.card` среди соответствующих ему дочерних элементов одного родителя, независимо от наличия между ними других элементов.

Это отличается от обычного:

```css
.card:nth-child(2) {}
```

Второй вариант требует, чтобы карточка занимала именно вторую позицию среди всех дочерних элементов.

## 19. Что делают `:not()`, `:is()` и `:where()`?

**Функциональные псевдоклассы** принимают аргументы в круглых скобках и позволяют создавать более гибкие условия выбора элементов.

### 1. `:not()` — исключение

Выбирает элементы, которые не соответствуют переданному селектору или списку селекторов.

Например:

```css
.button:not(.disabled) {
  cursor: pointer;
}
```

Выбирает все элементы `.button`, не имеющие класса `.disabled`.

Можно передавать несколько селекторов:

```css
.card:not(.featured, .hidden) {
  opacity: 0.8;
}
```

Правило применяется к карточкам, у которых отсутствуют оба класса: `featured` и `hidden`.

### 2. `:is()` — объединение

Позволяет объединять несколько альтернативных селекторов и уменьшать повторение кода.

Например, вместо:

```css
article h1,
article h2,
article h3 {
  color: navy;
}
```

можно написать:

```css
article :is(h1, h2, h3) {
  color: navy;
}
```

Оба варианта выбирают заголовки `h1`, `h2` и `h3`, находящиеся внутри `article`.

### 3. `:where()` — объединение с нулевой специфичностью

Работает аналогично `:is()`, но имеет принципиальное отличие: его специфичность вместе со всеми селекторами внутри аргумента всегда равна `0-0-0`.

```css
:where(h1, h2, h3) {
  margin: 0;
}
```

Полезен для:

- CSS Reset;
- базовых стилей;
- правил, которые должны легко переопределяться в дальнейшем.

### Сравнение специфичности

| Псевдокласс | Правило расчёта специфичности |
|---|---|
| `:not()` | Принимает специфичность наиболее специфичного аргумента |
| `:is()` | Принимает специфичность наиболее специфичного аргумента |
| `:where()` | Всегда имеет нулевую специфичность (`0-0-0`) |

Например:

```css
:is(.card, #featured) {
  color: red;
}
```

Специфичность всего селектора — `1-0-0`, даже если фактически выбран элемент по классу `.card`.

Причина заключается в том, что `:is()` учитывает наиболее специфичный аргумент (`#featured`).

Для сравнения:

```css
:where(.card, #featured) {
  color: red;
}
```

Специфичность всего селектора составляет `0-0-0`.

**Важно:** сами функции `:not()`, `:is()` и `:where()` не добавляют дополнительную специфичность. Она определяется согласно правилам соответствующего псевдокласса.

Ещё одна особенность: `:is()` и `:where()` используют более устойчивую обработку списков селекторов — отдельные недопустимые варианты могут отбрасываться без признания всего списка недопустимым.

## 20. Что делает `:has()`?

**`:has()` (Relational Pseudo-class)** — функциональный псевдокласс, позволяющий выбирать элемент на основании соответствия связанных с ним элементов указанным относительным селекторам.

На практике `:has()` особенно полезен для стилизации родительского элемента в зависимости от содержимого его дочерних элементов.

### Пример: выбор родителя

HTML:

```html
<div class="card">
  <img src="image.jpg" alt="">
  <h2>Product</h2>
</div>
```

CSS:

```css
.card:has(img) {
  padding: 20px;
}
```

Это правило выбирает `.card`, внутри которого находится хотя бы один элемент `<img>`.

Для проверки только непосредственного дочернего элемента можно использовать:

```css
.card:has(> img) {
  padding: 20px;
}
```

В данном случае карточка будет выбрана, только если `<img>` является её непосредственным ребёнком.

### Пример: выбор предыдущего элемента

`:has()` также позволяет выбирать элемент на основании следующего за ним элемента.

```css
h2:has(+ p) {
  margin-bottom: 10px;
}
```

Выбирает заголовок `<h2>`, непосредственно после которого расположен параграф `<p>` с тем же родителем.

### Особенности `:has()`

- Поддерживается современными основными браузерами (Baseline Widely Available с декабря 2023 года).
- Может принимать список относительных селекторов.
- Нельзя непосредственно вкладывать один `:has()` внутрь другого `:has()`.
- Псевдоэлементы, как правило, не допускаются внутри аргументов `:has()`.
- Слишком широкие и сложные проверки могут влиять на производительность при динамических изменениях DOM.

Например, желательно ограничивать область поиска конкретными компонентами:

```css
.card:has(> img) {}
```

вместо бесконтрольного использования сложных проверок через универсальный селектор `*`.

Специфичность `:has()` определяется наиболее специфичным селектором внутри его аргументов, аналогично `:is()` и `:not()`.

## 21. Какие ограничения и особенности есть у `:visited`?

**`:visited`** — псевдокласс, используемый для стилизации гиперссылок, которые браузер считает ранее посещёнными.

Например:

```css
a:visited {
  color: purple;
}
```

Этот псевдокласс имеет специальные ограничения безопасности, поскольку информация об истории посещений пользователя является приватной.

### Ограничения `:visited`

Браузеры специально ограничивают работу `:visited`, чтобы веб-сайты не могли получать информацию об истории посещений пользователя.

Разрешено изменять только ограниченный набор цветовых свойств:

- `color`;
- `background-color`;
- `border-color` и его составляющие;
- `outline-color`;
- `column-rule-color`;
- `text-decoration-color`;
- `text-emphasis-color`;
- цветовые составляющие SVG `fill` и `stroke`.

Дополнительные ограничения:

1. Различия в прозрачности между посещённой и непосещённой ссылкой не применяются.
2. Нельзя изменять размеры и геометрию элемента на основании состояния `:visited`.
3. JavaScript не может надёжно определить факт посещения ссылки посредством `getComputedStyle()` или методов выбора элементов.
4. Проверка состояния `:visited` не должна раскрывать реальную историю посещений пользователя.

Например:

```css
a:visited {
  font-size: 24px;
  transform: scale(1.2);
}
```

Такое правило не приведёт к изменению размера текста или масштаба в зависимости от истории посещений.

### Порядок псевдоклассов ссылок — LVHA

При стилизации ссылок традиционно рекомендуется соблюдать следующий порядок:

```css
a:link {
  color: blue;
}

a:visited {
  color: purple;
}

a:hover {
  color: red;
}

a:active {
  color: green;
}
```

Мнемоника: **LVHA — Link, Visited, Hover, Active**.

Этот порядок помогает корректно организовать каскад, поскольку перечисленные псевдоклассы имеют одинаковую специфичность.

## 22. Для чего используются `::before` и `::after`?

**`::before` и `::after`** — псевдоэлементы, позволяющие добавлять CSS-генерируемое содержимое без создания дополнительных HTML-элементов.

Они используются преимущественно для декоративных элементов интерфейса:

- линий и разделителей;
- иконок;
- декоративных символов;
- дополнительных визуальных деталей.

### Различие между `::before` и `::after`

- `::before` — создаёт содержимое перед основным содержимым элемента.
- `::after` — создаёт содержимое после основного содержимого элемента.

Например:

HTML:

```html
<p class="text">Hello</p>
```

CSS:

```css
.text::before {
  content: "→ ";
}

.text::after {
  content: " ✓";
}
```

Результат:

```text
→ Hello ✓
```

### Важные особенности

1. `::before` и `::after` не создают обычные HTML-элементы в исходном DOM.
2. Не предназначены для размещения важной смысловой информации.
3. CSS-генерируемое содержимое не всегда надёжно доступно вспомогательным технологиям.
4. Не применяются обычным образом к замещаемым элементам (Replaced Elements), например `<img>`.

**Практическая рекомендация:** использовать `::before` и `::after` для оформления, а значимое содержимое размещать непосредственно в HTML.

## 23. Что необходимо указать, чтобы `::before` или `::after` появился?

Для отображения `::before` или `::after` обычно необходимо задать свойство `content`.

Например:

```css
.element::before {
  content: "";
}
```

Даже если псевдоэлемент не содержит текста, пустая строка позволяет создать генерируемое содержимое, которому затем можно назначить стили.

Например, декоративную линию:

```css
.card::before {
  content: "";
  display: block;
  width: 40px;
  height: 2px;
  background-color: black;
}
```

Если `content` отсутствует либо принимает значения `normal` или `none`, соответствующий псевдоэлемент не отображается.

**Важно:** свойство `content` определяет, будет ли сгенерировано содержимое псевдоэлемента. Для управления его размером, расположением и оформлением используются обычные CSS-свойства, например `display`, `width`, `height`, `position`, `background-color` и другие.

## 24. Для чего используются `::placeholder`, `::selection` и `::marker`?

Эти псевдоэлементы позволяют стилизовать отдельные части интерфейса, которые не представлены самостоятельными HTML-элементами.

### 1. `::placeholder` — текст-подсказка

Позволяет стилизовать текст, отображаемый в полях формы посредством HTML-атрибута `placeholder`.

HTML:

```html
<input
  type="email"
  placeholder="Enter your email"
>
```

CSS:

```css
input::placeholder {
  color: gray;
  font-style: italic;
}
```

Не следует путать `::placeholder` с псевдоклассом `:placeholder-shown`.

Различие:

- `::placeholder` — стилизует сам текст-подсказку.
- `:placeholder-shown` — выбирает элемент управления, в котором в данный момент отображается placeholder.

**Важно:** placeholder не заменяет полноценный `<label>` и не должен использоваться как единственный способ обозначения назначения поля.

### 2. `::selection` — выделенный текст

Позволяет стилизовать часть содержимого, выделенную пользователем.

Например:

```css
::selection {
  color: white;
  background-color: navy;
}
```

При выделении текста пользователь увидит белый текст на тёмно-синем фоне.

Поддерживается ограниченный набор CSS-свойств, преимущественно связанных с оформлением текста и цветом выделения.

### 3. `::marker` — маркеры элементов списка

Позволяет стилизовать маркеры элементов списка: точки, цифры и другие обозначения.

HTML:

```html
<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>
```

CSS:

```css
li::marker {
  color: red;
  font-weight: bold;
}
```

В результате маркеры списка станут красными и получат полужирное начертание там, где это применимо.

`::marker` поддерживает ограниченный набор CSS-свойств, включая некоторые свойства текста, `color` и `content`.

Применяется к элементам, генерирующим маркер, то есть имеющим `display: list-item`.
