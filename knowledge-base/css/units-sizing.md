# VI. Размеры и единицы измерения

## 1. Какие единицы измерения существуют в CSS?

В CSS существует несколько типов числовых значений. Они используются не только для размеров элементов, но и для углов, времени, разрешения и других величин.

Для размеров чаще всего используются **единицы длины**.

Их можно разделить на две большие группы:

```text
единицы длины

├── абсолютные
│
└── относительные
```

### Абсолютные единицы длины

К ним относятся:

| Единица | Значение |
|---|---|
| `px` | CSS-пиксель |
| `cm` | сантиметры |
| `mm` | миллиметры |
| `Q` | четверть миллиметра |
| `in` | дюймы |
| `pt` | пункты |
| `pc` | пики |

Например:

```css
.box {
  width: 300px;
}
```

В веб-разработке чаще всего из абсолютных единиц используется:

```css
px
```

Единицы вроде:

```text
cm
mm
pt
in
```

чаще полезны для печатных документов.

---

### Относительные единицы длины

Их значение зависит от некоторой другой величины.

Например:

```text
em
rem
ch

vw
vh

svh
lvh
dvh
```

Также существуют современные единицы:

```text
cap
ex
ic
lh

rcap
rex
ric
rlh

svw
lvw
dvw

vmin
vmax

vi
vb
```

и единицы размеров контейнера:

```text
cqw
cqh
cqi
cqb
cqmin
cqmax
```

Для начала не нужно запоминать их все.

На практике особенно важно понимать:

```text
px
%
em
rem
vw
vh
svh
lvh
dvh
ch
fr
```

---

### Проценты

```css
width: 50%;
```

`%` технически является отдельным типом значения — процентом, а не обычной единицей длины.

Процент всегда рассчитывается относительно другой величины.

Например:

```css
.child {
  width: 50%;
}
```

обычно означает:

> ширина элемента составляет 50% ширины содержащего его блока.

Однако важно понимать:

> `%` не всегда означает процент ширины родителя.

То, относительно чего рассчитывается процент, зависит от конкретного CSS-свойства.

Например:

```css
font-size: 150%;
```

рассчитывается относительно размера шрифта родителя.

---

### Единицы угла

Для поворотов и других угловых значений используются:

```text
deg
rad
grad
turn
```

Например:

```css
.element {
  transform: rotate(45deg);
}
```

или:

```css
.element {
  transform: rotate(0.5turn);
}
```

`0.5turn` — половина полного оборота:

```text
180deg
```

---

### Единицы времени

Используются, например, в переходах и анимациях:

```text
s
ms
```

Например:

```css
.button {
  transition-duration: 0.3s;
}
```

или:

```css
.button {
  transition-duration: 300ms;
}
```

При этом:

```text
1s = 1000ms
```

---

### Единицы разрешения

Существуют:

```text
dpi
dpcm
dppx
x
```

Они используются значительно реже, например в некоторых медиавыражениях.

---

### `fr`

В CSS Grid существует специальная гибкая единица:

```css
fr
```

Например:

```css
.grid {
  display: grid;
  grid-template-columns: 1fr 2fr;
}
```

Она распределяет доступное свободное пространство между дорожками Grid.

`fr` рассмотрим отдельно в вопросе 9.

---

### Главное

Для повседневной адаптивной вёрстки чаще всего встречаются:

```text
px
%
rem
em
vw
vh
dvh
fr
```

А остальные единицы стоит изучать постепенно по мере необходимости.

Современный CSS действительно содержит значительно больше относительных единиц, чем базовые `px`, `em`, `rem`, `vw` и `vh`, включая единицы контейнеров и шрифта.

---

## 2. Чем абсолютные единицы отличаются от относительных?

Основная разница заключается в том, **от чего рассчитывается значение**.

### Абсолютные единицы

Абсолютная единица не рассчитывается относительно размера шрифта, родителя или окна браузера.

Например:

```css
.box {
  width: 300px;
}
```

Значение:

```text
300px
```

само по себе не зависит от ширины родителя.

К абсолютным единицам относятся:

```text
px
cm
mm
Q
in
pt
pc
```

---

### Относительные единицы

Относительная единица вычисляется относительно другой величины.

Например:

```css
font-size: 2rem;
```

зависит от размера шрифта корневого элемента.

```css
padding: 2em;
```

зависит от размера шрифта элемента.

```css
width: 50vw;
```

зависит от ширины области просмотра браузера.

```css
height: 100dvh;
```

зависит от текущей динамической высоты области просмотра.

---

### Пример с `%`

```css
.parent {
  width: 800px;
}

.child {
  width: 50%;
}
```

Ширина `.child` будет:

```text
800px × 50%
=
400px
```

Если ширина родителя изменится:

```css
.parent {
  width: 1000px;
}
```

то:

```text
50% от 1000px
=
500px
```

### Важный нюанс

Процент рассчитывается не всегда одинаково.

Например:

```css
width: 50%;
```

обычно рассчитывается относительно ширины содержащего блока.

Но:

```css
font-size: 150%;
```

рассчитывается относительно размера шрифта родителя.

То есть `%` означает:

> возьми определённую величину, которую задаёт конкретное CSS-свойство, и рассчитай от неё процент.

Поэтому нельзя сказать:

> `%` всегда считается от родителя.

Правильнее:

> Процент всегда зависит от контекста конкретного свойства.

---

### Пример с `rem`

Если:

```css
html {
  font-size: 16px;
}
```

то:

```css
.box {
  padding: 2rem;
}
```

получим:

```text
2 × 16px
=
32px
```

---

### Сравнение

| Характеристика | Абсолютные | Относительные |
|---|---|---|
| Зависят от другой величины | Нет | Да |
| Пример | `px` | `rem`, `%`, `vw` |
| Удобны для адаптивности | Иногда | Очень часто |
| Могут изменяться вместе с контекстом | Обычно нет | Да |

### Важный нюанс про `px`

Название «абсолютная единица» не означает, что:

```text
1 CSS px = 1 физический пиксель экрана
```

На современных экранах с высокой плотностью пикселей один CSS-пиксель может соответствовать нескольким физическим пикселям устройства.

Например, браузер может отображать:

```text
1 CSS px
```

с помощью нескольких физических пикселей дисплея.

Поэтому в CSS правильнее думать о `px` как о **CSS-пикселе**, а не буквально об одном светящемся пикселе монитора.

---

## 3. Что такое `em`?

`em` — относительная единица длины, связанная с размером шрифта.

В большинстве свойств:

```text
1em
=
текущий рассчитанный font-size элемента
```

Например:

```css
.card {
  font-size: 20px;
  padding: 2em;
}
```

Получаем:

```text
1em = 20px

2em = 40px
```

Поэтому:

```css
padding: 2em;
```

будет равен:

```text
40px
```

---

### Пример

```css
.button {
  font-size: 16px;
  padding: 0.5em 1em;
}
```

Расчёт:

```text
0.5em = 8px

1em = 16px
```

То есть фактически:

```css
padding: 8px 16px;
```

---

### Особенность `em` в `font-size`

Здесь есть очень важное исключение.

Если `em` используется непосредственно в:

```css
font-size
```

он рассчитывается относительно размера шрифта **родителя**.

Например:

```css
.parent {
  font-size: 20px;
}

.child {
  font-size: 1.5em;
}
```

Получаем:

```text
20px × 1.5
=
30px
```

Размер шрифта `.child`:

```text
30px
```

После этого другие свойства `.child`, заданные в `em`, будут рассчитываться уже от его собственного размера шрифта.

Например:

```css
.child {
  font-size: 1.5em;
  padding: 1em;
}
```

Если родитель имеет:

```text
20px
```

то:

```text
font-size:
20px × 1.5 = 30px
```

а затем:

```text
padding:
1em = 30px
```

---

### Для чего полезен `em`?

`em` удобно использовать, когда размеры компонента должны масштабироваться вместе с его текстом.

Например:

```css
.button {
  font-size: 1rem;
  padding: 0.75em 1.5em;
  border-radius: 0.5em;
}
```

Если увеличить `font-size` кнопки, её:

- внутренние отступы;
- радиус;
- другие размеры в `em`

тоже изменятся пропорционально.

---

### Важный недостаток

`em` может накапливаться при вложенности.

Например:

```css
.parent {
  font-size: 1.2em;
}

.child {
  font-size: 1.2em;
}
```

Если исходный размер:

```text
16px
```

то у родителя:

```text
16 × 1.2
=
19.2px
```

У ребёнка:

```text
19.2 × 1.2
=
23.04px
```

Поэтому при глубокой вложенности размеры могут становиться менее предсказуемыми.

`em` в современной спецификации определяется через рассчитанный размер шрифта элемента; для самого `font-size` расчёт идёт относительно родительского размера.

---

## 4. Что такое `rem`?

`rem` — относительная единица длины, которая рассчитывается относительно размера шрифта **корневого элемента документа**.

Обычно корневой элемент HTML:

```html
<html>
```

Например:

```css
html {
  font-size: 16px;
}
```

Тогда:

```text
1rem = 16px
2rem = 32px
0.5rem = 8px
```

---

### Пример

```css
.card {
  padding: 2rem;
}
```

Если:

```css
html {
  font-size: 16px;
}
```

получаем:

```text
2 × 16px
=
32px
```

---

### Вложенность не меняет `rem`

Например:

```css
html {
  font-size: 16px;
}

.parent {
  font-size: 30px;
}

.child {
  padding: 2rem;
}
```

Несмотря на:

```css
.parent {
  font-size: 30px;
}
```

для `.child`:

```text
1rem = 16px

2rem = 32px
```

потому что `rem` смотрит не на родителя, а на корневой элемент.

---

### Почему `rem` часто используют?

Потому что размер остаётся предсказуемым во всём документе.

Например:

```css
.title {
  font-size: 2rem;
}

.card {
  padding: 1.5rem;
}

.button {
  border-radius: 0.5rem;
}
```

Все размеры имеют одну общую точку отсчёта.

---

### Важно про `16px`

Часто говорят:

```text
1rem = 16px
```

Но это **не абсолютное правило CSS**.

`16px` — распространённое начальное значение размера шрифта браузера.

Пользователь может изменить его в настройках браузера.

Кроме того, разработчик может написать:

```css
html {
  font-size: 18px;
}
```

Тогда:

```text
1rem = 18px
```

Поэтому правильнее говорить:

> `1rem` равен размеру шрифта корневого элемента.

А не:

> `1rem` всегда равен `16px`.

---

## 5. Чем `em` отличается от `rem`?

Главное различие — **точка отсчёта**.

```text
em
→ зависит от размера шрифта элемента
  или родителя при font-size

rem
→ зависит от размера шрифта корневого элемента
```

---

### Пример

```css
html {
  font-size: 16px;
}

.parent {
  font-size: 20px;
}

.child {
  padding: 2em;
  margin: 2rem;
}
```

Для `.child`:

```text
2em
=
2 × 20px
=
40px
```

А:

```text
2rem
=
2 × 16px
=
32px
```

---

### Сравнение

| Характеристика | `em` | `rem` |
|---|---|---|
| Зависит от локального размера шрифта | Да | Нет |
| Зависит от корневого `<html>` | Нет | Да |
| Может изменяться из-за вложенности | Да | Нет |
| Удобен для масштабирования отдельного компонента | Да | Иногда |
| Предсказуем во всём документе | Меньше | Больше |

---

### Когда удобно использовать `em`?

Например, внутри кнопки:

```css
.button {
  font-size: 1rem;
  padding: 0.75em 1.5em;
}
```

Если увеличить:

```css
font-size
```

кнопка увеличится пропорционально.

---

### Когда удобно использовать `rem`?

Для общей системы размеров интерфейса:

```css
.page {
  padding: 2rem;
}

.title {
  font-size: 2rem;
}

.card {
  gap: 1.5rem;
}
```

Так размеры остаются связанными с одной общей базой.

---

### Главное

```text
em
→ локальная зависимость

rem
→ глобальная зависимость от корневого элемента
```

Обе единицы являются относительными и хорошо подходят для масштабируемых интерфейсов.

---

## 6. Что такое `vw` и `vh`?

`vw` и `vh` — относительные единицы, зависящие от размеров области просмотра браузера.

**Viewport** — область страницы, которую пользователь видит в окне браузера.

---

### `vw`

```text
vw = viewport width
```

`1vw` равен:

```text
1% ширины области просмотра
```

Например, если ширина:

```text
1200px
```

то:

```text
1vw = 12px
```

Следовательно:

```text
50vw = 600px
```

Пример:

```css
.hero {
  width: 80vw;
}
```

Элемент займёт:

```text
80% ширины области просмотра
```

---

### `vh`

```text
vh = viewport height
```

`1vh` равен:

```text
1% высоты области просмотра
```

Если высота области просмотра:

```text
900px
```

то:

```text
1vh = 9px
```

Следовательно:

```text
100vh = 900px
```

Пример:

```css
.hero {
  min-height: 100vh;
}
```

Элемент стремится занимать высоту, равную высоте области просмотра.

---

### Существуют также `vmin` и `vmax`

`vmin` выбирает меньшую из величин:

```text
vw
vh
```

То есть:

```text
1vmin
=
1% меньшей стороны viewport
```

`vmax`, наоборот:

```text
1vmax
=
1% большей стороны viewport
```

---

### Проблема `vh` на мобильных устройствах

На мобильном устройстве часть экрана может занимать интерфейс браузера:

- адресная строка;
- панель управления;
- другие элементы браузера.

Эти панели могут появляться и исчезать при прокрутке.

Поэтому понятие:

```css
100vh
```

исторически было не всегда удобным для полноэкранных мобильных блоков.

Именно для решения таких задач появились:

```text
svh
lvh
dvh
```

В современной модели обычные `vh`/`vw` относятся к стандартным viewport-единицам; текущие браузеры сопоставляют их с большими вариантами `lvh`/`lvw`.

---

## 7. Что такое `svh`, `lvh` и `dvh`?

Это современные единицы высоты области просмотра, созданные прежде всего для корректной работы с мобильными браузерами.

У мобильного браузера видимая область может менять размер.

Например:

```text
адресная строка показана
↓
свободной высоты меньше

адресная строка скрылась
↓
свободной высоты больше
```

Для этого CSS различает:

```text
svh
lvh
dvh
```

---

### `svh`

**Small Viewport Height** — высота маленькой области просмотра.

```text
1svh
=
1% высоты маленького viewport
```

`100svh` ориентируется на состояние, когда интерфейс браузера занимает больше пространства.

Условно:

```text
┌──────────────────┐
│ адресная строка  │
├──────────────────┤
│                  │
│                  │
│    viewport      │
│                  │
│                  │
└──────────────────┘
```

Это полезно, если важно гарантировать, что содержимое помещается даже тогда, когда панели браузера видимы.

---

### `lvh`

**Large Viewport Height** — высота большой области просмотра.

```text
1lvh
=
1% большой высоты viewport
```

`100lvh` соответствует состоянию, когда интерфейс браузера максимально убран и странице доступно больше пространства.

Условно:

```text
┌──────────────────┐
│                  │
│                  │
│                  │
│     viewport     │
│                  │
│                  │
│                  │
└──────────────────┘
```

---

### `dvh`

**Dynamic Viewport Height** — динамическая высота области просмотра.

```text
1dvh
=
1% текущей динамической высоты viewport
```

То есть значение изменяется вместе с фактической доступной высотой.

Например:

```css
.hero {
  min-height: 100dvh;
}
```

Когда адресная строка показана:

```text
100dvh → меньше
```

Когда она скрывается:

```text
100dvh → больше
```

---

### Сравнение

```text
svh
→ маленькая высота viewport

lvh
→ большая высота viewport

dvh
→ текущая динамическая высота viewport
```

| Единица | Что используется |
|---|---|
| `svh` | минимальная доступная высота |
| `lvh` | максимальная доступная высота |
| `dvh` | текущая высота |

---

### Практический пример

Для полноэкранного блока на мобильных устройствах часто удобно:

```css
.hero {
  min-height: 100dvh;
}
```

вместо:

```css
.hero {
  min-height: 100vh;
}
```

Потому что `dvh` реагирует на изменение интерфейса мобильного браузера.

---

### Есть аналоги для ширины

Существуют:

```text
svw
lvw
dvw
```

Например:

```text
1dvw
=
1% текущей динамической ширины viewport
```

Также существуют варианты для:

```text
vmin
vmax
vi
vb
```

например:

```text
svmin
lvmin
dvmin
```

Но на начальном этапе достаточно хорошо понимать:

```text
svh
lvh
dvh
```

Их определения в современной документации именно такие: small, large и dynamic viewport.

---

## 8. Что такое `ch`?

`ch` — относительная единица длины, связанная со шрифтом.

Она основана на ширине, точнее на горизонтальном размере символа:

```text
0
```

то есть цифры ноль в используемом шрифте.

Упрощённо:

```text
1ch
≈ ширина символа "0"
```

Например:

```css
.text {
  max-width: 60ch;
}
```

Это означает:

> максимальная ширина текста примерно равна ширине 60 символов `0` данного шрифта.

---

### Важный нюанс

`ch` **не означает точное количество символов текста**.

Например:

```css
width: 20ch;
```

не означает:

> сюда обязательно поместится ровно 20 любых букв.

Почему?

Потому что в большинстве шрифтов разные символы имеют разную ширину.

Например:

```text
i
```

обычно значительно уже:

```text
W
```

А `ch` ориентируется именно на размер символа:

```text
0
```

---

### Где полезен `ch`?

Очень удобно ограничивать длину текстовой строки.

Например:

```css
.article {
  max-width: 65ch;
}
```

Так можно приблизительно контролировать удобную ширину текста.

Также `ch` может быть полезен для полей:

```css
input {
  width: 30ch;
}
```

---

### Главное

```text
ch
→ единица, зависящая от шрифта
→ основана на размере символа "0"
→ удобна для ширины текста
```

Современное определение говорит именно о размере продвижения глифа `0`, а не о «средней ширине одного символа».

---

## 9. Что такое `fr`?

`fr` — специальная гибкая единица, используемая в **CSS Grid**.

Она означает долю доступного свободного пространства в сетке.

Например:

```css
.grid {
  display: grid;
  grid-template-columns: 1fr 1fr;
}
```

Две колонки получают одинаковые доли свободного пространства:

```text
1fr + 1fr
```

То есть примерно:

```text
50% / 50%
```

Но `fr` — это не просто другое написание процентов.

---

### Пример

```css
.grid {
  display: grid;
  grid-template-columns: 1fr 2fr;
}
```

Всего:

```text
1 + 2 = 3 доли
```

Первая колонка получает:

```text
1 / 3
```

свободного пространства.

Вторая:

```text
2 / 3
```

---

### Пример с фиксированной колонкой

```css
.grid {
  display: grid;
  grid-template-columns: 200px 1fr;
}
```

Допустим, контейнер имеет ширину:

```text
1000px
```

Сначала браузер выделяет:

```text
200px
```

первой колонке.

Остаётся:

```text
800px
```

Эта оставшаяся часть достаётся:

```text
1fr
```

---

### Несколько `fr`

```css
grid-template-columns: 200px 1fr 2fr;
```

Допустим, после фиксированной колонки осталось:

```text
900px
```

Всего гибких долей:

```text
1 + 2 = 3
```

Тогда условно:

```text
1fr = 300px

2fr = 600px
```

---

### Важный нюанс

`fr` распределяет **свободное пространство** после того, как браузер учёл другие ограничения сетки и размеры содержимого.

Поэтому нельзя всегда буквально считать:

```text
1fr 1fr
=
ровно 50% + 50%
```

В Grid есть дополнительные правила минимальных размеров содержимого.

Например, иногда:

```css
grid-template-columns: 1fr 1fr;
```

может дать неожиданный результат из-за минимального размера содержимого.

Для более строгого разрешения колонке сжиматься часто используется:

```css
grid-template-columns:
  minmax(0, 1fr)
  minmax(0, 1fr);
```

---

### Где можно использовать `fr`?

Например:

```css
grid-template-columns
grid-template-rows
```

`fr` предназначена именно для гибких размеров дорожек Grid.

Это не универсальная единица вроде:

```text
px
rem
vw
```

Например:

```css
width: 1fr;
```

не является обычным способом задания ширины элемента.

---

## 10. Как работает `calc()`?

`calc()` — математическая функция CSS, которая позволяет вычислять значение прямо в CSS.

Например:

```css
width: calc(100% - 40px);
```

Браузер вычисляет:

```text
100% ширины
-
40px
```

и использует результат как значение `width`.

---

### Главное преимущество

`calc()` позволяет сочетать разные совместимые единицы.

Например:

```css
width: calc(100% - 2rem);
```

Обычным арифметическим выражением без функции такую комбинацию записать было бы нельзя в тех местах, где синтаксис требует `calc()`.

---

### Практический пример

Есть боковая панель:

```css
.sidebar {
  width: 250px;
}
```

Основное содержимое должно занимать остальную ширину:

```css
.main {
  width: calc(100% - 250px);
}
```

То есть:

```text
ширина контейнера
-
250px
```

---

### Другой пример

```css
.card {
  width: calc(50% - 1rem);
}
```

Это может использоваться, например, когда две карточки занимают примерно половину контейнера, но между ними нужен промежуток.

---

### Арифметические операции

Современный синтаксис `calc()` допускает:

```text
+
-
*
/
```

Например:

```css
width: calc(100% - 40px);
```

```css
width: calc(10rem + 20px);
```

```css
width: calc(2em * 5);
```

```css
width: calc(100% / 3);
```

---

### Пробелы вокруг `+` и `-`

Для сложения и вычитания важно писать пробелы:

```css
width: calc(100% - 20px);
```

а не:

```css
width: calc(100%-20px);
```

Лучше придерживаться записи:

```text
значение пробел оператор пробел значение
```

---

### Можно использовать CSS-переменные

Например:

```css
:root {
  --sidebar-width: 280px;
}
```

```css
.main {
  width: calc(100% - var(--sidebar-width));
}
```

Это особенно полезно в реальных проектах.

---

### Можно использовать вложенные вычисления

Например:

```css
width: calc((100% - 40px) / 3);
```

Браузер сначала вычислит:

```text
100% - 40px
```

а затем разделит результат на:

```text
3
```

---

### `calc()` нельзя использовать для всего подряд

Результат должен иметь тип, который разрешён конкретным свойством.

Например:

```css
margin: calc(10px + 20px);
```

валидно:

```text
30px
```

Но:

```css
margin: calc(1 + 2);
```

получает безразмерное число:

```text
3
```

а `margin: 3` недопустим, поэтому такое значение не подойдёт.

---

### Современный нюанс 2026 года

В старых учебниках часто можно встретить утверждение:

> `calc()` работает только с `+`, `-`, `*` и `/` ограниченно или только с `+` и `-`.

Современная грамматика CSS Values Level 4 содержит все четыре арифметических оператора:

```text
+
-
*
/
```

При этом некоторые более новые возможности типизированной арифметики могут иметь различия в поддержке браузеров, поэтому при сложных вычислениях всё равно стоит проверять совместимость. MDN в сентябре 2026 года уже документирует `*` и `/` непосредственно в синтаксисе `calc()`.

---

## 11. Для чего используются `min()`, `max()` и `clamp()`?

Это математические функции CSS, которые позволяют ограничивать значения без большого количества медиазапросов.

---

### `min()`

`min()` выбирает **наименьшее** из переданных значений.

Например:

```css
.container {
  width: min(90%, 1200px);
}
```

Браузер сравнит:

```text
90%
1200px
```

и выберет меньшее значение.

---

### Пример

Если:

```text
90% = 900px
```

то:

```text
min(900px, 1200px)
=
900px
```

Если:

```text
90% = 1440px
```

то:

```text
min(1440px, 1200px)
=
1200px
```

Поэтому:

```css
width: min(90%, 1200px);
```

удобно для адаптивного контейнера:

```text
на маленьком экране
→ ширина уменьшается

на большом
→ не превышает 1200px
```

---

### `max()`

`max()` делает наоборот — выбирает **наибольшее** значение.

Например:

```css
.box {
  width: max(300px, 50%);
}
```

Если:

```text
50% = 200px
```

то браузер выберет:

```text
300px
```

Если:

```text
50% = 500px
```

то браузер выберет:

```text
500px
```

---

### `clamp()`

`clamp()` позволяет задать:

```text
минимум
предпочтительное значение
максимум
```

Синтаксис:

```css
clamp(min, preferred, max)
```

Например:

```css
font-size: clamp(1rem, 3vw, 2rem);
```

Здесь:

```text
1rem
→ минимальный размер

3vw
→ предпочтительный динамический размер

2rem
→ максимальный размер
```

---

### Как работает `clamp()`

Допустим:

```css
font-size: clamp(16px, 4vw, 32px);
```

Если:

```text
4vw = 12px
```

это меньше минимума, поэтому:

```text
font-size = 16px
```

Если:

```text
4vw = 24px
```

значение находится в диапазоне:

```text
16px ← 24px → 32px
```

поэтому:

```text
font-size = 24px
```

Если:

```text
4vw = 50px
```

это больше максимума:

```text
font-size = 32px
```

---

### Очень частый пример

Адаптивная типографика:

```css
.title {
  font-size: clamp(2rem, 5vw, 4rem);
}
```

Текст:

- не станет меньше `2rem`;
- плавно увеличивается вместе с шириной viewport;
- не станет больше `4rem`.

---

### Сравнение

```text
min()
→ выбери наименьшее

max()
→ выбери наибольшее

clamp()
→ удерживай значение между минимумом и максимумом
```

| Функция | Назначение |
|---|---|
| `min()` | ограничить значение сверху |
| `max()` | ограничить значение снизу |
| `clamp()` | задать нижнюю и верхнюю границу одновременно |

---

### Очень полезный паттерн контейнера

```css
.container {
  width: min(100% - 2rem, 1200px);
  margin-inline: auto;
}
```

Контейнер:

```text
не шире 1200px
+
оставляет пространство по краям маленького экрана
+
центрируется
```

`min()`, `max()` и `clamp()` широко поддерживаются; `clamp()` принимает именно минимум, предпочтительное значение и максимум.

---

## 12. Чем `width` отличается от `max-width` и `min-width`?

Все три свойства управляют шириной элемента, но выполняют разные задачи.

---

### `width`

`width` задаёт желаемую ширину элемента.

Например:

```css
.box {
  width: 500px;
}
```

Элемент получает ширину:

```text
500px
```

с учётом правил `box-sizing`.

При:

```css
box-sizing: content-box;
```

`width` задаёт ширину области содержимого.

При:

```css
box-sizing: border-box;
```

заданная ширина включает:

```text
content + padding + border
```

---

### `min-width`

`min-width` задаёт **минимально допустимую ширину**.

Например:

```css
.box {
  width: 50%;
  min-width: 300px;
}
```

Элемент стремится иметь:

```text
width: 50%
```

но не станет уже:

```text
300px
```

---

### `max-width`

`max-width` задаёт **максимально допустимую ширину**.

Например:

```css
.container {
  width: 100%;
  max-width: 1200px;
}
```

На маленьком экране:

```text
width = 100%
```

На большом:

```text
width ≤ 1200px
```

---

### Практический пример

```css
.container {
  width: 100%;
  max-width: 1200px;
  margin-inline: auto;
}
```

Получаем адаптивный контейнер.

На экране шириной:

```text
800px
```

он может иметь:

```text
800px
```

На экране шириной:

```text
1600px
```

ширина ограничится:

```text
1200px
```

---

### Что происходит при конфликте?

Например:

```css
.box {
  width: 500px;
  max-width: 300px;
}
```

`width` просит:

```text
500px
```

но:

```css
max-width: 300px;
```

не разрешает становиться шире.

Результат:

```text
300px
```

---

Другой пример:

```css
.box {
  width: 200px;
  min-width: 400px;
}
```

`width`:

```text
200px
```

но минимально разрешено:

```text
400px
```

Результат:

```text
400px
```

---

### Приоритет ограничений

Упрощённо:

```text
min-width
↓
нижняя граница

width
↓
желаемая ширина

max-width
↓
верхняя граница
```

Если `width` выходит за эти границы, ограничения его корректируют.

MDN прямо указывает:

```text
если width < min-width
→ выигрывает min-width

если width > max-width
→ выигрывает max-width
```


---

### Сравнение

| Свойство | Что задаёт |
|---|---|
| `width` | желаемую ширину |
| `min-width` | минимальную ширину |
| `max-width` | максимальную ширину |

---

## 13. Чем `height` отличается от `min-height`?

### `height`

`height` задаёт высоту элемента.

Например:

```css
.box {
  height: 300px;
}
```

Элемент получает заданную высоту:

```text
300px
```

С учётом `box-sizing` она может относиться к разным областям Box Model.

---

### Проблема фиксированной высоты

Представим:

```css
.card {
  height: 200px;
}
```

Если содержимого мало:

```text
┌───────────────┐
│ Text          │
│               │
│               │
└───────────────┘
```

всё нормально.

Но если содержимого станет слишком много:

```text
┌───────────────┐
│ Очень много   │
│ содержимого   │
│ внутри        │
└───────────────┘
  продолжение...
```

может возникнуть переполнение.

---

### `min-height`

`min-height` задаёт:

> минимальную высоту, ниже которой элемент не должен уменьшаться.

Например:

```css
.card {
  min-height: 200px;
}
```

Если контента мало:

```text
высота минимум 200px
```

Если контента становится больше:

```text
элемент может стать выше
```

---

### Пример

```css
.card {
  min-height: 200px;
}
```

С коротким содержимым:

```text
height ≈ 200px
```

С длинным:

```text
height может стать 350px
```

или больше.

---

### Поэтому `min-height` часто безопаснее

Для карточек и секций:

```css
.card {
  min-height: 300px;
}
```

часто надёжнее, чем:

```css
.card {
  height: 300px;
}
```

если количество содержимого заранее неизвестно.

---

### Частый пример для страницы

```css
.page {
  min-height: 100dvh;
}
```

Это означает:

> страница должна занимать хотя бы всю текущую высоту viewport, но может стать выше, если содержимого больше.

Если написать:

```css
height: 100dvh;
```

мы задаём конкретную высоту, что в некоторых случаях может привести к переполнению содержимого.

---

### Сравнение

| Свойство | Поведение |
|---|---|
| `height` | задаёт высоту |
| `min-height` | задаёт минимальную высоту и позволяет расти дальше |

`min-height` действительно не позволяет итоговой высоте стать меньше указанной величины.

---

## 14. Что означает `width: auto`?

```css
.element {
  width: auto;
}
```

означает:

> браузер должен самостоятельно вычислить подходящую ширину элемента согласно правилам текущей модели раскладки.

`auto` не означает конкретное число вроде:

```text
100%
```

и не означает:

```text
ширина по содержимому
```

во всех ситуациях.

Его точный результат зависит от контекста.

---

### Обычный блочный элемент

Например:

```html
<div class="box">Hello</div>
```

```css
.box {
  width: auto;
}
```

Для обычного блочного элемента в нормальном потоке ширина `auto` обычно приводит к тому, что элемент занимает доступную ширину содержащего блока.

Условно:

```text
родитель
┌────────────────────────────┐
│ child width: auto          │
│ ┌────────────────────────┐ │
│ │                        │ │
│ └────────────────────────┘ │
└────────────────────────────┘
```

---

### Почему это не совсем то же самое, что `width: 100%`?

Это важный нюанс.

```css
width: 100%;
```

и:

```css
width: auto;
```

могут визуально давать похожий результат, но рассчитываются по-разному.

При `width: 100%` процент задаёт ширину соответствующей области элемента относительно содержащего блока.

Если при этом есть:

```css
padding
border
```

и используется:

```css
box-sizing: content-box;
```

элемент может стать шире родителя.

Например:

```css
.child {
  width: 100%;
  padding: 20px;
}
```

При `content-box`:

```text
100%
+
40px padding
```

может выйти за границы родителя.

---

При:

```css
width: auto;
```

браузер для обычного блочного элемента рассчитывает доступную ширину с учётом других компонентов Box Model.

Поэтому:

```text
auto ≠ всегда 100%
```

---

### В других моделях раскладки

Значение `auto` может вести себя иначе:

- у Grid-элементов;
- у Flexbox-элементов;
- у абсолютно позиционированных элементов;
- у изображений;
- у элементов с собственными внутренними размерами.

Поэтому правильное определение:

> `width: auto` передаёт расчёт ширины алгоритму раскладки браузера.

MDN формулирует `auto` как значение, при котором браузер вычисляет и выбирает ширину элемента.

---

## 15. Что делает `aspect-ratio`?

`aspect-ratio` задаёт предпочтительное **соотношение ширины и высоты элемента**.

Например:

```css
.video {
  aspect-ratio: 16 / 9;
}
```

Это означает:

```text
ширина : высота
=
16 : 9
```

---

### Пример

```css
.video {
  width: 800px;
  aspect-ratio: 16 / 9;
}
```

Высоту браузер может вычислить:

```text
800 × 9 / 16
=
450px
```

Получаем:

```text
800 × 450
```

---

### Квадрат

```css
.avatar {
  aspect-ratio: 1 / 1;
}
```

означает:

```text
ширина = высота
```

Например:

```css
.avatar {
  width: 100px;
  aspect-ratio: 1 / 1;
}
```

получим:

```text
100 × 100
```

---

### Вертикальный элемент

```css
.poster {
  aspect-ratio: 2 / 3;
}
```

Здесь высота больше ширины.

---

### Очень важное условие

Чтобы `aspect-ratio` мог определить размер элемента, хотя бы одна из его сторон обычно должна оставаться автоматической.

Например:

```css
.box {
  width: 400px;
  aspect-ratio: 16 / 9;
}
```

Высота может быть рассчитана автоматически.

Или:

```css
.box {
  height: 300px;
  aspect-ratio: 1 / 1;
}
```

ширина может вычислиться из высоты.

---

### Если задать и `width`, и `height`

Например:

```css
.box {
  width: 400px;
  height: 100px;

  aspect-ratio: 1 / 1;
}
```

здесь размеры уже явно заданы:

```text
400 × 100
```

Поэтому `aspect-ratio` не сможет просто превратить элемент в квадрат.

В общем случае для влияния `aspect-ratio` на предпочтительные размеры хотя бы одна сторона должна оставаться автоматической.

---

### Использование с изображениями

Изображения часто имеют собственное естественное соотношение сторон.

Например:

```html
<img src="photo.jpg" alt="">
```

У изображения может быть естественное соотношение:

```text
3 / 2
```

CSS позволяет использовать:

```css
img {
  width: 100%;
  height: auto;
}
```

и изображение сохранит свои пропорции.

Также можно задать собственное:

```css
img {
  width: 100%;
  aspect-ratio: 16 / 9;
  object-fit: cover;
}
```

---

### `object-fit`

Очень часто `aspect-ratio` используется вместе с:

```css
object-fit: cover;
```

Например:

```css
.card__image {
  width: 100%;
  aspect-ratio: 4 / 3;
  object-fit: cover;
}
```

Теперь все изображения карточек будут иметь одинаковую визуальную область:

```text
4 : 3
```

а `object-fit: cover` позволяет изображению заполнить её без искажения пропорций самого изображения — лишняя часть при необходимости обрезается.

---

### Практический пример для видео

```css
.video {
  width: 100%;
  aspect-ratio: 16 / 9;
}
```

Теперь ширина может меняться вместе с контейнером:

```text
1200px
800px
500px
```

а высота будет автоматически сохранять отношение:

```text
16 : 9
```

---

### Сравнение

```text
aspect-ratio: 1 / 1
→ квадрат

aspect-ratio: 16 / 9
→ широкоформатный прямоугольник

aspect-ratio: 4 / 3
→ классическое соотношение

aspect-ratio: 2 / 3
→ вертикальный прямоугольник
```

---

### Главное

```text
aspect-ratio
=
предпочтительное отношение ширины к высоте
```

Записывается:

```css
aspect-ratio: width / height;
```

Например:

```css
aspect-ratio: 16 / 9;
```

При этом CSS рассматривает его как **предпочтительное**, а не безусловное соотношение: ограничения `min-width`, `max-width`, `min-height`, `max-height`, явно заданные размеры и правила текущей раскладки также могут участвовать в итоговом расчёте.
